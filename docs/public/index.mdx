---
title: "NoClick Community"
description: "Open-source, self-hosted workflow automation, integrations, and AI agents."
---

NoClick Community is the open-source NoClick: a visual editor and self-hosted
runtime for building and operating workflows, the same code that runs
noclick.com. It includes typed integration nodes, triggers,
collaboration, and agents that use credentials and model providers you control.

Start with [local development](/getting-started/local-development), then review
the [community boundary](/architecture/community-boundary) before deploying or
contributing.

This project is open source under the GNU AGPL, version 3; the SDKs are
Apache-2.0. See [License](/reference/license).
