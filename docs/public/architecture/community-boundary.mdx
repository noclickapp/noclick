---
title: "Community boundary"
---

Everything in this repository is open source under the AGPL-3.0-only, and it
runs end to end without any NoClick-operated service: scheduling, relay,
workspaces, mail, and storage all have local, operator-configured
implementations here.

The hosted service at noclick.com runs this same code and adds managed
infrastructure on top: multi-region delivery, retained agent runtimes, its
larger workflow-generation pipeline, internal diagnostics and analytics,
subscription billing, and managed publishing. Those live outside this
repository, and no community module may require them or a fixed private
endpoint.
