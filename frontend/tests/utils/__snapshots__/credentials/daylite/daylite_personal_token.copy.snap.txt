## daylite_personal_token (Daylite)
name: Access token
line: Paste an access token from Daylite.
how: Generate a personal token in Daylite and paste its access_token. Tokens expire after one hour. Refresh it using Daylite's documented personal-token flow, then replace the access token here. Read and write operations require daylite:read and daylite:write respectively.
from: developer.daylite.app
  Access token — Paste the access_token value, without the Bearer prefix. Personal access tokens expire after one hour.
