## practice_better_access_token (Practice Better)
name: Access token
line: Paste an access token from Practice Better.
how: Paste an existing Practice Better access_token obtained from the documented client-credentials grant at POST /oauth2/token. Paste only the token, without Bearer. Tokens expire: replace the saved token when it expires. NoClick does not obtain or refresh tokens. The token needs read access for the connection check, plus write access for mutations; your account permissions must also allow each operation. Listing your services proves read access, not every write permission.
