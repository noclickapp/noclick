## revolut_business_access_token (Revolut For Business)
name: Access token
line: Paste an access token from Revolut For Business.
how: Prepare an access token with your Revolut Business API certificate and JWT flow. Paste it without Bearer. Tokens expire after 40 minutes; replace an expired token here. READ is needed for reads, WRITE for counterparties and drafts, PAY for payments and exchange. This connection does not refresh tokens.
from: developer.revolut.com
  Access token
  Environment (optional) — Production uses real money. Sandbox uses test accounts and funds.
