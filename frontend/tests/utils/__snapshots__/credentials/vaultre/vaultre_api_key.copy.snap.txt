## vaultre_api_key (Vaultre)
name: API key and access token
line: Paste an API key and access token from Vaultre.
how: Register as an approved integrator before connecting. Paste your integrator API key and an account access token from Office Integrations > Third-Party Access. The account owner chooses the token's permissions. Both values are required.
from: docs.api.vaultre.com.au
  Integrator API key
  Account access token
