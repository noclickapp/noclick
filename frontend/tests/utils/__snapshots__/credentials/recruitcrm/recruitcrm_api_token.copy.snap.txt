## recruitcrm_api_token (Recruitcrm)
name: API token
line: Paste an API token from Recruitcrm.
how: The account owner can enable and copy the API token under Admin Settings > API. Public API access requires a Business plan or an eligible partnership. Paste the token alone; NoClick sends it as a Bearer header to api.recruitcrm.io.
from: help.recruitcrm.io
  API token
