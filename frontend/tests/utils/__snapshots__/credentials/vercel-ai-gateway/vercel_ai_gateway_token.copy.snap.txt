## vercel_ai_gateway_token (Vercel AI Gateway)
name: Access token
line: Paste an access token from Vercel AI Gateway.
how: Create a Vercel access token with access to the team whose AI Gateway you manage. Paste it here. Use Account Settings → Tokens. AI Gateway inference keys are separate. Optionally enter the team ID for a team-scoped connection.
from: vercel.com
  Access token
  Team ID (optional) — Optional team ID from Vercel Team Settings. Leave empty to use the token's default account.
