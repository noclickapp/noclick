## directiq_api_key (Directiq)
name: API key
line: Paste an API key from Directiq.
how: Paste your Directiq API key. NoClick sends it in the X-API-Key header to api.directiq.com. Connecting reads your contact lists. List operations return one page; pass next_page_token to continue. Deleting a list starts a background deletion and may also delete contacts that belong to no other list.
from: rest.directiq.com
  API key
