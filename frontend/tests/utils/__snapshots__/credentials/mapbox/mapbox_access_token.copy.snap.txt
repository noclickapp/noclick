## mapbox_access_token (Mapbox)
name: Access token
line: Paste an access token from Mapbox.
how: Paste a Mapbox access token and your account username. Geocoding accepts public tokens. Reading styles needs styles:read; modifying styles or sprites needs a secret token with styles:write. Use an unrestricted server token; URL-restricted tokens may reject server requests.
from: account.mapbox.com
  Access token
  Account username
