## contabo_bearer (Contabo)
name: Access token
line: Paste an access token.
how: Supply an existing Contabo access token authorized for the required compute GETs. Contabo's documented password grant uses four separate credentials; this node does not exchange, refresh or mint tokens. Replace an expired token manually. Connection reads protected instance metadata and proves scoped resource reachability, not principal/customer identity. The optional expected instance is an existing resource witness.
  Access token
  Expected instance ID (optional) — Optional exact existing instance ID as decimal text. Every operation independently verifies this resource; no customer or tenant identity is inferred.
