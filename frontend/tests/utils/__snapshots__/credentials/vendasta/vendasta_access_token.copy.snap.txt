## vendasta_access_token (Vendasta)
name: Access token
line: Paste an access token from Vendasta.
how: Enter an issued OAuth2 access token and its issuer-reported expiry/scopes. Choose its environment and one authorized CRM namespace. NoClick does not mint or renew this supplied token. CRM API access may require Trusted Tester entitlement.
from: developers.vendasta.com
  Access token
  Environment
  CRM Namespace — Partner ID or account group ID authorized for this token.
  Token Expiration — Issuer-reported ISO timestamp with timezone; this is not inferred from the token.
  Granted Scopes — Exact space-separated scopes returned by the issuer.
  Readable Metadata Fields (optional) — Explicit comma-separated field IDs or external IDs whose values may appear in outputs.
  Writable Metadata Fields (optional) — Explicit field IDs or external IDs allowed for record metadata mutations.
