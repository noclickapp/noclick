## conveyor_api_key (Conveyor)
name: API key
line: Paste an API key from Conveyor.
how: In Conveyor, open Settings > Integrations > Add Integration > Conveyor API. Name the key and grant the portal permissions your workflow needs, including reading folders for the connection check. Paste the API key here. NoClick sends it in X-API-KEY only to api.conveyor.com. Creating an authorization grants Trust Center access and may invite its recipient; nda_bypass skips signing the NDA when enabled.
from: docs.conveyor.com
