## hevo_api_key (Hevo)
name: API key
line: Paste an API key from Hevo.
how: Supply an existing API key and secret issued by your Hevo account owner for the selected region. Basic username is the key and password is the secret. No account login, generation, mint or renewal is performed. Actual entitlement and per-operation permission are not inferred.
from: api-docs.hevodata.com
  API key
  API secret
  Hevo account region — The supplied key and secret bind your existing Hevo team. Select its documented region; no caller URL or team-header authority is accepted.
