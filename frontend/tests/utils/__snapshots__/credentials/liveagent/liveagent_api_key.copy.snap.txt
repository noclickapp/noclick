## liveagent_api_key (Liveagent)
name: API key
line: Paste an API key from Liveagent.
how: In Liveagent, open Configuration > System > API and create an API key with permissions for the actions you will use. Paste the key and your hosted account URL. NoClick uses the apikey header with API v4.
from: support.liveagent.com
  LiveAgent account URL — Your hosted account URL, for example https://your.ladesk.com.
  API key
