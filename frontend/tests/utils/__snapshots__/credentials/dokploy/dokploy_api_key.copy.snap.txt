## dokploy_api_key (Dokploy)
name: API key
line: Paste an API key from Dokploy.
how: Use your existing API/CLI token from the owned instance profile; an administrator must permit API access. Public HTTPS only. Confirm the instance implements the pinned Dokploy v0.30.8 contract. Expected user and organization IDs are verified against protected user.get before operations. No OAuth, key generation, refresh or permission change occurs here.
from: docs.dokploy.com
  Public HTTPS instance — Canonical origin only, for example https://deploy.your-domain.com; no /api path, private network or transport override.
  API key
  Expected Dokploy user ID
  Expected Dokploy organization ID — The active organization attached to the API key, distinct from your NoClick organization.
