## pipeless_api_key (Pipeless)
name: API key
line: Paste an API key from Pipeless.
how: Open Account → Apps in Pipeless and copy your App ID and app API key. Paste the key without the Bearer prefix. Each app has its own key and graph database. NoClick checks the connection by reading recent events for that app.
