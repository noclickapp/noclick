## katana_mrp_api_key (Katana Mrp)
name: API key
line: Paste an API key from Katana Mrp.
how: In Katana, go to Settings > API and add an API key. Paste the key here without the Bearer prefix. NoClick sends it to api.katanamrp.com to access your Katana account.
from: developer.katanamrp.com
