## ollama_server (Ollama)
name: Proxy API key
line: Paste a Proxy API key from Ollama and enter the server URL.
how: Enter your publicly reachable Ollama server origin without /api. Hosted workflows cannot reach localhost or a private LAN. Local Ollama itself needs no authentication; if you expose it through an authenticated HTTPS proxy, paste that proxy's bearer token. Tokens require HTTPS. Cloud usage and balance require the Ollama API Key connection instead. Connection testing lists this server's models and proves reachability.
from: docs.ollama.com
  Server URL — Public HTTP(S) origin without /api. Use HTTPS when sending a proxy token.
  Proxy API key (optional) — Optional bearer token for your own HTTPS proxy.
