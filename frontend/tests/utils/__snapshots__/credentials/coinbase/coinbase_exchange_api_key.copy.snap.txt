## coinbase_exchange_api_key (Coinbase)
name: Exchange API key
line: Paste an Exchange API key from Coinbase.
how: Paste your Coinbase Exchange API key, base64 secret and passphrase. These are Exchange credentials, not a CDP private key or Advanced Trade key. Enable View for account reads and connection verification, and Trade for order creation/cancellation. No transfer permission is needed. Requests go only to api.exchange.coinbase.com. Account reads prove access to the key's profile, not write permissions or access to every portfolio.
from: exchange.coinbase.com
  API key
  API secret — Paste the base64 secret exactly as Coinbase Exchange issued it.
  Passphrase
