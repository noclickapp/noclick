## btcpay_server_api_key (Btcpay Server)
name: API key
line: Paste an API key from Btcpay Server.
how: In your Btcpay Server account, open Account → Manage Account → API Keys and create an API key. Paste the key and your server's HTTPS origin. Enable btcpay.user.canviewprofile to verify the connection, plus the permissions needed for your operations: view store settings, view/create/modify invoices, manage invoice status, view/modify payment requests, or manage/create/archive pull payments. Keys can be restricted to individual stores. NoClick sends Authorization: token <key> to this server. An accepted profile read does not verify write permissions.
from: docs.btcpayserver.org
