## mentortools_api_key (Mentortools)
name: API key
line: Paste an API key from Mentortools.
how: In Mentortools, open Settings → Integrations & Automations and create an API key with permission for your selected actions. Paste the key here without Bearer. NoClick sends it to app.mentortools.com as a bearer token. Connecting reads your courses; Get Account reads the key, portal and owner identity.
from: app.mentortools.com
