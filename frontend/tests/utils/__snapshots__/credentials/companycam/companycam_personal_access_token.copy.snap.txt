## companycam_personal_access_token (Companycam)
name: Personal access token
line: Paste a personal access token from Companycam.
how: In Companycam on the web, open Integrations > Access Tokens > New Personal Access Token. Choose Read & Write for create and update actions, then copy the token. Paste only the token, without Bearer. Tokens expire according to the expiration you choose; replace an expired token here.
from: help.companycam.com
