## simple_localize_api_key (Simple Localize)
name: Project API key
line: Paste a project API key from Simple Localize.
how: Paste the project API key from Settings > Credentials > API Key. NoClick sends it in X-SimpleLocalize-Token. Use a project API key, not an account personal token. Customer translations require the provider's Business plan.
