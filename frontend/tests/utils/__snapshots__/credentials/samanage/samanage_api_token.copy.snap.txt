## samanage_api_token (Samanage)
name: API token
line: Paste an API token from Samanage.
how: In SolarWinds Service Desk, open Setup > Users & Groups > Users, select your user, and copy an API token. An administrator can generate a token. Paste only the token and select your account's region. Your user's permissions apply to every operation.
from: documentation.solarwinds.com
  API token
  Account region (optional) — US, Europe, or Asia Pacific / Japan.
