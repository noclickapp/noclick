## dust_api_key (Dust)
name: API key
line: Paste an API key from Dust.
how: In Dust, open Admin > Developers > API keys. Paste your API key and the workspace ID after /w/ in your Dust URL. Choose your workspace's US or EU region. Reads and conversations work with a read-only key; resource writes need an Admin key with access to the selected space.
