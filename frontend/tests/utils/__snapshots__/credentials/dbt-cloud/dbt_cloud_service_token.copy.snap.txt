## dbt_cloud_service_token (Dbt Cloud)
name: Service token
line: Paste a service token from Dbt Cloud.
from: docs.getdbt.com
  Existing account token
  Account ID — This token must already belong to this account. Local ID restrictions are not provider permission introspection.
  Administrative API Deployment — Use the publisher-spec US host or a documented Account settings cell access URL. Other legacy/custom single-tenant/VPC hosts are outside this node.
  Cell region (optional)
  Cell account Prefix (optional) — Hostname prefix from Account settings, without scheme, path, port or dots.
  Allowed project IDs — Explicit local current restrictions. Listing projects filters to these IDs; saved restrictions never grow automatically.
  Allowed read Operations — Local operation restrictions; actual permission sets and account API entitlement still come from dbt.
