## bigcommerce_api_token (BigCommerce)
name: API token
line: Paste an API token from BigCommerce.
how: In your BigCommerce control panel, open Settings → Store-level API accounts and create an API account. Copy its store hash and access token. Grant Orders, Products, Customers and Store Inventory modify permissions for write actions, or read-only for reads. Information & Settings read-only is needed for the store identity check.
from: docs.bigcommerce.com
  Store Hash — The store hash from your API path: api.bigcommerce.com/stores/STORE_HASH/v3.
  Access token — Paste the access token from your store-level API account.
