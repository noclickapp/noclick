## jwplayer_api_secret (Jwplayer)
name: JWX management API secret
line: Paste a JWX management API secret from Jwplayer.
how: Supply an existing Management API v2 secret and property ID. NoClick does not issue, rotate or exchange tokens. API entitlement must be confirmed with your JWX account.
from: dashboard.jwplayer.com
  API secret — Existing Management API v2 secret, sent only in the Bearer header. Player license keys are different.
  Site ID — Exact eight-character property ID that bounds every read. This is not an account or principal identity.
