## funtranslations_api_key (Funtranslations)
name: API key
line: Paste an API key from Funtranslations.
how: Paste your Funtranslations API key and choose a translator included in your subscription. Connecting makes one translation request and uses your API quota. This integration uses the published Swagger 2.3 API with the X-Funtranslations-Api-Secret header. A successful read proves reachability, not account ownership; the public free tier may also accept a request.
