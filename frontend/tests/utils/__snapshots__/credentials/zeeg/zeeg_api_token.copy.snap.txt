## zeeg_api_token (Zeeg)
name: API token
line: Paste an API token from Zeeg.
how: Create an API token in Zeeg Account Settings → API Access and paste it here. Enable events:read/write, event_types:read/write, schedules:read and notes:read/write for the operations you use. Availability needs timetable and booking needs booking; both require a paid Zeeg plan. The token is sent only to api.zeeg.me.
from: app.zeeg.me
