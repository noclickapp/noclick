## splitwise_api_key (Splitwise)
name: API key
line: Paste an API key from Splitwise.
how: Open your registered app in Splitwise's developer settings and generate a personal API key. Paste the key alone. It grants access to your personal Splitwise account and is sent as a Bearer token to secure.splitwise.com. Connecting reads your current user; it does not verify every write permission.
from: secure.splitwise.com
