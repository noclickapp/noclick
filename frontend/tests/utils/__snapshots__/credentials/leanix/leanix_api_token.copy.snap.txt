## leanix_api_token (Leanix)
name: SAP Lean IX API token
line: Paste an SAP Lean IX API token from Leanix.
from: help.sap.com
  Workspace subdomain — Actual single subdomain of your SAP Leanix workspace; requests use only https://<subdomain>.leanix.net.
  Existing Technical user API token — Exchanged with Basic client ID apitoken; no technical user, token or role is created here.
  Known Accessible Fact Sheet ID — Protected read witness; this does not prove a personal identity, numeric workspace ID or ownership.
