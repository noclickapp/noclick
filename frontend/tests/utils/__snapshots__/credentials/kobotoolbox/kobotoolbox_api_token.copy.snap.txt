## kobotoolbox_api_token (Kobotoolbox)
name: API key
line: Paste an API key from Kobotoolbox.
how: In Kobotoolbox, open Account Settings > Security > Display API Key. Paste the key and select the server where your account lives. The key can access your account's projects and data; keep it private.
from: support.kobotoolbox.org
  API key
  KoboToolbox server (optional)
