## higgsfield_api_key (Higgsfield)
name: API key
line: Paste an API key from Higgsfield.
how: Paste your Higgsfield Console key ID and secret. Optionally paste an existing request ID from this account to verify access with a read. Without a request ID the connection is saved as unverified. No generation is submitted during connection.
from: console.higgsfield.ai
  API key ID
  API key secret
  Verification request ID (optional) — Optional existing request UUID owned by this account. Used only for the connection read and request picker.
