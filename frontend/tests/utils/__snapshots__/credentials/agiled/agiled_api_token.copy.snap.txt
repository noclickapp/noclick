## agiled_api_token (Agiled)
name: API token
line: Paste an API token from Agiled.
how: In Agiled, open Settings > API Settings and copy your API token. Paste it here with your Agiled account URL. NoClick sends the token as api_token and the account URL as the Brand header to my.agiled.app. Agiled documents 180 requests per hour.
from: my.agiled.app
  API token
  Agiled account URL — Your account's HTTPS origin, for the Brand header.
