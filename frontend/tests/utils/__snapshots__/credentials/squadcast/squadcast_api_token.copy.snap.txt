## squadcast_api_token (Squadcast)
name: API refresh token
line: Paste an API refresh token from Squadcast.
how: In Squadcast, open My Profile and generate an API refresh token. Paste that token and select your account region. Your role controls which reads and changes are allowed.
from: developers.squadcast.com
  API refresh token — Paste the API refresh token from My Profile, without a header prefix.
  Account region (optional) — Choose the region where your Squadcast account is hosted.
