## royalmail_api_token (Royalmail)
name: API token
line: Paste an API token from Royalmail.
how: In ChannelShipper or Royal Mail Click & Drop, open Settings → Integrations → Royal Mail API and copy the API token. Paste only the token, without Bearer. Account features determine whether ChannelShipper details, OBA labels/returns or OLP services are available.
from: api.parcel.royalmail.com
  API token
