## auth0_token (Auth0)
name: Token
line: Paste a token from Auth0.
how: Paste a Management API access token and your tenant domain from Auth0 Dashboard → Settings. Use the tenant's auth0.com domain, including its region, rather than a custom login domain. Grant read:users for connection verification and the permissions required by your operations. Tokens expire; replace an expired token here.
from: auth0.com
  Tenant domain — Your Auth0 tenant domain, e.g. example.us.auth0.com.
  Access token — Management API bearer token with permissions for the selected operation.
