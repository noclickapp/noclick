## oracle_field_service_basic (Oracle Field Service)
name: Basic
line: Enter the Deployment host Label, authentication instance name, Registered application client ID and Registered application client secret for Oracle Field Service.
from: docs.oracle.com
  Deployment host Label — The exact environment label before .fs.ocs.oraclecloud.com. HTTPS only; deprecated etadirect hosts and Fusion IAM endpoints are not supported.
  Authentication instance name — The exact INSTANCE_NAME or alternate instance name from your service console. It can differ from the deployment label; their relationship must be verified by the owner.
  Registered application client ID
  Registered application client secret
