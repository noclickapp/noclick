## oracle_field_service_bearer (Oracle Field Service)
name: Bearer token
line: Paste a bearer token from Oracle Field Service.
from: docs.oracle.com
  Deployment host Label — The exact environment label before .fs.ocs.oraclecloud.com. HTTPS only; deprecated etadirect hosts and Fusion IAM endpoints are not supported.
  Supplied OAuth bearer token — A token issued for this deployment/application by the documented Field Service token service. No automatic mint, JWT assertion or refresh is performed.
  Actual token expiry (optional) — Supply the actual timezone-qualified expiry if known. The sample expires_in=3600 is not assumed. Without this, expiration is known only when the provider rejects the token.
