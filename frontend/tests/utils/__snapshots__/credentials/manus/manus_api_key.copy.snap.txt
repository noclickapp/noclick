## manus_api_key (Manus)
name: API key
line: Paste an API key from Manus.
how: In Manus Developers settings, create an API key and paste it here. The key grants full access to your Manus account. NoClick sends it in x-manus-api-key and checks the account with the read-only user.me endpoint.
