## hjarni_api_token (Hjarni)
name: API token
line: Paste an API token from Hjarni.
how: In Hjarni, open Settings > Connections and create an API token. Choose the folders and Read or Write access your workflow needs, then paste the token here without the Bearer prefix. NoClick checks the account with GET /me. Restricted tokens can access only their granted folders; some account-wide operations require full access.
