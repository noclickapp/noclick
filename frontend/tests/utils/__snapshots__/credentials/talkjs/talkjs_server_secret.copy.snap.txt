## talkjs_server_secret (Talkjs)
name: Server secret
line: Paste a server secret from Talkjs.
how: Supply the existing app ID and associated server secret. Native backend uses installed PyJWT to sign a fresh 30-second HS256 admin token per REST request, iss=app ID and tokenType=admin, without sub. Tokens remain in memory and never appear in frontend code or output. Admin credentials have full app data access; native operation allowlisting does not reduce provider rights. No environment fallback, login, key creation/rotation or public catalog identity proof. Direct secret Bearer authentication is legacy and not used.
from: talkjs.com
