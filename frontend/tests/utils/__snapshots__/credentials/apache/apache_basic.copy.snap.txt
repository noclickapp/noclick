## apache_basic (Apache)
name: Airflow username and password
line: Paste an Airflow username and password from Apache.
how: Connect an Airflow 2.x deployment with Basic API authentication enabled. Enter its HTTPS API root, username and password. Ask your Airflow administrator to enable the Basic authentication backend and grant the DAG, run, variable or pool permissions your workflow needs.
from: airflow.apache.org
  API Root — HTTPS API root, for example https://airflow.example.com/api/v1. An origin alone is expanded to /api/v1.

  Password
