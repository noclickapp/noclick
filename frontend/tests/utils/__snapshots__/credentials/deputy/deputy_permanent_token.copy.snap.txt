## deputy_permanent_token (Deputy)
name: Permanent token
line: Paste a Permanent token from Deputy.
how: Paste a Deputy permanent token and your Deputy workplace URL, such as https://your-workplace.au.deputy.com. In Deputy, open /exec/devapp/oauth_clients, add an OAuth client, save it, and select Get an Access Token. Requests use Bearer authentication; the token's existing user permissions control access. Connecting reads your workplace locations.
from: developer.deputy.com
  Workplace URL — HTTPS origin of your Deputy workplace, including its region; no API path.
  Permanent token
