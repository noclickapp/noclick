## turbot_pipes_api_token (Turbot Pipes)
name: API token
line: Paste an API token from Turbot Pipes.
how: In Turbot Pipes, open Your Profile → Advanced → Credentials & Access and click New Token. Paste the token without the Bearer prefix. The token must have access to the organization workspaces you choose. NoClick checks your own workspace list; this does not prove permission to write every resource.
