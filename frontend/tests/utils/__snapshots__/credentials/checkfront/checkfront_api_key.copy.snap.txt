## checkfront_api_key (Checkfront)
name: API key
line: Paste an API key from Checkfront.
how: In Checkfront, open Manage > Developer and create a token-pair application. Paste its API key and API secret, plus your tenant URL (for example https://your-company.checkfront.com). Migrated accounts can use their manage.na1.bookingplatform.app or manage.eu1.bookingplatform.app URL. API access requires an eligible paid account. The pair is sent using HTTP Basic authentication. Use a credential with permission for the selected operations.
from: api.checkfront.com
