## voiceflow_pat (Voiceflow)
name: Personal access token
line: Paste a personal access token from Voiceflow.
how: Create a personal access token under Voiceflow Settings > Access tokens. Supply its existing workspace/project IDs and environment alias. Current vfp_ tokens act with your account's access across its workspaces and expire; rotate manually before expiry. This node binds knowledge operations to the supplied project/environment and verifies current returned metadata. A returned project name identifies that project, not a human principal or universal write entitlement.
from: voiceflow.com
  Personal access token
  Workspace ID
  Project ID — Find the existing project ID under Settings > General > Metadata.
  Knowledge Environment Alias — An existing environment alias such as main. No environment is created or published.
