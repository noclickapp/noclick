## visualstudio_token (Visualstudio)
name: Access token
line: Paste an access token from Visualstudio.
how: Paste an existing VSOnline user JWT access token, without the Bearer prefix. The published API accepts bearer tokens; this connection does not create or refresh them. NoClick sends it only to online.visualstudio.com. Use a token authorized for the environments you want to manage.
from: online.visualstudio.com
