## syncro_api_token (Syncro)
name: API token
line: Paste an API token from Syncro.
how: In Syncro, open Admin > API - API Tokens and create a Custom Permissions token. Paste it with your account subdomain. Grant only the customer, ticket, invoice and asset permissions your operations need. NoClick verifies the token with the current-user read; this does not prove every write permission.
from: docs.syncrosecure.com
  Account subdomain — The part before .syncromsp.com in your Syncro account URL.
  API token
