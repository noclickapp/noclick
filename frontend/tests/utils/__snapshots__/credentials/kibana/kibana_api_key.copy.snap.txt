## kibana_api_key (Kibana)
name: API key
line: Paste an API key from Kibana.
how: Enter your public HTTPS Kibana origin and paste an encoded Elastic API key from Stack Management > API Keys, without the ApiKey prefix. Grant the Kibana privileges needed for your operations. Data views, rules and connectors use the default space. The connection check lists your accessible spaces; it does not verify write permissions. Reverse-proxy base paths are not supported.
from: elastic.co
  Kibana URL — Public HTTPS origin, for example https://my-deployment.kb.us-east-1.aws.elastic.cloud. Include a port if needed; omit paths and /app.
  Encoded API key
