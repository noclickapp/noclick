## chatwoot_api_token (Chatwoot)
name: API token
line: Paste an API token from Chatwoot.
how: In Chatwoot, open Profile Settings and copy your API access token. Enter the account ID from your /app/accounts/<id> URL. Use https://app.chatwoot.com for Chatwoot Cloud, or your self-hosted HTTPS origin. The token uses your user's permissions; routing and account lists may require an administrator.
from: developers.chatwoot.com
  API token
  Account ID
  Chatwoot URL (optional) — Exact HTTPS origin of Chatwoot Cloud or your self-hosted instance.
