## shopvox_api_token (Shopvox)
name: API token
line: Paste an API token from Shopvox.
how: Paste your Shopvox account UUID and existing REST auth token (accountID and authToken from Shopvox). The token belongs to a user and account. If it expires, replace it here. API access depends on your plan; jobs listing must be enabled by Shopvox support. NoClick verifies the connection using the authenticated user and business name.
from: developers.shopvox.com
  Account ID — The accountID UUID supplied by Shopvox.
  Auth token
