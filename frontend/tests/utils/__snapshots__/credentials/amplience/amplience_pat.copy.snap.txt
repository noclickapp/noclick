## amplience_pat (Amplience)
name: Personal access token
line: Paste a personal access token from Amplience.
how: Supply an existing personal access token and known hub ID. Current docs admit user/organization PATs that do not expire but can be deleted. Bearer header only at api.amplience.net/v2/content. No PAT creation, exchange, refresh or principal/organization discovery. Entitlement and functional/ACL permissions need independent qualification.
from: amplience.com
  Already Issued token
  Independently Known Hub ID — A protected resource binding, not proof of token principal or organization ownership.
