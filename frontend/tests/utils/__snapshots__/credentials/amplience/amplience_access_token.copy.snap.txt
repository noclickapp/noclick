## amplience_access_token (Amplience)
name: Access token
line: Paste an access token from Amplience.
how: Supply an already issued client-credentials access token, its independently known timezone-aware expiry and hub ID. Documented issued tokens last 300 seconds. This node never exchanges a client key/secret or refreshes a token; replace an expired saved token through the credential UI. Bearer header only, not a client secret/PAT substitution.
from: amplience.com
  Already Issued token
  Independently Known Hub ID — A protected resource binding, not proof of token principal or organization ownership.
  Actual Issued token expiry (ISO8601)
