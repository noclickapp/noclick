## altoviz_api_key (Altoviz)
name: API key
line: Paste an API key from Altoviz.
how: In Altoviz, open Settings, then API access, create a key and paste it here. NoClick sends it in the X-API-KEY header to api.altoviz.com. The connection check reads your customers.
