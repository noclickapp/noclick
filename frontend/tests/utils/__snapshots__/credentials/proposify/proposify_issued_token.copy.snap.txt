## proposify_issued_token (Proposify)
name: Issued OAuth token
line: Paste an Issued OAuth token from Proposify.
how: Supply an already-issued Proposify Connect Bearer token and its actual granted scopes. No OAuth client registration, authorization, exchange or refresh is automated. Expiry/client/account absence is unknown, not filled from an app/global client. API enablement/paid entitlement remains unverified. Draft mutations require an expected account ID observed from a protected V3 object. User list is account users, not token-user identity.
from: apidocs.proposify.com
  Already-Issued Proposify access token
  Actual Granted Operation Scopes — Record actual applicable read/write permissions, not requested/guessed scopes. At least one read permission is needed for protected connect proof.
  Actual Issuing client ID (if known) (optional)
  Expected Proposify account ID (if known) (optional) — Actual numeric account.id observed on an accessible V3 object. Optional for reads; required locally for draft mutations. This is a resource/account binding, not proof of the token principal.
  Actual Issuer token expiry (if known) (optional) — Timezone-aware known expiry only. Unknown expiry is not a non-expiring token. Replace expired/rejected issued tokens; this credential does not refresh.
