## carbone_api_token (Carbone)
name: API token
line: Paste an API token from Carbone.
how: Copy your API token from your Carbone account home page and paste it here without the Bearer prefix. Test tokens generate watermarked PDFs only; production tokens support other formats and consume your Carbone credits. NoClick checks access by listing your templates.
