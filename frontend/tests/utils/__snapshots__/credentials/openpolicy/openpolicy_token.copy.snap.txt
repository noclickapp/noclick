## openpolicy_token (Openpolicy)
name: Agent token
line: Paste an Agent token from Openpolicy.
how: Enter your OPA instance's HTTPS origin and paste a bearer token accepted by its authorization policy. The instance must enable --authentication=token and authorize the APIs you use. NoClick lists loaded policies to check the connection; OPA has no user profile API.
from: openpolicyagent.org
  Instance URL — Exact HTTPS origin, including the port if needed; for example https://opa.example.com:8181.
  Bearer token
