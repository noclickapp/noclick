## swarmsyncai_api_key (Swarmsyncai)
name: Agent API key
line: Paste an Agent API key from Swarmsyncai.
how: Paste the agentApiKey issued when you registered your SwarmSync agent. The key acts as that agent, including after a human claims it. Keys expire after 30 days; paste a renewed key when needed. Human-only billing and payout routes are not included.
