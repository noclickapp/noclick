## nutshell_api_key (Nutshell)
name: API key
line: Paste an API key from Nutshell.
how: Create an API key under Setup → API keys. Enter the email address of the Nutshell user who owns the key. Nutshell uses the email as the HTTP Basic username and the API key as its password.
from: app.nutshell.com
  Nutshell user email
  Nutshell API key
