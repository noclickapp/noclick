## loyverse_token (Loyverse)
name: Access token
line: Paste an access token from Loyverse.
how: Create a personal access token in Loyverse Back Office → Integrations → Access tokens. Paste the token only. Grant read access for the resources you use and write access for customer, category or supplier saves. Store reads verify access to your account; they do not verify write permissions.
from: r.loyverse.com
