## langbase_api_key (Langbase)
name: API key
line: Paste an API key from Langbase.
how: Paste a Langbase user or organization API key with access to the pipes, memories and threads you need. Use an account key rather than a pipe-only key so NoClick can list your pipes to check the connection. LLM operations use the provider keys configured in Langbase.
