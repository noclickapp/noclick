## custify_api_key (Custify)
name: API key
line: Paste an API key from Custify.
how: Copy your API key and API URL from Custify Settings → Developers → API Key. The key grants read and write access. Paste only the key, without Bearer.
from: app.custify.com
  API key
  API URL (optional) — The HTTPS API origin shown beside your key in Custify.
