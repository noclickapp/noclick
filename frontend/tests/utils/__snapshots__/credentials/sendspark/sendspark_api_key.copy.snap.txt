## sendspark_api_key (Sendspark)
name: API key
line: Paste an API key from Sendspark.
how: Copy your API key and API secret from Sendspark's API Credentials page (account menu → API Credentials). Paste the values without header names. NoClick uses them to identify your workspace and run the operations you select.
