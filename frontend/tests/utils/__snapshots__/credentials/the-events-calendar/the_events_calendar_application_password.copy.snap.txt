## the_events_calendar_application_password (The Events Calendar)
name: Application password
line: Paste an application password from The Events Calendar.
how: Enter your WordPress site URL and username, then paste an application password from Users → Profile → Application Passwords (WordPress 5.6+ over HTTPS). Use an account allowed to edit the events, venues, organizers and terms you automate. The connection read shows public site events; it establishes reachability, not account identity or write permissions.
from: developer.wordpress.org
  WordPress site URL — HTTPS WordPress installation URL, e.g. https://example.com or https://example.com/blog; omit /wp-admin and /wp-json.
  WordPress username
  Application password
