## amazing_marvin_api_token (Amazing Marvin)
name: API token
line: Paste an API token from Amazing Marvin.
how: Open Amazing Marvin's API strategy settings and paste API_TOKEN (the limited-access token). NoClick sends it as X-API-Token to serv.amazingmarvin.com. Full-access tokens are not needed. Schedule requests at least one minute apart; Marvin limits queries to 1,440 per day and bursts to one every three seconds.
from: app.amazingmarvin.com
