## linkace_user_token (Linkace)
name: User API token
line: Paste an user API token from Linkace.
how: Supply an existing USER API token and one public HTTPS instance. Bearer header only, fixed /api/v2. No system/admin token, user lookup, token issue/refresh, Basic/OAuth or host fallback. User-token kind is a supplied declaration, not introspected identity; list access proves reachability only. Permissions, entitlement and installed v2 compatibility are unknown.
from: linkace.org
  Existing user API token
  Public HTTPS LinkAce instance origin
