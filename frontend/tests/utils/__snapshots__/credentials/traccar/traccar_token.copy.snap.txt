## traccar_token (Traccar)
name: API token
line: Paste an API token from Traccar.
how: Paste an existing Traccar bearer token and your server HTTPS origin (without /api). Generate a token in your Traccar account settings. The token has your account permissions.
from: traccar.org
  Server URL — HTTPS origin of your Traccar server, for example https://demo.traccar.org
  API token
