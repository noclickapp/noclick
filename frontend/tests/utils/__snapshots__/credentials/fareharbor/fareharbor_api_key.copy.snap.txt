## fareharbor_api_key (Fareharbor)
name: API keys
line: Enter the application key, user key and company shortname for Fareharbor.
how: Paste the application key and user key issued by Fareharbor, and the company shortname from your Fareharbor dashboard URL. API access must be enabled by Fareharbor. These keys are sent only to fareharbor.com.
from: developer.fareharbor.com
  Application key
  User key
  Company shortname — Company shortname in your Fareharbor dashboard URL, for example hawaiianadventures.
