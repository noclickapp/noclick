## boldsign_client_credentials (Boldsign)
name: OAuth client
line: Enter the Issued credential environment, client ID, client secret and Requested API Scopes for Boldsign.
how: Supply an existing US-region machine client ID and secret, actual Sandbox/Live label, and explicit API scopes. Tokens are obtained at account.boldsign.com with client_credentials and sent only to api.boldsign.com. No callback, consent or refresh token. Checking the protected document list proves reachability only; provider permissions and saved ID allowlists remain authoritative.
from: developers.boldsign.com
  Issued credential environment — Choose the actual issued credential environment. This label does not switch or prove the provider environment.
  Actual credential expiry, if set (optional) — Use the actual API key or client secret validity date when configured. No lifetime or renewal is assumed.
  Allowed document IDs (optional) — Enter a JSON list of exact resource IDs, for example ["existing-id"]. An empty list permits no selected resources.
  Allowed template IDs (optional) — Enter a JSON list of exact resource IDs, for example ["existing-id"]. An empty list permits no selected resources.
  Allowed owned contact IDs (optional) — Enter a JSON list of exact resource IDs, for example ["existing-id"]. An empty list permits no selected resources.
  Allowed owned contact group IDs (optional) — Enter a JSON list of exact resource IDs, for example ["existing-id"]. An empty list permits no selected resources.
  Allow contact creation (optional) — Enter true to opt in or false to decline. Creates an organization contact only. New IDs still require explicit saved scope before later reads or changes.
  Client ID
  Client secret
  Requested API Scopes — Enter explicit scopes separated by single spaces (or supply a structured list). Connection checks require Documents.All; template reads require Templates.Read or All, tag changes also require Write or All. Contact permissions remain provider-enforced; no undocumented scope is invented.
