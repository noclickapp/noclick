## eduzz_access_token (Eduzz)
name: Access token
line: Paste an access token from Eduzz.
how: Paste an existing application access token for your Eduzz account, without the Bearer prefix. Create an app and enable the permissions needed by your actions in the Eduzz Developer Console. Application authentication is documented. Personal test tokens are for development only. Webhook triggers also need webhook_read and webhook_write permissions.
from: console.eduzz.com
