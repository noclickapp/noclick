## conjur_api_key (Conjur)
name: API key
line: Paste an API key from Conjur.
how: Enter your Conjur HTTPS server origin, account, login and existing API key. For a host, use host/<host-id> as the login. NoClick exchanges the key for a short-lived access token for each execution and verifies the connection with WhoAmI. Permissions remain controlled by your Conjur policy. Secret reads and loaded policies can return sensitive values.
from: github.com
  Server URL — Exact HTTPS origin of your Conjur server, e.g. https://conjur.example.com.
  Account
  Login — User ID, or host/<host-id>. Enter the original value, without URL encoding.
  API key
