## investorbase_api_key (Investorbase)
name: API key
line: Paste an API key from Investorbase.
how: Copy your subscriber API key from Account → Integrations. For an enterprise key issued by Investorbase, choose Enterprise and enter your registered end-user ID for property data requests. Enterprise account management needs an enterprise key. NoClick reads usage (subscriber) or account details (enterprise) to verify the connection.
from: investorbase.com
  API key
  Key kind (optional)
  Enterprise end-user ID (optional) — Your registered user_id. Required for property data calls with an enterprise key; omitted for subscriber keys and account management.
