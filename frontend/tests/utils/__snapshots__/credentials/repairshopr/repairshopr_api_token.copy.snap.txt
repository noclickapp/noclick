## repairshopr_api_token (Repairshopr)
name: API token
line: Paste an API token from Repairshopr.
how: In Repairshopr, open your user profile and copy an API key with permissions for your workflow. Paste the key and your account subdomain below. NoClick sends the key as a Bearer token and checks the current user and customers to verify the connection.
from: api-docs.repairshopr.com
  Account subdomain — The part before .repairshopr.com in your account URL. You can also paste the full account URL.
  API token
