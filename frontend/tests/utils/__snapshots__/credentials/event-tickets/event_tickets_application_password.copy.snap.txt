## event_tickets_application_password (Event Tickets)
name: Application password
line: Paste an application password from Event Tickets.
how: In your WordPress admin, open Users → Profile → Application Passwords and create a password. Enter the site URL, your username and that application password. Your user needs permission to read attendees. Requires WordPress 5.6 or later and Event Tickets. Cart actions use a new session and do not place an order.
from: developer.wordpress.org
  WordPress site URL — HTTPS site root, including a WordPress installation subdirectory if needed.
  WordPress username
  Application password
