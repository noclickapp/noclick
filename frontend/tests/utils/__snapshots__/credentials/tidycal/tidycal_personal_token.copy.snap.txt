## tidycal_personal_token (Tidycal)
name: Personal access token
line: Paste a personal access token from Tidycal.
how: In Tidycal, open Integrations → Advanced → Manage API keys → Personal tokens. Create a personal access token and paste it here. The REST API is available on every plan. Use a personal token for the REST API; MCP connection tokens cannot access it.
from: tidycal.com
