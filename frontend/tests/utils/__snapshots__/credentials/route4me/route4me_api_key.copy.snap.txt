## route4me_api_key (Route4me)
name: API key
line: Paste an API key from Route4me.
how: Copy your Route4me API key from My Account > API. Paste only the key. NoClick sends it as the api_key query parameter to wh.route4me.com. Connecting reads one page of your address book; individual operations need the corresponding account features and permissions.
