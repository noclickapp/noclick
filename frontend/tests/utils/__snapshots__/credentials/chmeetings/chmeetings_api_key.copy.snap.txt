## chmeetings_api_key (Chmeetings)
name: API key
line: Paste an API key from Chmeetings.
how: Copy your Chmeetings API key from Settings → Integrations → API Integration (Get API). Paste only the key. NoClick sends it in the apikey header to api.chmeetings.com. Connection testing reads your groups; it does not verify permission for every operation.
from: help.chmeetings.com
  API key
