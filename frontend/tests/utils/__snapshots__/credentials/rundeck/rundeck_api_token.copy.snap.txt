## rundeck_api_token (Rundeck)
name: API token
line: Paste an API token from Rundeck.
how: Paste an existing API token from your Rundeck User Profile and the public HTTPS server URL. Use a token whose roles allow the selected jobs and projects. NoClick sends X-Rundeck-Auth-Token over HTTPS and checks your user profile. API version 60 is required.
from: docs.rundeck.com
  Server URL — Your public HTTPS Rundeck server, for example https://rundeck.example.com. Include a deployment context path if used; omit /api/60.
  API token
