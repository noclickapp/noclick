## foursquare_service_key (Foursquare)
name: Service API key
line: Paste a service API key from Foursquare.
how: In your Foursquare Developer project, open Settings and generate a Service API Key. Paste that key here without the Bearer prefix. Use a key with Places API access. NoClick checks the key by reading suggested edits submitted using it; this does not verify a personal Foursquare identity.
from: foursquare.com
  Service API key
