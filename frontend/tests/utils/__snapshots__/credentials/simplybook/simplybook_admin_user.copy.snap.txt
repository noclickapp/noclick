## simplybook_admin_user (Simplybook)
name: Simplybook.me admin user
line: Enter the company login, admin user login and API user key or password for Simplybook.
how: Use your existing admin login and an API User Key from Settings > API User Keys (recommended), or its genuine password. Password login may require 2FA, which this node does not bypass. The admin token is minted over HTTPS for each operation; there is no OAuth callback or refresh token. Management operations require the returned admin role.
from: simplybook.me
  Company login — Existing company's login, not its booking URL.
  Admin user login
  API user key or password
