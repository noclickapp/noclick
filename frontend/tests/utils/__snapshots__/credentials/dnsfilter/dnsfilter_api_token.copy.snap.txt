## dnsfilter_api_token (Dnsfilter)
name: API token
line: Paste an API token from Dnsfilter.
how: Get an API token from Account Settings in the Dnsfilter dashboard. Paste the token itself, without an Authorization or Bearer prefix. NoClick sends it only to api.dnsfilter.com. The token needs permission for the operations you use.
from: app.dnsfilter.com
  API token
