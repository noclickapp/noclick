## plaud_user_token (Plaud)
name: Embedded user token
line: Paste an Embedded user token from Plaud.
how: Paste an existing Embedded user access token, not a partner token. Choose the token's region and enter a device serial number for the read-only binding check. Replace expired tokens yourself. Binding reads prove token acceptance, not device ownership.
from: docs.plaud.ai
  Access token
  API region (optional)
  Device serial number — A device SN for the read-only connection check (881 = Note Pro, 882 = NotePin S).
