## spydra_api_key (Spydra)
name: API key
line: Paste an API key from Spydra.
how: In your Spydra Network, open API Keys and create or copy an API key. Paste the network's Asset Tokenization REST API base URL, including /tokenize/<chaincodeccid>, from the app's REST API page. The key is network-specific. NoClick sends it as X-API-KEY to this deployment; use only your trusted Spydra deployment URL.
