## pocketsmith_developer_key (Pocketsmith)
name: Developer key
line: Paste a developer key from Pocketsmith.
how: In Pocketsmith, open Profile > Security & integrations > Manage developer keys. Create a key for your own account and paste it here. The key can read and change your financial data. NoClick sends it only to api.pocketsmith.com in the X-Developer-Key header.
