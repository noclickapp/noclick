## wowza_access_token (Wowza)
name: Access token
line: Paste an access token from Wowza.
how: Paste your Wowza Video API access token from the Wowza Video account. NoClick sends it as a Bearer token to api.video.wowza.com. The connection check lists your live streams; allow the read and write permissions needed for your automation.
