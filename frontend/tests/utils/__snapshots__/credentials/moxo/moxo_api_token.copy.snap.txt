## moxo_api_token (Moxo)
name: Personal access token
line: Paste a personal access token from Moxo.
how: Create a personal access token in Moxo Settings → API keys. Paste the token without Bearer and select your organization's region. Personal tokens act as you and expire by default. Organization API keys cannot perform all these operations; use a personal token.
from: developers.moxo.com
  Personal access token
  API region (optional) — Use the region where your Moxo organization lives; tokens work only there.
