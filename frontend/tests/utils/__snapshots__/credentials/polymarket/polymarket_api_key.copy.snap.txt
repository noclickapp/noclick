## polymarket_api_key (Polymarket)
name: CLOB API key
line: Paste a CLOB API key from Polymarket.
how: Paste your existing CLOB API key, secret and passphrase, and the signer wallet address used to create them. These are CLOB L2 credentials, not Builder or Relayer keys. Use the official SDK to create or derive them with your wallet first. Never paste a wallet private key. NoClick signs account requests locally with HMAC-SHA256. Public market reads do not verify a credential.
from: docs.polymarket.com
