## fleetio_api_key (Fleetio)
name: API key
line: Paste an API key from Fleetio.
how: In Fleetio, open Settings → API Keys. Paste an API key and the Account Token for the account you want to automate. The key's permissions must allow each selected operation. NoClick checks access by listing that account's vehicles.
from: secure.fleetio.com
  API key
  Account token
