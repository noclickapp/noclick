## commusoft_api_key (Commusoft)
name: API key
line: Paste an API key from Commusoft.
how: An administrator can create an API key in Commusoft Settings → Private applications. Paste the key and choose the business region. Your subscription must support private applications.
from: developer.commusoft.com
  API key — Paste the private application's API key without the Bearer prefix.
  Region (optional) — UK, or US for a US/Canada business.
