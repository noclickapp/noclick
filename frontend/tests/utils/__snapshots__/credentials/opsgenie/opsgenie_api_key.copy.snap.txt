## opsgenie_api_key (Opsgenie)
name: API key
line: Paste an API key from Opsgenie.
how: In Opsgenie, open Settings > Integrations and add an API integration. Copy its API key. Enable read access and the write permissions your workflow needs. Choose the region of your Opsgenie account.
from: docs.opsgenie.com
  API key — Paste the API integration key without the GenieKey prefix.
  Region (optional) — Use EU for an account hosted in the European region; otherwise use US.
