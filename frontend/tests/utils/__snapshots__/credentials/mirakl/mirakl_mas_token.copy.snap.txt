## mirakl_mas_token (Mirakl)
name: Platform
line: Enter the MAS access token, Marketplace URL, Marketplace ID, Role and Bound Shop ID for Mirakl.
from: developer.mirakl.com
  MAS access token — Already issued Mirakl Authentication System OAuth2 access token. Bearer header only; legacy API keys and Connect tokens are not supported.
  Marketplace URL — Exact public HTTPS origin from the MAS token response; not the Connect or auth service.
  Marketplace ID — Tenant ID from the same MAS token response. This supplied value is a binding, not an independently proved account identity.
  Role — Role of the granted Platform resource. Seller operations use the token's single selected shop.
  Bound Shop ID — Seller: exact shop_id from MAS. Operator: one existing shop to restrict order and product-offer reads.
  Expiry (Unix Seconds) (optional) — Optional actual expiry from the issued grant. No TTL is guessed; expired supplied tokens must be replaced. This node does not mint or refresh grants.
