## docupilot_api_token (Docupilot)
name: API token
line: Paste an API token from Docupilot.
how: In Docupilot Settings > API Settings, create a key and secret and base64 encode key:secret as described in the API guide. Paste that encoded token without an authorization prefix. The published V2 schema specifies Authorization: Basic. Copy the workspace ID from Settings > Workspace details. Requests go to the US API server.
from: help.docupilot.app
  Encoded API token
  Workspace ID
