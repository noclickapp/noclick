## unleash_token (Unleash)
name: Access token
line: Paste an access token from Unleash.
how: In Unleash, open Profile > View profile settings > Personal API tokens and create a token. Paste it with your instance base URL. Service account tokens also work. Permissions follow the token's user or service account; allow project reads to verify the connection, and the write permissions needed by your workflow. Backend and frontend SDK tokens cannot manage flags.
from: docs.getunleash.io
  Instance URL — Public HTTPS base URL before /api, e.g. https://example.app.unleash-hosted.com. A self-hosted path prefix is supported.
  Access token — Paste the complete personal access or service account token, without a Bearer prefix.
