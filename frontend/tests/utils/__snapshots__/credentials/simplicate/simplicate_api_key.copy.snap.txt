## simplicate_api_key (Simplicate)
name: API key
line: Paste an API key from Simplicate.
how: In Simplicate, open General settings → API and create a token for a user with the required permissions. Paste its key and secret separately, and enter your Simplicate subdomain. The token inherits that user's rights.
from: developer.simplicate.com
  Subdomain — The company part of https://company.simplicate.app; enter only company.
