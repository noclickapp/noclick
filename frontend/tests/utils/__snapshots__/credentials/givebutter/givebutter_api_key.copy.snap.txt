## givebutter_api_key (Givebutter)
name: API key
line: Paste an API key from Givebutter.
how: In Givebutter, open Settings → Developers → API and copy your API key. Paste the key without the Bearer prefix. NoClick sends it only to api.givebutter.com. Access to your campaigns is checked when connecting.
from: help.givebutter.com
