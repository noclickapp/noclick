## salesmsg_personal_access_token (Salesmsg)
name: Personal access token
line: Paste a personal access token from Salesmsg.
how: In Salesmsg Settings > Developer > Personal Access Tokens, create a token and paste it here. Allow contacts, conversations, messages and tags read/write, teams read and users read for the operations you use. The connection check reads your account's tags and requires tags:read.
from: app.salesmessage.com
