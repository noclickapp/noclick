## teachable_supplied_oauth (Teachable)
name: Supplied user OAuth v2
line: Enter the Existing v2 user OAuth access token and Expected user ID for Teachable.
from: docs.teachable.com
  Expected Course ID (optional) — Optional actual course anchor. A protected course read must match; this is not a school identity claim.
  Allow management Writes (optional) — Off by default. Allows student creation, name update and enrollment/removal. These change real school records and access; notification suppression and billing effects are not promised.
  Existing v2 user OAuth access token
  Expected user ID — Actual Teachable user ID. Current-user me must match before resource requests; do not use an Admin API key here.
  Expires At (optional) — Actual token expiry when known; no lifetime is invented for supplied tokens.
  Refresh token (optional)
  Client ID (optional) — Actual existing v2 school-registered OAuth app, only needed with its refresh token.
  Client secret (optional)
