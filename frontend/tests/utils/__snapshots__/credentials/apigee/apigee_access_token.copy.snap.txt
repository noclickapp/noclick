## apigee_access_token (Apigee)
name: Registry API access token
line: Paste a Registry API access token from Apigee.
how: Paste a Google Cloud access token with cloud-platform scope and Registry permissions on your project. Enter the project ID and location (usually global). Access tokens expire; replace an expired token here. NoClick reads your project's APIs to check the connection.
from: cloud.google.com
  Access token
  Google Cloud project ID
  Location (optional)
