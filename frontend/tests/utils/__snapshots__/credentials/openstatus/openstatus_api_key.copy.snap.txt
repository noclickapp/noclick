## openstatus_api_key (Openstatus)
name: API key
line: Paste an API key from Openstatus.
how: Supply an existing account-authorized API key. Prefer a read-only ['read'] key from Settings → General → API Keys. Sent only as x-openstatus-key to fixed public HTTPS api.openstatus.dev/rpc. This node does not create, introspect, refresh or revoke keys. Protected reads establish reachability, not actor/workspace identity, key scope verification or ownership.
from: openstatus.dev
