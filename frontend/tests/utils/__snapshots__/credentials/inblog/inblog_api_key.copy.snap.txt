## inblog_api_key (Inblog)
name: API key
line: Paste an API key from Inblog.
how: In Inblog, open Settings → API Keys and create a key for your blog. Select the scopes needed by your operations: posts:read/write/delete, tags:read/write/delete, authors:read, blogs:read, redirects:read/write, forms:read and form_responses:read. Paste the key only. NoClick checks the connected blog with GET /me; that check does not prove every operation's permissions.
