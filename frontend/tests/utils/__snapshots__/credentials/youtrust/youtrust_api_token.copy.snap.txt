## youtrust_api_token (Youtrust)
name: API token
line: Paste an API token from Youtrust.
how: Paste your Youtrust API key. Choose the environment the key was created for. NoClick sends it as a Bearer token to the API server published by Youtrust (api.yousign.app or api-sandbox.yousign.app).
from: developers.youtrust.com
  API token
  Environment (optional)
