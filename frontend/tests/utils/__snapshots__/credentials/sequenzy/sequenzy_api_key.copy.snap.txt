## sequenzy_api_key (Sequenzy)
name: API key
line: Paste an API key from Sequenzy.
how: In Sequenzy, open Settings → API Keys & SMTP and create a workspace API key. Paste the key only. Choose the permissions needed for your actions: subscriber reads/writes/deletes, tags, lists and sequences; event-triggering and enrollment need explicit delivery permissions. Use a workspace key (seq_live_ or legacy ek_), since account keys can implicitly select another workspace. Connection checks read account info and do not prove write permissions.
