## etermin_api_key (Etermin)
name: API keys
line: Enter the Public API key and private secret key for Etermin.
how: Copy the public API key and private secret key from your Etermin account settings under Configuration → Integration – API → API. NoClick signs each request with a fresh salt and HMAC-SHA256. Both keys are required. Connecting reads your account's calendars.
