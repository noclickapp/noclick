## predictleads_api_key_token (PredictLeads)
name: API key and token
line: Paste an API key and token.
how: Enter the supplied key and token. Subscription checks use no credits; company and signal reads consume credits. Approved companies are a local workflow restriction, not vendor OAuth scopes.
  API key
  API token
  Approved Companies — JSON string array of company UUIDs or bare domains. The picker uses this saved list without spending credits. Maximum 50 is a NoClick limit.
  Allow Credit-Consuming Reads (optional) — Permit this node to request company and signal datasets. Each company witness and dataset page costs one credit according to the current API spec.
