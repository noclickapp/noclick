## waiverfile_api_key (Waiverfile)
name: API key
line: Paste an API key from Waiverfile.
how: In your Waiverfile admin, open Settings > API Keys. Paste the API key and its site ID (GUID). The key must belong to that site.
from: waiverfile.com
  API key
  Site ID — Site GUID belonging to this API key.
