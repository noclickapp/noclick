## coolify_token (Coolify)
name: Token
line: Paste a token from Coolify.
how: Create a team-scoped Coolify API token. Paste the entire ID|secret value. Use read for metadata and write for project/environment changes; write also requires the owner's/admin's current role. No deploy, read:sensitive or root ability is needed. Self-host API access must already be enabled and publicly reachable over HTTPS; this integration cannot adjust IP rules or trust private addresses. The selected team ID is verified against /teams/current, not public health. Team proof does not establish human identity or every permission.
from: coolify.io
  Coolify HTTPS origin (optional) — Canonical lowercase public HTTPS origin only. An intentional non-default HTTPS port is allowed; no API path or trailing slash.
  Bound Coolify team ID — Positive ID of the team that issued this token.
  Coolify API token
