## responsys_auth_token (Responsys)
name: Auth token
line: Paste an auth token from Responsys.
how: Supply an existing issued token and its exact account endpoint. This is not an IDCS OAuth token or a login cookie. Expired tokens require a newly issued pair.
from: docs.oracle.com
  Issued account endpoint — The exact REST endPoint returned with this authToken; login and AFTM hosts are not account REST origins.
  Auth token — Raw issued Responsys authToken, without Bearer prefix. Tokens expire after two hours.
