## responsys_password (Responsys)
name: API password
line: Paste an API password from Responsys.
how: Supply your provisioned API username and password, Oracle login origin and previously issued account endpoint. The issued token renews automatically.
from: docs.oracle.com
  Issued account endpoint — The exact REST endPoint returned with this authToken; login and AFTM hosts are not account REST origins.
  Login origin — The exact Oracle login2/login5/login.rsys8/login.rsys9 or account global-routing REST origin.
