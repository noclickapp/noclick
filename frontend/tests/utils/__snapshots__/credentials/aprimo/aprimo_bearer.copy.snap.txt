## aprimo_bearer (Aprimo)
name: DAM bearer token
line: Paste a DAM bearer token from Aprimo.
how: Supply an existing Aprimo DAM bearer token, its single tenant label, and one readable classification UUID. No token exchange or refresh is performed. DAM API entitlement and API scope must already be granted. The connection proves selected resource reachability, not account identity.
from: developers.aprimo.com
  Bearer token
  Tenant — Single label before .dam.aprimo.com; no URL or path
  Bound Classification ID — Readable classification UUID; all record and schema reads stay bound to this classification
