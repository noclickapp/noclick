## wikimedia_access_token (Wikimedia)
name: Access token
line: Paste an access token from Wikimedia.
how: Create an owner-only OAuth 2.0 client on Wikimedia Meta and paste its access token. Choose grants to read pages, edit existing pages, and create pages for the operations you use. For Wikidata keep the default wiki URL. For your own Wikibase use its HTTPS origin and a token issued for that wiki. Connect reads item Q24 and requires the API's authenticated username header; public item content alone never verifies the account. NoClick does not refresh this token; replace it if revoked.
from: meta.wikimedia.org
  Access token
  Wiki URL (optional) — HTTPS origin of Wikidata or your own Wikibase, e.g. https://www.wikidata.org
