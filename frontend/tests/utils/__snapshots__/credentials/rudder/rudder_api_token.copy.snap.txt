## rudder_api_token (Rudder)
name: API token
line: Paste an API token from Rudder.
how: In Rudder, open Administration → API Accounts and create an account with the permissions your operations need. Paste its token and your public HTTPS server origin. NoClick sends X-API-Token to that server and lists its managed nodes to check access. API accounts are separate from user accounts; the read does not identify a person.
from: docs.rudder.io
  Server URL — Public HTTPS origin, for example https://rudder.example.com. Omit /rudder/api/latest.
  API token
