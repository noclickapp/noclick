## signrequest_api_token (Signrequest)
name: API token
line: Paste an API token from Signrequest.
how: Create an API token in your Signrequest team's API settings and paste the token here. NoClick sends it to signrequest.com using Authorization: Token. Use a sandbox team's token for testing; production sends can incur Signrequest charges.
from: signrequest.com
