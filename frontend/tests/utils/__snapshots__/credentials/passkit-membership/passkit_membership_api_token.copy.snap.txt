## passkit_membership_api_token (Passkit Membership)
name: API token
line: Paste an API token from Passkit Membership.
how: In your PassKit project, open Settings → Pass APIs and generate a long-lived API token. Paste the token without the Bearer prefix. This token grants full, permanent account API access; keep it private and revoke it in PassKit when no longer needed. Select your account's API region from Developer Tools → API Region. NoClick lists your membership programs to check the connection.
from: help.passkit.com
  API token
  API region (optional) — Europe (pub1) or United States (pub2); use the region shown in PassKit Developer Tools.
