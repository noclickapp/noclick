## xama_hub_bearer_token (Xama Hub)
name: Bearer token
line: Paste a bearer token from Xama Hub.
how: Obtain an access token using your Open API Application ID and Secret as described in Xama's authentication guide. Paste the access_token without the Bearer prefix. Tokens expire; replace this token when Xama rejects it. Tenant ID is your Xama Hub client identifier, different from the OAuth Application ID.
from: platform.xamatech.com
  Tenant ID
  Access token
