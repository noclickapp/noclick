## ironclad_api_token (Ironclad)
name: Access token
line: Paste an access token from Ironclad.
how: Paste an existing Ironclad access token without the Bearer prefix. Replace it when it expires; NoClick does not refresh pasted tokens. Legacy access tokens are deprecated by Ironclad. For client-credentials or legacy tokens, enter the Ironclad user email whose permissions apply. For a personal user token, leave the email blank to use its own identity. Select the same region where the token was issued. A successful read verifies access to records, not all write permissions.
from: developer.ironcladapp.com
  Access token
  Act as user email (optional) — An existing Ironclad user email, required for client-credentials tokens. Omit for a personal user token.
  API region (optional) — Production, EU production, or demo.
