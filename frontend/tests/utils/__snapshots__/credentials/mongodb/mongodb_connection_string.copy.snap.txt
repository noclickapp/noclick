## mongodb_connection_string (MongoDB)
name: Connection string
line: Paste a connection string from MongoDB.
how: Go to MongoDB Atlas → Database → Connect → Drivers, copy the connection string, and replace <password> with your database user password. For self-hosted MongoDB use mongodb://user:pass@host:27017/.
from: cloud.mongodb.com
  Connection string — MongoDB URI, e.g. mongodb+srv://user:pass@cluster.mongodb.net/ or mongodb://localhost:27017/
