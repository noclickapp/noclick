## flutterwave_access_token (Flutterwave)
name: Access token
line: Paste an access token from Flutterwave.
how: Paste a Flutterwave v4 access token generated with your client credentials, and select its environment. Access tokens expire after 10 minutes: replace the token before running again after expiry. NoClick does not generate or refresh tokens. A v3 secret key does not work with this integration.
from: developer.flutterwave.com
  Access token
  Environment (optional)
