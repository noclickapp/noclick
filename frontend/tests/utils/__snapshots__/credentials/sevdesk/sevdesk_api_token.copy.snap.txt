## sevdesk_api_token (Sevdesk)
name: API token
line: Paste an API token from Sevdesk.
how: In Sevdesk, open Extensions > Integrations (Erweiterungen > Integrationen), reveal the API token for integrations and copy it. Paste the token itself, without an Authorization or Bearer prefix. NoClick sends it only to my.sevdesk.de. Listing your contacts checks the connection; this does not verify write permissions.
from: hilfe.sevdesk.de
  API token — Your Sevdesk administrator's API token.
