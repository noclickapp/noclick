## hitpay_api_key (Hitpay)
name: API key
line: Paste an API key from Hitpay.
how: Copy your business API key from the Hitpay dashboard under Settings > API Keys. Paste the key without a header prefix. Select the environment where the key was issued. NoClick sends it only to Hitpay's matching API host.
from: docs.hitpayapp.com
