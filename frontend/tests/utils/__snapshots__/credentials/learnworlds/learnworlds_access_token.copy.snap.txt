## learnworlds_access_token (Learnworlds)
name: Access token
line: Paste an access token from Learnworlds.
how: In your Learnworlds school, open Settings > Developers > API. Copy the API URL and Client ID, then copy an Access Token. API access requires a Learning Center or High Volume plan. Use the original school.learnworlds.com URL. Paste only the token, without Bearer. Replace it here when it expires or is revoked.
from: support.learnworlds.com
  School API URL — Original HTTPS school.learnworlds.com URL; /admin/api or /admin/api/v2 may be included.
  Client ID
  Access token
