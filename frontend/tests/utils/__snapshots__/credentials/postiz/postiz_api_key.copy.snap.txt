## postiz_api_key (Postiz)
name: API key
line: Paste an API key from Postiz.
how: Copy the API key from Postiz Settings. For self-hosted Postiz, enter your instance's public/v1 API base URL.
from: platform.postiz.com
  API key
  API base URL (optional) — Postiz Cloud, or the full public/v1 base URL of your self-hosted instance.
