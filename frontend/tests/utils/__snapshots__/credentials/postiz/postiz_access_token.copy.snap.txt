## postiz_access_token (Postiz)
name: OAuth access token
line: Paste an OAuth access token from Postiz.
how: Use an OAuth access token issued by your existing Postiz OAuth app. Browser authorization and app registration are separate from this manual-token credential.
from: docs.postiz.com
  OAuth access token — An existing non-expiring Postiz OAuth access token. Paste the token itself, without Bearer. This credential does not initiate browser OAuth.
  API base URL (optional)
