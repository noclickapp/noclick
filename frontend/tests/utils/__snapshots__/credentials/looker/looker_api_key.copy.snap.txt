## looker_api_key (Looker)
name: API key
line: Paste an API key from Looker.
from: docs.cloud.google.com
  Instance URL — Your Looker API base URL, e.g. https://acme.cloud.looker.com:19999 (original) or https://acme.api.looker.app (Google Cloud core)
  Client ID — API3 client_id from Looker Admin > Users > Edit > API Keys
  Client secret — API3 client_secret paired with the client_id
