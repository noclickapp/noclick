## digicert_api_key (Digicert)
name: API key
line: Paste an API key from Digicert.
how: In Digicert ONE, open Admin Profile > API Tokens to create an API token, or Account Manager > Access > Service User to create a service user token (recommended). Paste the token ID and select your instance. Grant Content Trust Manager audit-log read access for connection verification and the permissions needed by your workflow operations.
from: dev.digicert.com
