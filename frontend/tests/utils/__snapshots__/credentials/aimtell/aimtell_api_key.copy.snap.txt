## aimtell_api_key (Aimtell)
name: API key
line: Paste an API key from Aimtell.
how: In the Aimtell dashboard, open Settings > API Key. Paste your API key. NoClick sends it in the X-Authorization-Api-Key header to api.aimtell.com and reads your websites to check the connection.
from: developers.aimtell.com
  API key
