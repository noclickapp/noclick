## digistore24_api_key (Digistore24)
name: API key
line: Paste an API key from Digistore24.
how: Paste your Digistore24 API key from Settings > Account access > API keys. The key needs permission for the operations you use. NoClick sends it in the X-DS-API-KEY header only to www.digistore24.com. Connecting reads the API key owner's user information; this does not prove write permissions.
from: help.digistore24.com
