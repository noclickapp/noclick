## handwrytten_session_token (Handwrytten)
name: Session UID token
line: Paste a Session UID token from Handwrytten.
how: Paste an existing session UID token returned by Handwrytten /auth/authorization. This integration targets the published v1 API, which sends this token as uid in authenticated JSON requests. Do not paste your password or a v2 API key. Handwrytten recommends API keys for its newer v2 API; password sign-in is deprecated but remains supported. NoClick does not sign in, refresh, reset passwords or create accounts. Replace this token if the session expires.
from: handwrytten.com
