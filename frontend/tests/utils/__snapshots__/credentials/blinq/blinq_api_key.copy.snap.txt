## blinq_api_key (Blinq)
name: API key
line: Paste an API key from Blinq.
how: In the Blinq web app, open Settings > API keys and create a key. Requires a Pro or Business plan and verified email. Select blinq:identity:read for connection verification, blinq:notes:read for notes, blinq:contacts:read for contacts, blinq:cards:read for cards, and blinq:webhooks:read/write for subscriptions. Creating subscriptions also requires blinq:contacts:read. Paste the key without Bearer. Keys cannot exceed the owner's workspace permissions.
