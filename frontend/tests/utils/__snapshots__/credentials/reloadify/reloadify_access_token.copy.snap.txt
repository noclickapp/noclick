## reloadify_access_token (Reloadify)
name: Access token
line: Paste an access token from Reloadify.
how: Paste an existing access_token without the Bearer prefix. In Reloadify Settings > Reloadify API, generate a client ID and secret, then exchange them at POST https://app.reloadify.com/oauth/token with grant_type=client_credentials. Tokens last at most two hours: replace this token when it expires. The connection check reads your account's segments.
from: app.reloadify.com
  Access token
