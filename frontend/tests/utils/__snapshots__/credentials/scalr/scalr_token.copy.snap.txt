## scalr_token (Scalr)
name: Existing bearer token
line: Paste an Existing bearer token from Scalr.
how: Supply an existing personal or service-account Bearer token, canonical tenant.scalr.io host, and independently known accessible account ID/catalog page. Protected catalog access proves reachability, never actor/tenant ownership. No token creation/exchange/refresh. Entitlement and permissions remain unknown.
from: docs.scalr.io
  Existing personal or Service-account token
  Canonical tenant host — One tenant.scalr.io label. No custom host, scheme, port or path.
  Independently Known Accessible account ID
  Known account Catalog page (optional) — Page containing the known account; local bound. No automatic traversal or completion claim.
