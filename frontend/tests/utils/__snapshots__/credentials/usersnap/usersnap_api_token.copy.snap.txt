## usersnap_api_token (Usersnap)
name: API token
line: Paste an API token from Usersnap.
how: Requires a Usersnap Enterprise plan with REST API access. Paste a JWT you have signed using HS256 and the JWT secret from Settings > REST API, with the generated JWT ID in the kid header. Paste the finished token, without Bearer; do not paste the signing secret. NoClick sends it only to platform.usersnap.com.
from: app.usersnap.com
  API token
