## agencyzoom_bearer_token (Agencyzoom)
name: Access token
line: Paste an access token from Agencyzoom.
how: Paste an existing JWT access token returned by Agencyzoom's POST /v1/api/auth/login. Omit the Bearer prefix. Requests use the permissions of that user; an agency owner is needed for full agency access. Replace expired tokens here. NoClick does not sign in or refresh the token.
