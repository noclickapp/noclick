## nylas_access_token (Nylas)
name: Access token
line: Paste an access token from Nylas.
from: developer.nylas.com
  Nylas region (optional)
  Connected Grant ID — Actual v3 grant ID. Every operation stays bound to this grant.
  Issued access token
  Known expiry (Unix Seconds) (optional) — Only enter an expiry supplied by your authorization system. Reconnect when expired; this node does not refresh tokens.
