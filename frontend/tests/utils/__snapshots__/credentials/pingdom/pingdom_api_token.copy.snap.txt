## pingdom_api_token (Pingdom)
name: API token
line: Paste an API token from Pingdom.
how: In My Pingdom, generate an API token. Paste the token here. Read access supports reports and lists; Read/Write access is required to create, modify or delete checks and maintenance windows. NoClick sends it as a Bearer token to api.pingdom.com.
from: my.pingdom.com
  API token
