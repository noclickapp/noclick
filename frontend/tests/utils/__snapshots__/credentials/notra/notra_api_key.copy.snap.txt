## notra_api_key (Notra)
name: API key
line: Paste an API key from Notra.
how: Paste your Notra account or organization API key. Account keys can select a workspace with its ID or slug; this is required when you belong to multiple workspaces. Organization keys can select only their own workspace. NoClick sends the key only to api.usenotra.com. Grant access to the operations you use; connecting reads your authenticated workspace context.
from: usenotra.com
  API key
  Workspace ID or slug (optional) — Required for account keys belonging to multiple workspaces.
