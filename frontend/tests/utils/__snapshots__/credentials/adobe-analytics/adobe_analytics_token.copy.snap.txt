## adobe_analytics_token (Adobe Analytics)
name: Access token
line: Paste an access token from Adobe Analytics.
how: Use an already-issued OAuth User or Server-to-Server access token, its public client ID, and a discovery-authorized global company ID. Analytics product-profile permissions are required. Legacy JWT grants are excluded.
from: developer.adobe.com
  Issued OAuth access token
  API key (Client ID) — The Adobe Developer client ID that issued this OAuth token.
  Global company ID — Select the Analytics company returned by discovery/me.
  Token expiry (optional) — Known ISO 8601 expiry with timezone. NoClick does not mint or refresh tokens.
