## appcenter_api_token (Appcenter)
name: API token
line: Paste an API token from Appcenter.
how: Paste an existing App Center User API token. Read-only tokens support reads; writes need Full Access and the corresponding account permissions. The token is sent in X-API-Token to api.appcenter.ms. Microsoft has retired App Center; this integration targets its legacy API contract.
from: learn.microsoft.com
  API token
