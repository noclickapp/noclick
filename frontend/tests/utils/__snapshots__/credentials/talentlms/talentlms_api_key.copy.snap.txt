## talentlms_api_key (Talentlms)
name: API key
line: Paste an API key from Talentlms.
how: In Talentlms, open Account & Settings > Integrations > API. Enable API access and paste your API key. Enter your Talentlms portal subdomain or its HTTPS address, such as https://example.talentlms.com. The key inherits the API user's permissions; writes require permission to change the selected resources.
from: help.talentlms.com
