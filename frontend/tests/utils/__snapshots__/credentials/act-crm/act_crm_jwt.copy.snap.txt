## act_crm_jwt (Act Crm)
name: JWT
line: Enter the web API instance, Act database name and Issued JWT for Act Crm.
how: Use an already issued Act Web API JWT and its database. Enter the complete public HTTPS instance base including the cloud tenant path and /act.web.api. No login or token renewal is performed.
from: act.com
  Web API instance — For example https://your-host/your-tenant-api/act.web.api; never a contacts or authorize URL
  Act database name — Bound to this issued token
  Issued JWT
