## databox_api_key (Databox)
name: API key
line: Paste an API key from Databox.
how: Create an API key in Account Management > Profile > Password & Security (admin access required), then paste it here. NoClick sends it in the x-api-key header to api.databox.com and verifies it by reading your profile. Use a key with access to the resources your workflow needs.
