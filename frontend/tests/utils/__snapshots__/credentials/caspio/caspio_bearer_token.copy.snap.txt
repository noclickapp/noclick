## caspio_bearer_token (Caspio)
name: Bearer token
line: Paste a bearer token from Caspio.
how: Paste an existing access token from your Caspio API profile and its resource endpoint, ending in /rest. The profile must permit the tables, views and tasks you use. Access tokens expire after 24 hours; replace the token when it expires. NoClick does not generate or refresh tokens.
from: howto.caspio.com
  Resource endpoint — Your API profile's HTTPS resource endpoint, for example https://b1abc2.caspio.com/rest.
  Access token
