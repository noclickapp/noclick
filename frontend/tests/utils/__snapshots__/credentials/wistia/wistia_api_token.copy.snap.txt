## wistia_api_token (Wistia)
name: API token
line: Paste an API token from Wistia.
how: Paste a Wistia API token from Account Settings > API. Reads need Read all data (or Read all folder and media data for media/folders); writes and URL imports need Read, update & delete anything. Use a permanent account token for the account connection check. NoClick sends it only to api.wistia.com as a Bearer token.
from: docs.wistia.com
