## quickfile_token (Quickfile)
name: Personal bearer token
line: Paste a personal bearer token from Quickfile.
how: In your Quickfile account, open Account Settings → Third Party Integration → API. Generate a personal bearer token for your own account, enabling the endpoint groups your workflow uses. Paste the token without the Bearer prefix. The connection check reads your business details via /account/me. The REST API is in beta.
