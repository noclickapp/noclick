## rentman_api_token (Rentman)
name: API token
line: Paste an API token from Rentman.
how: In Rentman, open Configuration → Integrations and generate a personal API JWT. Paste the token without Bearer. Only the most recently generated token works; generating another invalidates the previous one. NoClick sends it only to api.rentman.net.
from: api.rentman.net
  API token
