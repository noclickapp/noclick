## snapchat_capi_token (Snapchat)
name: Conversions API token
line: Paste a Conversions API token from Snapchat.
how: In Ads Manager, open Business Details → Conversions API Tokens and generate a token as an Organization Admin. Paste the token and a website Pixel ID belonging to that organization. NoClick reads that asset's validation stats to check access. Tokens are long lived; replace a revoked token manually.
from: ads.snapchat.com
  Conversions API token
  Pixel ID — A website pixel owned by the organization that generated the token.
