## formaloo_api_token (Formaloo)
name: API token
line: Paste an API token from Formaloo.
how: Open your profile menu in Formaloo and choose API Key & Token. Paste your API key and an existing authorization token. To obtain a token, follow the direct API access instructions. Paste only the values, without header prefixes. An optional workspace identifier selects a workspace you can access.
from: dash.formaloo.net
  API key
  Authorization token
  Workspace identifier (optional) — Optional business_identifier.
