## ilert_api_key (Ilert)
name: API key
line: Paste an API key from Ilert.
how: Use an existing user REST API key and its actual current-user ID. No key creation or OAuth flow. REST Bearer authentication differs from Events integrationKey and Basic login context.
from: docs.ilert.com
  Existing ilert user REST API key — Supply the existing user REST key alone, not an Events integrationKey. Sent only in the Bearer header.
  Expected Current user ID — Existing private numeric ID from GET /users/current. Each operation verifies the actual actor; this is not a tenant ID.
  Optional team Context (optional) — Omit for all VIEW-permitted resources independent of UI selection. Header 0 means ALL teams, -1 MY teams, a positive ID selects a team. Catalog access does not establish membership.
