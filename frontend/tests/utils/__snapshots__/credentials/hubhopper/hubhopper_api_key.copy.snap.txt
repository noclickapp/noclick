## hubhopper_api_key (Hubhopper)
name: Partner API key
line: Paste a partner API key from Hubhopper.
how: Paste the API key and partner ID supplied by Hubhopper for the production Partner Integration API. These are sent as x-api-key and hhPartnerId. The connection check confirms access to the partner catalog; this API does not identify your account.
from: docs.hubhopper.com
  API key
  Partner ID — The hhPartnerId supplied with your partner API access.
