## runscope_api_token (Runscope)
name: Personal access token
line: Paste a personal access token from Runscope.
how: In Runscope Applications, create an application and copy its Personal Access Token. Paste that token here. Your own account is authorized automatically. NoClick sends it as a Bearer token. The token must allow the reads and writes you select.
from: runscope.com
  Personal access token
