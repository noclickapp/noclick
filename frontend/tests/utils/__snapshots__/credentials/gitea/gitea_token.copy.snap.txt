## gitea_token (Gitea)
name: Personal access token
line: Paste a personal access token from Gitea.
how: In your Gitea instance, open Settings → Applications → Manage Access Tokens. Paste an existing token and the public HTTPS instance origin. Use read:user for connection verification, read:repository and read:issue for reads, and write:repository and write:issue for writes you use. Tokens are sent as Authorization: token, never in URLs. Instances hosted under a URL subpath are not supported.
from: docs.gitea.com
  Gitea instance URL — Public HTTPS origin, for example https://gitea.example.com. No API path, query or fragment.
  Personal access token
