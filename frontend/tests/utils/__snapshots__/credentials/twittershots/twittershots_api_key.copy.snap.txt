## twittershots_api_key (Twittershots)
name: API key
line: Paste an API key from Twittershots.
how: Paste your Twittershots API key from Account Settings. NoClick sends it in the X-API-KEY header to api.twittershots.com. Connecting reads your remaining quota; it does not generate a screenshot or identify your Twitter/X account.
