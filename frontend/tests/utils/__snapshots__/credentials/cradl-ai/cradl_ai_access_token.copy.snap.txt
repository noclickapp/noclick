## cradl_ai_access_token (Cradl AI)
name: Access token
line: Paste an access token from Cradl AI.
how: Paste a Cradl AI bearer access token obtained using your application's client credentials, as described in the API introduction. Give the application read access to agents for the connection check, plus the read/write scopes needed by your operations. Tokens expire: replace this token when it expires. NoClick does not refresh it or ask for your application secret.
