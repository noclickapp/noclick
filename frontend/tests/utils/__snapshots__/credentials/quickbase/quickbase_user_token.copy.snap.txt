## quickbase_user_token (Quickbase)
name: User token
line: Paste an user token from Quickbase.
how: Create a user token in My preferences > My user information > Manage my user tokens, and assign it to the apps you need. Paste the token without QB-USER-TOKEN. Enter your realm hostname and an app ID the token can read; NoClick reads that app to check the connection. App access and your Quickbase permissions determine which operations are allowed.
from: help.quickbase.com
  User token
  Realm hostname — Your realm hostname, for example demo.quickbase.com, without https:// or a path.
  Connection app ID — An existing app assigned to this token. Find its ID in the app URL after /db/.
