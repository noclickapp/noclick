## numverify_api_key (Numverify)
name: API access key
line: Paste an API access key from Numverify.
how: Paste your Numverify API access key from the dashboard. NoClick sends it to apilayer.net over HTTPS. Your plan must support HTTPS. The connection check reads supported countries and proves key reachability, not account identity.
