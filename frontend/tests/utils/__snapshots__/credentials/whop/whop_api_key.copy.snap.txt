## whop_api_key (Whop)
name: API key
line: Paste an API key from Whop.
how: Paste a production Account API key from Whop Developer settings, without Bearer. Grant company:balance:read for the account connection check, plus the permissions needed by your operations. Sandbox keys cannot be used here. Whop enforces the key's permissions on each request.
