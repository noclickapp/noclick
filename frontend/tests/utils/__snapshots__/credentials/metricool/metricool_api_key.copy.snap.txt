## metricool_api_key (Metricool)
name: API token
line: Paste an API token from Metricool.
how: Supply an existing API token and the userId/blogId from your Metricool account. Current authentication uses X-Mc-Auth, not Authorization. API access is documented for Advanced and Custom plans; your actual entitlement is unverified. No login, mint, refresh or token introspection is performed.
from: help.metricool.com
  API token
  Metricool user ID — Your supplied account userId; it is never inferred from a shared brand's owner.
  Default Brand ID — Existing accessible brand used for connection validation and the brand list. Other selected brands require a current list witness.
