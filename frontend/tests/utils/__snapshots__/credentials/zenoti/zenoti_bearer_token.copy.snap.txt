## zenoti_bearer_token (Zenoti)
name: User token
line: Paste an user token from Zenoti.
how: Supply an existing role-bound Zenoti user token and its actual expiry. Sent as Authorization: bearer TOKEN. Employee permissions, password changes, departures and token expiry can restrict access. This node does not obtain or refresh tokens and does not prove a user identity from public catalog metadata.
from: docs.zenoti.com
  Existing user token
  Actual token expiry — Timezone-aware ISO 8601 expiry supplied with the issued token; no assumed duration or renewal.
