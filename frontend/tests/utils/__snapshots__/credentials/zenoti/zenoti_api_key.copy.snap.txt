## zenoti_api_key (Zenoti)
name: Organization API key
line: Paste an organization API key from Zenoti.
how: Supply an existing organization-issued API key. Sent as Authorization: apikey KEY. Organization-wide key access is distinct from a role-bound user token. API enablement and write permission are not proved by a catalog read. No environment fallback or key creation.
