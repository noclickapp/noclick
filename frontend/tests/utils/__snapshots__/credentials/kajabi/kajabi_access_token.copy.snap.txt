## kajabi_access_token (Kajabi)
name: Access token
line: Paste an access token from Kajabi.
how: In Kajabi Settings → API, create a User API Key with permissions for the operations you need. Exchange its client_id and client_secret using grant_type=client_credentials at POST https://api.kajabi.com/v1/oauth/token, then paste only the access_token here. Public API access must be enabled. Replace the token when it expires.
from: developers.kajabi.com
  Access token — Paste the access_token value without the Bearer prefix. Replace it when it expires.
