## adobe_campaign_access_token (Adobe Campaign)
name: Access token
line: Paste an access token from Adobe Campaign.
from: experienceleague.adobe.com
  Campaign Product — v8 REST requires enabled FDA; Enterprise FFDA is unsupported. Standard is a separate existing product tenant.
  Campaign tenant ID — Exact instance route identifier supplied by Adobe, including stage suffix if applicable. Use the current v8 tenant after migration; not an IMS @AdobeOrg ID.
  API key (Client ID)
  Issued OAuth access token — Already-issued OAuth server-to-server Bearer token for this tenant and Campaign API product profile. JWT authentication is retired; no token mint or refresh is performed.
  Token expiry (Unix Seconds) — Actual expiry derived from the issuer's token response. Replace this saved credential when it expires.
