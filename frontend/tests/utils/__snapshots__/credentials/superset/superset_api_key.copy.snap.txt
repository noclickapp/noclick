## superset_api_key (Superset)
name: API key
line: Paste an API key from Superset.
how: Enter your Superset server origin and paste an existing API key. API key support must be enabled by your administrator. Use HTTPS for a remote server. The key inherits its user's permissions and configured scopes. NoClick checks the current user; it does not request a password or create a key.
from: superset.apache.org
  Server URL — Your Superset origin, for example https://superset.example.com. Deployments under a URL subpath are not supported.
