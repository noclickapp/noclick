## bungie_token (Bungie)
name: API key and token
line: Paste an API key and token from Bungie.
how: Paste your application's API key and an existing Bungie access token from that same application. The token needs ReadBasicUserProfile for connection, ReadDestinyInventoryAndVault for private inventory, and MoveEquipDestinyItems for item and loadout actions. Tokens expire; replace the access token when it expires. NoClick does not refresh this manually supplied token.
from: bungie.net
