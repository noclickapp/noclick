## bandsintown_api_key (Bandsintown)
name: API key
line: Paste an API key from Bandsintown.
how: In Bandsintown for Artists, open your artist's Settings, then General, and copy the API Key. Paste it as the application ID and enter that artist's canonical name. Keys are artist-specific unless Bandsintown approves broader access. These reads verify reachability, not account identity or ownership.
from: artists.bandsintown.com
  Application ID (API key)
  Artist name — Canonical name of the artist this key can access; also used for the connection check.
