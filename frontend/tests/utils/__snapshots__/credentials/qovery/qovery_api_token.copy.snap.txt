## qovery_api_token (Qovery)
name: API token
line: Paste an API token from Qovery.
from: qovery.com
  Authorized organization UUID — Exact organization approved for this machine API token. Parent records must belong to this organization.
  Machine API token — Supply only the machine API token, without a prefix. Human OIDC Bearer tokens, scope discovery and token creation are not implemented.
