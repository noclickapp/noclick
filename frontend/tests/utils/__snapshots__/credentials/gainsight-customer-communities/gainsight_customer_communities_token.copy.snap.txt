## gainsight_customer_communities_token (Gainsight Customer Communities)
name: Access token
line: Paste an access token from Gainsight Customer Communities.
how: In Control > Integrations > API, find your API region and create client credentials. Exchange them at that region's /oauth2/token with grant_type=client_credentials and scope=read write, then paste only the access_token here. Tokens expire (the documented example lasts 7200 seconds); replace the token after expiry. NoClick does not renew pasted tokens. Read-only workflows need only read scope. The categories read checks community access, not user identity or write permissions.
from: developer-portal.gainsight.com
  API region (optional) — Choose the Base URL shown in Control > Integrations > API.
  Access token
