## yodeck_token (Yodeck)
name: API token
line: Paste an API token.
how: Supply an existing Yodeck API token value, a nonsecret label and an existing accessible workspace ID. Requests use Authorization: Token label:value. This integration does not issue tokens or log in. The selected workspace is an access witness, not account or actor identity. Permissions and entitlement remain specific to the token's role.
  Token Label (optional) — Nonsecret label for the documented Token label:value header; local header-safe limit is 128 characters.
  API token Value
  Workspace ID — Exact existing accessible workspace ID as decimal text. Every operation verifies this witness and child workspace ancestry.
