## ragic_api_key (Ragic)
name: API key
line: Paste an API key from Ragic.
how: Paste the issued RAW API key, without Basic or base64 conversion. Select the exact documented regional server and supplied account/folder/sheet. Optional paired record and nonsensitive field IDs permit a protected scoped read. It proves resource reachability only, not principal/key validity/private-sheet access; without them no probe occurs. No login, query key, token mint or writes.
from: ragic.com
  Raw API key
  Ragic server
  Account Component
  Folder Component — One folder component from the existing sheet URL, without slash.
  Sheet Index
  Existing Witness Record ID (optional)
  Nonsensitive Witness Field ID (optional) — Paired with the record ID; fetch only this numeric field and discard its value.
