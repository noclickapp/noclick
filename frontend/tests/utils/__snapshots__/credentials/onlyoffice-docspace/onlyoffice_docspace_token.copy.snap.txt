## onlyoffice_docspace_token (Onlyoffice Docspace)
name: Token
line: Paste a token from Onlyoffice Docspace.
how: Enter your DocSpace portal HTTPS URL and paste an existing personal access token. Obtain the token using the provider's authentication instructions. NoClick sends it as a Bearer token to this portal; it does not collect your password or create or renew tokens. The account must have permission for the selected operation.
from: api.onlyoffice.com
  DocSpace portal URL — Your portal HTTPS origin, for example https://yourportal.onlyoffice.com, without an API path.
  Personal access token
