## webcrm_access_token (Webcrm)
name: Access token
line: Paste an access token from Webcrm.
how: Paste an AccessToken returned by Webcrm's POST /Auth/ApiLogin (authCode is your application token from Configuration → Integration → API → REST). Enable organisation read access for connection verification, plus read/write access for the records you use. Paste the access token, not the application token. Access tokens expire: replace this credential's token when Webcrm rejects it. NoClick does not sign in or refresh it automatically.
from: api.webcrm.com
  Access token — The AccessToken from Webcrm's token response, without the Bearer prefix. Replace it when it expires.
