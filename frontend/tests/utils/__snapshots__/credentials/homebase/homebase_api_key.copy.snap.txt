## homebase_api_key (Homebase)
name: API key
line: Paste an API key from Homebase.
from: docs.joinhomebase.com
  Existing Homebase API key
  Expected company name — Match the current /company response; a name is not a unique company identity.
  Expected company Owner ID — The company owner's documented user ID, not a claim about the API key's principal.
  Allowed Location UUIDs — Only these explicit locations may be read or selected; each is checked through its documented protected resource.
