## dex_api_key (Dex)
name: API key
line: Paste an API key from Dex.
how: In Dex Settings > Dex API & MCP, create a key for Personal Dex or your workspace. Paste the key here. Choose Read & write to create or change records; a Read-only key supports reads. Workspace API access must be enabled by its owner or admin.
