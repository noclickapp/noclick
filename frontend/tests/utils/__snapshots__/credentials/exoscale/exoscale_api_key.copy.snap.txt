## exoscale_api_key (Exoscale)
name: API key
line: Paste an API key.
how: Supply an existing API key and secret authorized for the selected zone's metadata GETs. Requests use APIv2 EXO2-HMAC-SHA256 headers, not legacy v1 or Partner API signing. Connection reads protected instance metadata; an empty catalog proves reachability only. The optional expected instance is an existing resource witness, not organization or human identity. This node never issues keys, assumes roles, provisions or controls resources.
  API key
  API secret
  API Zone (optional) — Only these two exact APIv2 hosts are qualified by this integration. This is zone-local access, not global inventory.
  Expected instance ID (optional) — Optional exact existing instance UUID. Every operation checks this protected witness in this zone; it does not establish organization ownership.
