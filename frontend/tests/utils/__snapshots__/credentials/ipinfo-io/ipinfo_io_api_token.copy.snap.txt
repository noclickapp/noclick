## ipinfo_io_api_token (Ipinfo Io)
name: API token
line: Paste an API token from Ipinfo Io.
how: Paste your IPinfo API token from your account dashboard. NoClick sends it as a bearer token to IPinfo only. The token information read verifies acceptance and shows plan limits; it does not verify a person's identity. Specialized products require the corresponding IPinfo subscription.
