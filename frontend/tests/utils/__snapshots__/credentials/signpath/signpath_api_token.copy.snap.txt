## signpath_api_token (Signpath)
name: API token
line: Paste an API token from Signpath.
how: In Signpath, open My profile and generate an API token, or use a CI user token. Paste the token without Bearer and the organization ID from the organization page. API calls use that user's permissions; approval and administration require the corresponding roles.
from: docs.signpath.io
  API token
  Organization ID — Copy the organization UUID from Signpath's organization page.
