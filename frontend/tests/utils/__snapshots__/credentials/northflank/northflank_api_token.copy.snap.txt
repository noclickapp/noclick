## northflank_api_token (Northflank)
name: API token
line: Paste an API token from Northflank.
how: Supply an issued user or team API token. Use token default for its authenticated context, or explicitly bind requests to a known team ID using the documented /teams/{teamId} routes. Team ID is resource routing, not a verified principal identity. Team tokens require a configured API role; choose only needed read permissions and project manage permissions if using empty-project writes. No OAuth, token mint or refresh is automated. Paid access and role permissions remain unverified.
from: northflank.com
  Issued user or team API token
  Actual API Routing Context — Explicit resource context; not an assertion about the token's principal.
  Known team ID (optional) — Required only for explicit team routes. Not auto-discovered or inferred.
