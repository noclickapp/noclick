## rollbar_access_token (Rollbar)
name: Account access token (read/write)
line: Paste an account access token (read/write) from Rollbar.
from: rollbar.com
  Account access token (read/write) — Account token with read and write scopes. Required for account, project, team, and user operations.
  Project access token (read/write) (optional) — Project token with read and write scopes. Used for item, occurrence, environment, and deploy operations on its project; otherwise the account token and Project ID are used.
  Project Post server Item token (optional) — Separate project token with post_server_item scope. Required to report messages and deploys.
