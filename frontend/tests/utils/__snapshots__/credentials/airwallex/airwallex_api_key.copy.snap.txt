## airwallex_api_key (Airwallex)
name: API key
line: Paste an API key from Airwallex.
how: In Airwallex Settings > Developer > API keys, copy your client ID and API key. Grant the read and write permissions your operations need. Choose the matching production or sandbox environment. NoClick obtains a short-lived access token for each run; connecting reads your global accounts and does not prove write permissions.
from: airwallex.com
