## cpy_access_token (Cpy)
name: Peer Tube access token
line: Paste a Peer Tube access token from Cpy.
how: Enter your PeerTube instance URL and paste an existing access_token obtained using the official REST API instructions. Tokens expire: replace the token when it expires. NoClick does not store your password or automatically refresh tokens. Use an account allowed to manage the videos and channels you select.
from: docs.joinpeertube.org
  Instance URL — Public HTTPS origin of your PeerTube instance, for example https://peertube.example.com
  Access token
