## rbaskets_token (Rbaskets)
name: Request Baskets token
line: Paste a Request Baskets token from Rbaskets.
how: Paste the token shown when you created your basket and its basket name. NoClick reads that basket's protected settings to check the token. Service statistics and listing baskets require a service master token; basket tokens authorize only their own basket. This integration connects to rbaskets.in.
from: rbaskets.in
  Token
  Basket name
