## sematext_account_api_key (Sematext)
name: Account API key
line: Paste an account API key.
how: Enter an existing account API key, its US or EU region, and approved existing app IDs. This is distinct from an app ingestion/read/write token. Protected catalog access does not identify a principal or prove account ownership.
  Account API key
  Account region (optional) — Use the region in which the key and apps already exist. No cross-region fallback is performed.
  Approved app IDs (optional) — JSON string array of existing positive app IDs, at most 50. Example: ["123","456"].
  Include app and Rule Names (optional) — Opt in to names only. Messages, tokens, emails, integration configuration, queries, runbooks and all links are always omitted.
