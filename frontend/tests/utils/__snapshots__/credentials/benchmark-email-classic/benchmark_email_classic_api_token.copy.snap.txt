## benchmark_email_classic_api_token (Benchmark Email Classic)
name: Admin API token
line: Paste an admin API token from Benchmark Email Classic.
how: In Benchmark Email Classic, open Integrations → API and copy your Admin API Token. Paste the token alone. NoClick sends it in the AuthToken header to Benchmark's Classic API. This is separate from the newer Benchmark Email API key.
from: ui.benchmarkemail.com
