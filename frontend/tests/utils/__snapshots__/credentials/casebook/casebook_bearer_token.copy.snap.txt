## casebook_bearer_token (Casebook)
name: Bearer token
line: Paste a bearer token from Casebook.
how: Register an incoming application in Casebook Admin > Global > Integrations and obtain a Bearer token using Casebook's documented client credentials request. Paste the access_token without the Bearer prefix. Tokens expire after one hour: replace the token before running again. NoClick does not refresh it. Requires External Data Interoperability licensing and application roles for each operation. This integration uses the US API (api.casebook.net).
from: gohub.casebook.net
