## heygen_api_key (Heygen)
name: API key
line: Paste an API key from Heygen.
how: Paste the API key from your Heygen account settings. NoClick sends it as x-api-key to api.heygen.com. The connection check reads your current user and billing information. Generation consumes Heygen credits and may require a paid plan. The connection check does not prove access to every operation.
from: app.heygen.com
  API key
