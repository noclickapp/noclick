## kintone_api_token (Kintone)
name: API token
line: Paste an API token from Kintone.
how: In your app settings, open API Token, generate a token with the permissions your workflow needs, and update the app. Paste the token, your tenant URL, and that app's ID. Enable View records for reads; enable Add, Edit, or Delete records for writes. The app-name connection check requires View or Add records permission. App settings reads may require App management permission. Multiple app tokens for lookup fields can be separated by commas. NoClick checks the app name to verify access.
from: kintone.dev
  API token
  Tenant URL — Your HTTPS tenant origin, such as https://example.kintone.com or https://example.cybozu.com.
  App ID — The numeric ID in your app URL.
