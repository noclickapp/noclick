## club_os_token (Club Os)
name: API token
line: Paste an API token from Club Os.
how: Paste the token returned by Club Os's authenticate endpoint using the API username and password supplied by Club Os. Tokens last 24 hours; replace the token here after it expires. Paste only the token, without an Authorization or Bearer prefix. NoClick verifies access by reading the locations this API user can access. The published v2 contract specifies HTTP, so requests send this token without transport encryption.
