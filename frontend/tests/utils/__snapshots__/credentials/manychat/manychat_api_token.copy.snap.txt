## manychat_api_token (Manychat)
name: API token
line: Paste an API token from Manychat.
how: In your Manychat account, open Settings → API and generate an Account Public API key (requires a supported paid plan). Paste the key without Bearer. Use the account key, not the Profile Public API key. NoClick reads your page information to check the connection.
from: help.manychat.com
  API token
