## brex_api_token (Brex)
name: API token
line: Paste an API token from Brex.
how: In Brex Developer settings, create a token with companies.readonly for the connection check. Enable expenses.card, cards, accounts.cash.readonly, accounts.card.readonly, transactions.card.readonly, transactions.cash.readonly, transfers, transfers.readonly and vendors.readonly for the operations you use. Copy the token when it is created; Brex only shows it once.
from: dashboard.brex.com
  API token — User token generated in Brex Developer settings.
