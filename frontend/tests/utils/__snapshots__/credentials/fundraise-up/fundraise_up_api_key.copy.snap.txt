## fundraise_up_api_key (Fundraise Up)
name: API key
line: Paste an API key from Fundraise Up.
how: Use an organization-admin-issued Bearer API key. Choose test or live explicitly; permissions are independent and NoClick never switches modes. Campaigns, fundraisers and designations exist only in live mode. Select a permitted read resource for connection checking. Account ID is a local output fence, not an account identity claim. Keys do not expire; old keys created before January 30, 2026 were scheduled for deactivation six months later. No token mint or refresh.
from: dashboard.fundraiseup.com
  API key
  Live data — Required: false for test supporter data; true for live data. No fallback.
  Account ID — Eight-character account ID used to fence returned metadata. Parent keys may read subaccounts.
  Connection read resource (optional) — Choose a resource the key has Read permission for in this mode.
