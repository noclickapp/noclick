## payments_api_key (Payments)
name: API key
line: Paste an API key from Payments.
how: In the GOV.UK Pay admin tool, select your service, then Settings, Developers, API keys. Paste an API key for that service. Use a test-service key to test Payments. NoClick sends it as a bearer token; the Payments read proves access to the service, not your personal identity.
from: docs.payments.service.gov.uk
