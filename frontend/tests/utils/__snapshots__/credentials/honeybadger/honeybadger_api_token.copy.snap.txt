## honeybadger_api_token (Honeybadger)
name: API token
line: Paste an API token from Honeybadger.
how: API v3 is in preview: ask Honeybadger support to enable API tokens for your account, then create a v3 API token and paste it here. v2 personal auth tokens and project ingestion keys do not work. Choose your account's region. Grant only the scopes needed: account:read, projects:read, projects:create, projects:write, faults:read, faults:write and deploys:read. Connection checks read the token's account ID; they do not verify every operation's permissions.
from: docs.honeybadger.io
  API token
  Account region (optional) — Use the region where your Honeybadger account is hosted.
