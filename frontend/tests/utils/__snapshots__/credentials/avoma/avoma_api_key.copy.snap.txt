## avoma_api_key (Avoma)
name: API key
line: Paste an API key from Avoma.
how: Ask an Avoma organization admin to open Settings → Organization → Developer and copy the full API key (CLIENT_KEY:CLIENT_SECRET). Paste it here without the Bearer prefix. Choose the minimum user or organization access needed. NoClick reads users to check the connection; that check does not prove access to every meeting or write operation.
from: help.avoma.com
