## smartproxy_api_key (Smartproxy)
name: API key
line: Paste an API key from Smartproxy.
how: Smartproxy is now Decodo. In Account and Settings → Settings → API Keys, create a Public API key and paste it here. Residential proxies support management operations; mobile proxies support only dashboard traffic and targets. Datacenter and ISP products are not supported by this API.
