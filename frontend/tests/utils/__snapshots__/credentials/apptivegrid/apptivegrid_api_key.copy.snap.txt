## apptivegrid_api_key (Apptivegrid)
name: API key
line: Paste an API key from Apptivegrid.
how: In Profile & Settings → API credentials, create a key. Paste its key and the secret shown once. Use Admin for writes or Read only for reads. Paste your user ID from the Location header of GET /api/users/me with Basic authentication.
from: app.apptivegrid.de
  API key
  API secret
  User ID — Your account ID from /api/users/me's Location header, for example 64f1a2b3c4d5e6f708091a2b.
