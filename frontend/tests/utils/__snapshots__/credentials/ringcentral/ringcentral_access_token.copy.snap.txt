## ringcentral_access_token (Ringcentral)
name: Access token
line: Paste an access token from Ringcentral.
how: Paste an access token issued for your production Ringcentral app. Access tokens expire; replace this credential when yours expires. The app needs ReadAccounts, ReadCallLog, RingOut, SMS, Faxes, ReadMessages, EditMessages, ReadContacts and Contacts permissions for all operations. A JWT credential must first be exchanged for an access token by your app.
from: developers.ringcentral.com
  Access token — Paste a production Ringcentral access token without the Bearer prefix; JWT assertions cannot call the API directly.
