## id4i_api_key (Id4i)
name: API key
line: Paste an API key from Id4i.
how: In Id4i, create an API key with HMAC signing and the permissions your workflows need. Paste its UUID, its application secret and your organization namespace. NoClick signs a fresh two-minute HS512 JWT for each request. RSA keys are not supported.
from: backend.id4i.de
  API key UUID
  Application secret
  Organization namespace — For example de.acme. Used for the private organization connection read and as the default organization.
