## rezdy_api_key (Rezdy)
name: API key
line: Paste an API key from Rezdy.
how: In Rezdy, open Integrations > Rezdy API and request an API key. Paste the key here. NoClick sends it in the apiKey header to api.rezdy.com. Your plan and key permissions determine which operations are available.
from: developers.rezdy.com
