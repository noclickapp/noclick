## qonversion_secret_key (Qonversion)
name: Project secret key
line: Paste a project secret key from Qonversion.
how: Paste the issued project sk_ Secret Key unchanged, without Bearer. SDK/public keys and historical test_sk_ prefixes are distinct. Native v4 GET reads only; no key mint, environment-prefix rewriting or refresh. Optionally supply an existing Product ID for a protected connection read; this proves that resource's reachability, not project/account identity. Without it provider acceptance remains unknown.
