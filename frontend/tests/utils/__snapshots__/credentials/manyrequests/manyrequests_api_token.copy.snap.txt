## manyrequests_api_token (Manyrequests)
name: API token
line: Paste an API token from Manyrequests.
how: Requires the Manyrequests Pro plan. In your portal, open Settings → Integrations → API → Create token. Paste the token and your portal domain below. Custom portal domains are supported.
from: help.manyrequests.com
  Portal domain — Your Manyrequests portal, for example youragency.manyrequests.com, or its custom domain.
  API token — Paste the token itself, without the Bearer prefix.
