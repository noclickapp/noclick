## sirv_access_token (Sirv)
name: Access token
line: Paste an access token from Sirv.
how: Supply an existing Bearer token, its actual issuer-reported scope list including files:read, actual expiry deadline, and a selected absolute root-folder path. This node neither creates nor refreshes tokens. Sent only in the Authorization header to fixed public HTTPS api.sirv.com/v2. Folder reads establish reachability, not principal/tenant ownership or token-claim verification.
from: sirv.com
  Existing access token
  Selected Root Folder — Absolute account path, such as /catalog. A local read boundary, not account identity.
  Actual token expiry — Timezone-aware ISO deadline from the genuine token issuance time and expiresIn. Never inferred from a decoded JWT.
  Actual token scope List — Copy the issuer-reported scope array, including files:read. No scope is requested or granted by this node.
