## frame_io_v4_token (Frame Io V4)
name: Access token
line: Paste an access token from Frame Io V4.
how: Paste an existing Adobe IMS access token for Frame.io V4. Access tokens typically expire after one hour; replace the token when it expires. NoClick does not refresh it. For an eligible auto-migrated account using a legacy developer token, enable Legacy developer token to send the required x-frameio-legacy-token-auth header. Frame.io account roles determine read and write access. Connection verification reads the current user.
from: developer.frame.io
  Access token
  Legacy developer token (optional)
