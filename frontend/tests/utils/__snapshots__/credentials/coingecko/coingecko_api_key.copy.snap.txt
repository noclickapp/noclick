## coingecko_api_key (Coingecko)
name: API key
line: Paste an API key from Coingecko.
how: Paste a Coingecko Demo API key from your Developer Dashboard. Use a Demo key, not a paid Pro key. NoClick sends it in the x-cg-demo-api-key header to api.coingecko.com. The connection check reads public API status and proves reachability, not account identity.
