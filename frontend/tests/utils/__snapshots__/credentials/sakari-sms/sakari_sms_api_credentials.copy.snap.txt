## sakari_sms_api_credentials (Sakari Sms)
name: API client
line: Enter the account ID, client ID and client secret for Sakari Sms.
how: In Sakari, open Account Details (the cog) and find API Credentials. Paste the account ID, client ID and client secret. NoClick exchanges the client credentials for a temporary token at api.sakari.io for each operation. Listing contacts checks this account's read access; Sakari controls write permissions.
from: developer.sakari.io
  Account ID
  Client ID
  Client secret
