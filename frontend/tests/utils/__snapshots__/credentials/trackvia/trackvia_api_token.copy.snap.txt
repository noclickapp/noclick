## trackvia_api_token (Trackvia)
name: API token
line: Paste an API token from Trackvia.
how: In Trackvia Account Settings → API Access, copy your account API key and an active API user's auth token. Paste them below. Tokens expire on the date chosen by your administrator; replace expired tokens here. If needed, enter the account ID and your custom Trackvia tenant URL.
from: developer.trackvia.com
  Auth token
  Account API key
  Account ID (optional) — Optional account-id header for an account selection.
  TrackVia tenant URL (optional) — HTTPS URL of your Trackvia tenant, without /openapi.
