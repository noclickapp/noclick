## ramp_access_token (Ramp)
name: Access token
line: Paste an access token from Ramp.
how: Create a Ramp Developer API app and obtain an access token using client credentials. Include business:read, cards:read, cards:write, transactions:read, transactions:write, reimbursements:read, reimbursements:write, bills:read and bills:write for all operations. Paste only the access token. Client-credentials tokens expire after 10 days; obtain and paste a replacement when expired. Other token lifetimes follow expires_in.
from: docs.ramp.com
  Access token — Ramp Developer API bearer access token. Paste the token without the Bearer prefix.
