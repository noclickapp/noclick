## kadoa_api_key (Kadoa)
name: API key
line: Paste an API key from Kadoa.
how: An Admin or Owner can generate a team API key in Kadoa Settings > General. Paste it here. NoClick sends it in the x-api-key header to api.kadoa.com. Listing your workflows verifies read access; individual writes may need additional permissions.
