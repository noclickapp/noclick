## cvent_client_credentials (Cvent)
name: Client
line: Enter the client ID and client secret for Cvent.
how: Create a Cvent application in the developer portal, associate the required API scopes, and paste its client ID and client secret. NoClick obtains a short-lived access token using the client credentials grant. This method uses the North America API region.
from: developers.cvent.com
  Client ID
  Client secret
