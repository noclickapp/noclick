## gocardless_access_token (Gocardless)
name: Access token
line: Paste an access token from Gocardless.
how: In your Gocardless dashboard, open Developers, then Create access token. Paste the token only. Choose the matching Live or Sandbox environment. Read-write access is required for writes; read-only tokens can run reads. Live writes can move real money or cancel collections.
from: manage.gocardless.com
  Access token
  Environment (optional)
