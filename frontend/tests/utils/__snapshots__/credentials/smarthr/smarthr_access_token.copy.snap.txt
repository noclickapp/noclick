## smarthr_access_token (Smarthr)
name: Access token
line: Paste an access token from Smarthr.
how: Ask a Smarthr administrator to issue an access token in the admin screen. Enter your tenant subdomain and paste the token. The token must permit the operations you use; NoClick checks access by reading your company records.
from: developer.smarthr.jp
  Tenant subdomain — The part before .smarthr.jp in your Smarthr address, for example acme.
  Access token
