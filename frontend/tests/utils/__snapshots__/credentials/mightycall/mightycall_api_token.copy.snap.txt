## mightycall_api_token (Mightycall)
name: API token
line: Paste an API token from Mightycall.
how: Paste your Mightycall API key and existing authorization token. The API key is in Settings > API. Generate an authorization token with the documented POST /auth/token client_credentials request using your API key and secret key or extension. Tokens last 24 hours: replace the token here when it expires. API access requires an eligible Mightycall plan.
from: panel.mightycall.com
