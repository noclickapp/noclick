## google_cloud_natural_language_api_key (Google Cloud Natural Language)
name: API key
line: Paste an API key from Google Cloud Natural Language.
how: Enable the Cloud Natural Language API and billing on your Google Cloud project, then paste an API key allowed to call this API. NoClick sends it in the x-goog-api-key header. Connecting analyzes the fixed text 'Hello, world!' and consumes analysis quota. This proves key acceptance, not account identity. With an API key, Cloud Storage documents must be publicly readable; private objects need an authenticated principal.
from: console.cloud.google.com
  API key — Paste the key string from your Google Cloud project's Credentials page.
