## cliniko_api_key (Cliniko)
name: API key
line: Paste an API key from Cliniko.
how: Create your user API key under My Info → Manage API keys. Paste the issued value only, retaining its shard suffix. Permissions match that user's current role. The key is the Basic username with an empty password; this is not a Bearer token or an OAuth flow. Supply an administrator contact for NoClick's required User-Agent.
from: docs.api.cliniko.com
  Issued Cliniko API key
  Application Administrator Contact — Use an address where your integration administrator can be contacted.
