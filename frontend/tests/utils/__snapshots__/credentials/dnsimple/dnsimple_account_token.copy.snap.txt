## dnsimple_account_token (Dnsimple)
name: Account token
line: Paste an account token from Dnsimple.
how: Supply an existing ACCOUNT access token, exact account ID and explicit production or sandbox. Bearer header only; sandbox requires separately issued keys. No token issue/refresh, Basic/user-token/OTP/OAuth flow or host fallback. Token kind is a supplied declaration, not provider identity proof. Protected catalog access proves reachability only; scoped permissions and plan eligibility are unknown.
from: developer.dnsimple.com
  Existing account access token
  Bound DNSimple account ID
  Explicit API Environment (optional)
