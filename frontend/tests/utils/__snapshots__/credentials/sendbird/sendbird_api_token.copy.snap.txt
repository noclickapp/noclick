## sendbird_api_token (Sendbird)
name: API token
line: Paste an API token from Sendbird.
how: In Sendbird Dashboard, select your application and open Settings > Application > General. Copy its case-sensitive Application ID and a master or secondary API token. Prefer a secondary token with the permissions your operations need. NoClick sends it only to that application's Sendbird Chat API. This is not a user access token. A user-list read checks access; write permissions are not verified.
from: dashboard.sendbird.com
  Application ID — The application ID, without a URL or api- prefix.
  API token
