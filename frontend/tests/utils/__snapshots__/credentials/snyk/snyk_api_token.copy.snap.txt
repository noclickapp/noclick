## snyk_api_token (Snyk)
name: API token
line: Paste an API token from Snyk.
how: Paste an existing Snyk API token for the US API (api.snyk.io), without the token prefix. API access requires an eligible Snyk plan. Use a service account token for ongoing automation; its permissions control which organizations and actions are available. Get a personal API token from Account settings, or a service account token from your organization administrator.
from: app.snyk.io
