## credly_api_token (Credlys Acclaim Platform)
name: Authorization token
line: Paste an Authorization token from Credlys Acclaim Platform.
how: In Credly Organization Management, open Developers and copy an authorization token. Paste the token here. NoClick sends it as the HTTP Basic username with a blank password to api.credly.com. Tokens expire after 180 days by default; replace an expired token here. Write operations need a token with write permissions.
