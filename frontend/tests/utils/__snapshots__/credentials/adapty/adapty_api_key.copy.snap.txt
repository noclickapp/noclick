## adapty_api_key (Adapty)
name: API key
line: Paste an API key from Adapty.
from: app.adapty.io
  App secret API key — Secret key from App settings → General. SDK/public keys are not Server-side API credentials.
  Adapty app ID — Actual internal app UUID; every returned profile must match this app.
  Known Profile for connection Check — An existing profile in this app used for a read-only connection check. This is a resource reference, not account identity.
