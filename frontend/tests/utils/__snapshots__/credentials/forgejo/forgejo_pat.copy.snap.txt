## forgejo_pat (Forgejo)
name: Personal access token
line: Paste a personal access token from Forgejo.
how: Supply an existing PAT for one public HTTPS Forgejo instance. Authorization token header only, fixed /api/v1; no OAuth, refresh, issue, Basic/Bearer/query auth or Gitea fallback. Current-user ID proves authenticated actor, repository access does not prove ownership. Development Swagger/released-instance compatibility and permissions remain unverified.
from: forgejo.org
  Existing Forgejo personal access token
  Public HTTPS Forgejo instance origin
