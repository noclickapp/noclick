## hetzner_api_token (Hetzner)
name: API token
line: Paste an API token from Hetzner.
how: In your Hetzner Console project, open Security → API tokens and generate a token. Paste it here. Read-only tokens support reads and polling; choose Read & Write for changes. Tokens are scoped to one project.
from: console.hetzner.com
  API token
