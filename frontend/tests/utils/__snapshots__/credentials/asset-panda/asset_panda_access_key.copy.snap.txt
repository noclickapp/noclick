## asset_panda_access_key (Asset Panda)
name: Access key
line: Paste an access key from Asset Panda.
from: prohelp.assetpanda.com
  Access key ID — Supplied Pioneer/Pro key ID sent only in Access-Key-Id to the fixed api.assetpanda.app host.
  Access key secret — Supplied Pioneer/Pro key secret sent only in Access-Key-Secret. Legacy V2/V3 OAuth credentials are incompatible.
  Account ID — Exact permitted account ID. Protected GET /accounts membership is checked for every native operation; no ownership, role or expiry is inferred.
