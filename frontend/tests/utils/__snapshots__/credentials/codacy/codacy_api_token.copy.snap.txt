## codacy_api_token (Codacy)
name: API token
line: Paste an API token from Codacy.
how: In Codacy, open your account → Access management and click Create API token under Account API tokens. Paste it here. NoClick sends it in the api-token header to api.codacy.com. Repository tokens do not support all these operations. Access follows your Codacy account permissions.
from: docs.codacy.com
