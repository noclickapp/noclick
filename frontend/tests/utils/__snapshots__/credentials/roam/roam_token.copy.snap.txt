## roam_token (Roam)
name: Personal access token
line: Paste a personal access token from Roam.
how: In Roam, open User Settings → Developer and create a Personal Access Token if your workspace permits it. Paste the token alone. Enable the PAT groups for the chat, user, group and meeting operations you need. NoClick sends it only to api.ro.am. PATs have a daily quota of 1,000 requests. Connection testing reads token.info; it does not prove every operation is permitted.
