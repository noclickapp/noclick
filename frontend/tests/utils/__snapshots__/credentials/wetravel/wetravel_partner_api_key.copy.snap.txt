## wetravel_partner_api_key (Wetravel)
name: Partner API key
line: Paste a partner API key from Wetravel.
how: Paste the Partner API key generated in your Wetravel account under Partner API Integration. NoClick exchanges this refresh token for a short-lived access token and lists your trips to verify the connection. The key is shown only once when created. API access must be enabled for your account; listing trips does not prove write permissions.
from: developer.wetravel.com
