## nifty_pm_personal_access_token (Nifty Pm)
name: Personal access token
line: Paste a personal access token from Nifty Pm.
how: In Nifty, open Settings → API Tokens → New token. Choose the scopes for your actions and paste the token here. Tokens reach one workspace. Include members:read for the connection check; reads need the corresponding resource:read scope, creates and updates resource:write, assignments tasks:link, and deleting tasks tasks:delete. A successful connection check does not prove write permissions.
from: developers.niftypm.com
