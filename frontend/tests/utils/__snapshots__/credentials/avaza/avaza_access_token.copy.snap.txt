## avaza_access_token (Avaza)
name: Existing PAT or OAuth2 access token
line: Paste an Existing PAT or OAuth2 access token from Avaza.
how: Supply an existing Personal Access Token or issued OAuth2 access token. Both use Authorization: Bearer on fixed api.avaza.com. Required read scopes depend on the operations: read_account, read_contacts, read_projects and read_timesheets. PATs run under their creating user's roles and selected scopes. Protected /api/Account returns the actual AccountID; it does not identify the user or prove every permission/plan. No token creation/exchange/refresh, password, environment fallback or JWT identity decoding.
from: avaza.com
  Existing PAT or OAuth2 access token
  Supplied token Source (optional) — Caller-declared source, not decoded identity. OAuth access tokens expire; obtain a new existing token when required. No exchange or refresh is performed.
