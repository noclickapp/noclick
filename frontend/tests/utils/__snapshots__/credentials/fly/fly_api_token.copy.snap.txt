## fly_api_token (Fly)
name: API token
line: Paste an API token from Fly.
how: Paste an app-scoped deploy token for one app, or an organization token for app creation and organization-wide access. Create the narrowest token needed using Fly tokens create deploy or Fly tokens create org. Read-only tokens support reads only. NoClick sends it as a Bearer token to api.machines.dev.
