## everyaction_api_key (Everyaction)
name: API key
line: Paste an API key from Everyaction.
how: Use an API key issued for this integration, requested through API Integrations in your CRM. Enter the assigned application name and the key without its |0 or |1 suffix; choose the database mode separately. My Campaign (1) is the usual Everyaction CRM. Available operations depend on your key's approved permissions and security tier.
from: docs.everyaction.com
  Application name — Application name assigned with your API key.
  API key
  Database mode (optional) — 1: My Campaign / Everyaction CRM. 0: My Voters (requires permission).
