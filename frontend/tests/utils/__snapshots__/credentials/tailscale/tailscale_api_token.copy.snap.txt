## tailscale_api_token (Tailscale)
name: API token
line: Paste an API token from Tailscale.
how: Paste a personal API access token from Tailscale Settings → Keys. Use an API access token, not a device auth key or OAuth client secret. Tokens inherit your Tailscale permissions and expire after 1–90 days; replace the saved token when it expires. Connecting reads devices in the token's default tailnet. Write permissions are checked by Tailscale when each operation runs.
from: login.tailscale.com
