## zuora_client_credentials (Zuora)
name: OAuth client
line: Enter the tenant Environment, Existing OAuth client ID and Existing OAuth client secret for Zuora.
how: Use your existing dedicated API user's OAuth client for this exact Zuora tenant and environment. Client credentials mint a one-hour bearer token; there is no browser callback or refresh token. API roles and subscription features remain tenant controlled. Select an entity only when its actual grant permits it.
from: developer.zuora.com

  Existing OAuth client ID
