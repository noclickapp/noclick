## touchsms_api_key (Touchsms)
name: API key
line: Paste an API key from Touchsms.
how: In Touchsms, open Settings → API Keys and copy both the Access Token and Token ID. NoClick uses the Access Token as the HTTP Basic username and the Token ID as the password. Connection testing reads your account details without sending a message.
from: dev.touchsms.com.au
