## keycloak_token (Keycloak)
name: Admin access token
line: Paste an admin access token from Keycloak.
how: Paste an existing admin access token, your Keycloak HTTPS origin and target realm name (not its ID). The instance must be mounted at the origin root; /auth subpath installations are not supported. Grant only the realm-management roles your actions need: view-realm for the connection read; query-users/view-users and manage-users for users, groups and memberships; query-clients/view-clients for clients; view-events for events. Realm role reads require view-realm. A token from admin-cli expires in one minute by default. NoClick does not mint or refresh tokens: replace it when it expires. Requests use Authorization: Bearer and do not follow redirects.
from: keycloak.org
  Keycloak instance URL — HTTPS origin such as https://sso.example.com; no admin path, query or fragment.
  Realm name
  Admin access token
