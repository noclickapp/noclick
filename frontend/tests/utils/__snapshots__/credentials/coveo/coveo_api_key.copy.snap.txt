## coveo_api_key (Coveo)
name: API key
line: Paste an API key from Coveo.
from: docs.coveo.com
  API key — Already issued Coveo API key, kept on the backend and sent only as Bearer. No browser token, OAuth flow, search-token mint or refresh is configured.
  Organization ID — Exact permanent organization ID; determines fixed Search/Admin host and path. Never a caller URL.
  Region (optional) — Actual primary deployment region. Push requires this region; current Search/Admin roots route by organization. HIPAA explicitly selects orghipaa hosts.
  Connection Probe (optional) — Search performs an empty protected query and does not claim a person or organization name. Organization performs a protected organization read and requires Organization - View.
  Search Hub (optional) — Use the search hub enforced by your key if it has one. Actual key/pipeline restrictions remain authoritative.
  Allow management Writes (optional) — Off by default. Allows source refresh/rebuild/pause/resume and Push status updates, which affect indexed content/jobs and activity logs; notifications are not assumed suppressed.
  Allow Content read (optional) — Off by default. Explicit search excerpts may reveal indexed private text. Document/media URLs, raw fields, content and credentials are always withheld.
