## clockify_api_key (Clockify)
name: API key
line: Paste an API key from Clockify.
how: Generate a key in Profile settings → Preferences → Advanced → Manage API keys. For a regional or workspace subdomain, use its Clockify host and generate a key for that workspace.
from: app.clockify.me
  API key
  API domain (optional) — Use api.clockify.me for global workspaces, or your regional/workspace subdomain, such as euc1.clockify.me.
