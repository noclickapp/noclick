## bonzo_api_token (Bonzo)
name: API token
line: Paste an API token from Bonzo.
how: In Bonzo, open Settings, Integrations, API and choose Add Token. Select the resource permissions needed by your workflow, then copy the token when it is shown. Paste only the API token here, without Bearer. Access follows the creating user's permissions; use a Team Lead or Admin token to manage multiple owners' prospects. NoClick checks the current user and sends the token only to app.getbonzo.com.
from: support.getbonzo.com
