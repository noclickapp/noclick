## systemeio_api_key (Systemeio)
name: API key
line: Paste an API key from Systemeio.
how: In systeme.io profile settings, open Public API keys and generate a key. Paste it here without a header prefix. NoClick sends it as X-API-Key to api.systeme.io. Connection verification reads your contacts; it does not verify every write permission.
from: developer.systeme.io
  API key
