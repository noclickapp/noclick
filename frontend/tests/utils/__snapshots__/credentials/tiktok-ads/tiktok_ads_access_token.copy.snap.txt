## tiktok_ads_access_token (TikTok Ads)
name: Access token
line: Paste an access token from TikTok Ads.
how: Paste an existing authorized TikTok API for Business access token from your developer app and the advertiser ID it can access. Your app needs permission for each API you use. NoClick sends the token in the Access-Token header to business-api.tiktok.com. This is separate from a TikTok video publishing token.
from: business-api.tiktok.com
  Access token
  Advertiser ID — The numeric TikTok Ads Manager account ID authorized for this token.
