## quipuapp_api_credentials (Quipuapp)
name: Quipu API client
line: Enter the client ID, client secret and Business account slug for Quipuapp.
how: Copy the client ID and client secret from your Quipu API application, and the business account slug from its Quipu URL. NoClick exchanges these for a two-hour access token using the ecommerce scope whenever an operation runs. These are API application credentials; no browser sign-in is needed.
from: quipuapp.github.io
  Client ID
  Client secret
  Business account slug — The account/business URL slug, without the host or slashes.
