## vagaro_issued_client_token (Vagaro)
name: Issued client token
line: Paste an Issued client token from Vagaro.
from: docs.vagaro.com
  Issued client access token — Token already issued by your Vagaro Developer Settings client credentials. Client IDs/secrets and token minting are not collected by this node.
  Exact account region — Use the region from your account subdomain, for example us04. The docs do not publish an exhaustive region enumeration; the fixed API host cannot be changed.
  Actual token expiry — ISO date-time with timezone from actual issuance; the documented expires_in example is 3600 seconds. Replace the saved token when expired; no automatic renewal or replay.
  Declared Issued Scopes (optional) — Exact comma-separated scope values requested when issuing this token, represented here as a list. Local declared metadata is checked, while provider authorization remains authoritative. Updates additionally need write access or write employee as documented.
