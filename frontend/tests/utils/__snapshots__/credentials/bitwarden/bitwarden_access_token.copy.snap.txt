## bitwarden_access_token (Bitwarden)
name: Access token
line: Paste an access token from Bitwarden.
how: Paste an organization bearer access token obtained with your organization API key and scope api.organization. Tokens expire after 60 minutes; replace an expired token. This is not a Secrets Manager access token or a personal vault session.
from: bitwarden.com
  Access token
  Server region (optional)
