## teamup_calendar_api_key (Teamup Calendar)
name: API key
line: Paste an API key from Teamup Calendar.
how: Paste your Teamup API key and the calendar access key from your calendar URL (the ks… segment). Use a key with the permissions your workflow needs. For calendars requiring login, also paste an existing bearer token. NoClick never requests a password or signs you in.
from: teamup.com
  API key
  Calendar access key
  Bearer token (optional)
