## canopy_api_key (Canopy)
name: API key
line: Paste an API key from Canopy.
how: In Canopy, open Settings > API Management and copy your API key. API access requires Plus or Premium. Paste the key alone. NoClick uses the published Canopy v4 API server and sends it in the x-canopy-api-key header.
from: support.getcanopy.com
