## softr_api_key (Softr)
name: API key or personal access token
line: Paste an API key or personal access token from Softr.
how: Paste your Softr API key or personal access token with access to the databases you want to automate. Enable write access for create, update and delete actions. NoClick sends it in the Softr-Api-Key header to tables-api.softr.io. List databases checks the databases visible to this key.
