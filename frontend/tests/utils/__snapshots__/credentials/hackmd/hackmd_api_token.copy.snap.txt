## hackmd_api_token (Hackmd)
name: API token
line: Paste an API token from Hackmd.
how: In Hackmd, open My account > Settings > API, create an API token, and paste the copied token here. NoClick sends it as a Bearer token to api.hackmd.io. Your notes verify the connection; an empty account is verified by reading its current profile.
from: hackmd.io
  API token — Paste the API token without the Bearer prefix.
