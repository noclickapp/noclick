## levitate_api_key (Levitate)
name: Personal API key
line: Paste a personal API key from Levitate.
how: In Levitate, open your name menu, Integrations, Personal API Keys, Manage, then Create API Key. Select levitate:contacts and paste the key without the Bearer prefix. Public API access must be enabled on your account. Keys expire after 30, 90, 180 or 365 days; replace this credential before expiry. Zapier and MCP keys do not work here. NoClick reads a page of your contacts to check the key.
from: help.levitate.ai
