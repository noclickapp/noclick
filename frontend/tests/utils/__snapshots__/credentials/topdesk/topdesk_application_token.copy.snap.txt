## topdesk_application_token (Topdesk)
name: Application token
line: Paste an application token from Topdesk.
how: Enter your public HTTPS Topdesk URL, operator login name and application token from My settings > Application tokens (Application passwords on older versions). Give the operator REST API and incident read permissions, plus write permissions for the actions you use. Use the application token as the password, not your account password. Connection checks read your incidents.
from: developers.topdesk.com
  TOPdesk URL — For example https://example.topdesk.net. Public HTTPS self-hosted installations are also supported.
  Operator login name
  Application token
