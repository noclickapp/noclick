## memberspot_api_key (Memberspot)
name: API key
line: Paste an API key from Memberspot.
how: In Memberspot, open Settings → API keys (/settings/apikeys), create an API key and paste it here. NoClick sends it in the X-API-KEY header to api.memberspot.de. The key can manage members and course access in its school.
from: app.memberspot.de
