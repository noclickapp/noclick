## youcanbookme_api_key (Youcanbookme)
name: Account API key
line: Paste an account API key from Youcanbookme.
from: support.youcanbook.me
  Account ID — Exact account ID paired with this issued key. Team account access requires the organization owner's matching account/key; entitlement is not assumed.
  Auth username — HTTP Basic username: this account ID or its account email. Do not enter a login password here.
  API key — Already issued account API key. This is not your account login password, OAuth token or a key-issuance action.
