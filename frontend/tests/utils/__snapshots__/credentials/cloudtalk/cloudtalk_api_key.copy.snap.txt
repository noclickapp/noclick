## cloudtalk_api_key (Cloudtalk)
name: API key
line: Paste an API key from Cloudtalk.
how: In Cloudtalk, open Account → Settings → API Keys. Paste the API Access Key ID and Access Key Secret. An administrator can generate these keys. NoClick uses HTTP Basic authentication and reads your account's agents to check the connection.
from: dashboard.cloudtalk.io
  Access key ID
  Access key secret
