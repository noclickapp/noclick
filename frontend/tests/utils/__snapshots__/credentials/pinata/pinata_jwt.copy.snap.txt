## pinata_jwt (Pinata)
name: JWT
line: Paste a JWT from Pinata.
how: Create a Pinata API key and paste its JWT. Grant file and group read/write permissions for the operations you use. Legacy JSON pinning and usage require the corresponding IPFS permissions. NoClick sends it only to api.pinata.cloud. Listing public-network files proves account read access, not every write permission.
