## weaviate_api_key (Weaviate)
name: API key
line: Paste an API key from Weaviate and enter the cluster URL.
from: console.weaviate.cloud
  Cluster URL — Your Weaviate REST endpoint, e.g. https://my-cluster.weaviate.network
  API key (optional) — Required for Weaviate Cloud; optional for an unsecured instance.
  OpenAI API key (optional)
  Cohere API key (optional)
  HuggingFace API key (optional)
  Anthropic API key (optional)
  Google API key (optional)
  Mistral API key (optional)
  Weaviate Embeddings API key (optional) — Get one at console.weaviate.cloud → Embeddings.
