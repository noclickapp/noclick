## churchtools (Churchtools)
name: Login token
line: Paste a login token from Churchtools.
how: Supply your already-issued profile Login token and exact person ID for this public HTTPS Churchtools installation. The node uses Authorization: Login, never password login, token retrieval, impersonation or OAuth minting.
from: churchtools.academy
  ChurchTools Installation — Exact public HTTPS origin, for example https://your-church.church.tools. Custom public tenant domains are accepted; no path, private host or TLS override.
  Login token
  Your Person ID — Matched against whoami with only_allow_authenticated=true. This proves this user on this installation, not operation permissions.
