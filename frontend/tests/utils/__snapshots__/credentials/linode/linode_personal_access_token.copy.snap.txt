## linode_personal_access_token (Linode)
name: Personal access token
line: Paste a personal access token from Linode.
how: Create a personal access token in Cloud Manager > My Profile > API Tokens and paste it here. Grant only the categories needed: Linodes and Domains Read/Write for mutations, Images, Volumes and Events Read Only for reads. The profile read checks the current user; it does not verify every operation's permissions.
from: cloud.linode.com
  Personal access token
