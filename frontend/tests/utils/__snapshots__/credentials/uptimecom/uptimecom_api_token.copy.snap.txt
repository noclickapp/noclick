## uptimecom_api_token (Uptimecom)
name: API token
line: Paste an API token.
how: Enter an existing entitled API key, the expected numeric user pk from authenticated /auth/me/, and approved monitoring IDs. Saved restrictions narrow NoClick; provider permissions remain authoritative.
  API key
  Expected user ID — Numeric pk returned by the protected /auth/me/ endpoint. This authenticates a user witness, not account ownership or paid entitlement.
  Approved Monitoring IDs (optional) — Existing numeric IDs as JSON strings, for example {"checks":["123"],"tags":["4"],"statuspages":["5"]}. Maximum 50 per family/100 total are NoClick limits.
  Include resource Labels (optional) — Opt in to check names, tag names and status-page/component names. User personal data, check configuration and all URLs are always omitted.
