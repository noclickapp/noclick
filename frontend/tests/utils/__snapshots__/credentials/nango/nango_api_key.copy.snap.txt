## nango_api_key (Nango)
name: Environment API key
line: Paste an Environment API key from Nango.
how: Paste an environment API key from Nango's Environment settings → API Keys. Select permissions for the operations you use, including listing integrations for the connection check. NoClick sends it as a Bearer token to api.nango.dev.
