## apphud_s2s_api_key (Apphud)
name: App-level S2 S API key
line: Paste an App-level S2 S API key from Apphud.
from: docs.apphud.com
  Existing App-level S2S API key
  Apphud application ID — The eight-character application identifier from App settings. This is not a bundle ID. The fixed key/app pair is used on every chart request.
  Allowed Chart IDs (optional) — Explicit local restrictions. Catalog discovery never extends this list; it does not prove account identity or paid access.
  Allowed Operations — List Charts is required for current protected discovery. All supported operations are analytics reads, including POST queries.
