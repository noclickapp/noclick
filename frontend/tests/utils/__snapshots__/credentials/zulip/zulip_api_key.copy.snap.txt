## zulip_api_key (Zulip)
name: API key
line: Paste an API key from Zulip.
how: In Zulip, open Personal settings > Account & privacy and copy your API key. Paste the email that owns that key and your organization's HTTPS URL. Bot email and API key pairs also work, subject to the bot's permissions. NoClick uses HTTP Basic authentication and reads your subscribed channels to check the connection.
from: zulip.com
  Zulip server URL — Organization origin, e.g. https://example.zulipchat.com. Public HTTPS self-hosted servers are supported.
  Account email
  API key
