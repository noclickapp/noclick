## wolfram_alpha_api_app_id (Wolfram Alpha API)
name: AppID
line: Paste an AppID from Wolfram Alpha API.
how: Create an app in the Wolfram|Alpha Developer Portal and paste its AppID with LLM API access. NoClick sends it as a Bearer token to www.wolframalpha.com. The connection query consumes API usage and proves key acceptance, not account identity.
from: developer.wolframalpha.com
