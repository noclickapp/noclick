## maintainx_api_key (Maintainx)
name: API key
line: Paste an API key from Maintainx.
how: In Maintainx, open Settings > Integrations > API Keys and generate a key for your user. API access requires Premium or Enterprise. Paste only the key, without Bearer. For a multi-organization key, enter the organization ID to use for list and create operations; record IDs on other operations are global IDs.
from: app.getmaintainx.com
  API key
  Organization ID (optional) — Required for multi-organization keys when listing or creating records.
