## sec_api_tokens (Sec)
name: API tokens
line: Enter the Filer API token, user API token and Filer CIK for Sec.
how: Paste a filer API token supplied by your technical administrator, your user API token from Filer Management, and the 10-digit CIK of the account you manage. Filer-management writes require the appropriate account administrator role. NoClick sends both tokens to the production Sec EDGAR API; submission-status and system-status reads use only the filer token.
from: filermanagement.edgarfiling.sec.gov
  Filer API token
  User API token
  Filer CIK — Your account's 10-digit Central Index Key, including leading zeroes.
