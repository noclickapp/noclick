## cleverreach_access_token (Cleverreach)
name: Access token
line: Paste an access token from Cleverreach.
how: In Cleverreach, open My Account → Interfaces → REST API and use Test process now to get an API token, then paste it here. NoClick sends it as a Bearer token to rest.cleverreach.com. Use a token with access to the lists and actions you need. If it expires, replace it with a new token; NoClick does not refresh pasted tokens.
