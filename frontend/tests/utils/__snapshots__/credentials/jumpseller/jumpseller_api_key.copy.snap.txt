## jumpseller_api_key (Jumpseller)
name: API login and token
line: Paste an API login and token from Jumpseller.
how: In your Jumpseller Admin Panel, open Account > Preferences > API and MCP. Copy the API Login, then use Show token and confirm your password to reveal the Auth Token. Both are required. NoClick sends them using HTTP Basic authentication only to api.jumpseller.com. Enable access to the resources your workflow uses.
