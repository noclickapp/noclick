## hostfully_api_key (Hostfully)
name: API key
line: Paste an API key from Hostfully.
how: For a Hostfully account with API access, copy the agency API key and agency UID from Agency Settings. Select the environment that issued your key. This connects your own agency; Hostfully partner applications use a separate OAuth flow. NoClick reads the agency to verify the connection.
from: dev.hostfully.com
  API key
  Agency UID — At the bottom of Hostfully Agency Settings.
  Environment (optional)
