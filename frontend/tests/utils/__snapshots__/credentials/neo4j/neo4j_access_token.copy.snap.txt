## neo4j_access_token (Neo4j)
name: Access token
line: Paste an access token from Neo4j.
how: Paste an existing Aura API bearer access token, without the Bearer prefix. Obtain it from the documented token endpoint using your Aura Console client credentials. Access tokens expire after one hour: reconnect with a new token when expired. NoClick does not exchange or refresh client credentials. This manages Aura infrastructure; it does not run Cypher queries. Connection checks read your accessible Aura projects.
