## bold_commerce_token (Bold Commerce)
name: API access token
line: Paste an API access token from Bold Commerce.
how: In Bold Account Center, open API access tokens and create a private token with the Subscriptions, Customers, Orders, Shops and Subscription Groups permissions needed by your workflows. Paste the token and your shop identifier. Find the identifier with GET https://api.boldcommerce.com/shops/v1/info, as described in Bold's Making API Calls guide. NoClick checks your shop information before saving.
from: account.boldcommerce.com
  API access token
  Shop identifier — Your Bold shop identifier, without a URL or path.
