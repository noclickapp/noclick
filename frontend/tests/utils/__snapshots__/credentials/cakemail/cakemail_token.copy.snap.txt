## cakemail_token (Cakemail)
name: Personal access token
line: Paste a personal access token from Cakemail.
how: Paste a personal access token created with POST /users/self/pats. Grant the read/write scopes for the operations you use; triggers need webhooks:read and webhooks:write. Tokens are sent only to api.cakemail.dev.
from: api.cakemail.dev
  Personal access token
