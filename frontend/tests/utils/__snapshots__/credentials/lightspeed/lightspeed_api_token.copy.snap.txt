## lightspeed_api_token (Lightspeed)
name: API token
line: Paste an API token from Lightspeed.
how: For Retail X-Series on the Plus plan, paste a private app token from Developer Portal > Organizations > Edit application > Generate New Token, after the store admin approves the app. Legacy personal tokens from Setup > Personal tokens also work where available. New accounts use private apps. Enter only your store domain prefix, for example mystore from mystore.retail.lightspeed.app. Grant the scopes needed for your operations, including outlets:read to verify the connection. Tokens are sent only to that store; NoClick does not refresh them. Replace expired or revoked tokens here.
from: developers.retail.lightspeed.app
  Store domain prefix — The store subdomain before .retail.lightspeed.app, without a URL.
  API token
