## spacebring_basic (Spacebring)
name: Customer Basic auth
line: Enter the Customer client ID, Customer client secret and Network ID for Spacebring.
how: The Spacebring app owner retrieves the customer Client ID and Client Secret from the selected network's Settings > Developers. Supply that network's UUID. Native customer Basic authentication is separate from partner OAuth registration. Connection checks the returned network ID and title; it does not identify a human owner or prove write entitlement.
from: spacebring.com
  Customer client ID
  Customer client secret
  Network ID — Canonical UUID of the existing network belonging to these customer credentials.
