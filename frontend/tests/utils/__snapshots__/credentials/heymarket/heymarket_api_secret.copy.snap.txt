## heymarket_api_secret (Heymarket)
name: API secret
line: Paste an API secret from Heymarket.
how: In Heymarket, open Settings > Integrations > API and generate an API Secret. Paste its Secret ID and Secret Key here. The key is shown only once. NoClick signs a fresh short-lived JWT on the server for each request. Connection checks read your inboxes.
