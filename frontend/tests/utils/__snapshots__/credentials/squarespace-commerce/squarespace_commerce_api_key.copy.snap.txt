## squarespace_commerce_api_key (Squarespace Commerce)
name: API key
line: Paste an API key from Squarespace Commerce.
how: In your Squarespace site's Settings > Advanced > Developer API Keys, generate a key. Enable Products, Inventory, Orders, Transactions and Profiles reads as needed, and Read and Write for Products, Inventory or Orders mutations. Paste only the key. Connection checks read the website profile; this does not verify every API permission. API availability depends on your Squarespace plan.
from: developers.squarespace.com
