## slicktext_api_key (Slicktext)
name: API key
line: Paste an API key from Slicktext.
how: In your Slicktext dashboard, open the menu beside your name → Settings → API & Webhooks → API Keys → Create API Key. Copy the key when shown and paste it here. Use a key for the new Slicktext platform; legacy accounts use a different API. The brand read checks your key and returns the brand ID needed by other operations.
