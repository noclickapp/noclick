## stack_exchange_access_token (Stack Exchange)
name: Access token
line: Paste an access token from Stack Exchange.
how: Paste your Stack Apps application's API key and an existing OAuth access token issued to that same application. The token needs write_access for comment writes and read_inbox for inbox and notifications. Generate the token through your application's documented OAuth flow; NoClick does not create or refresh it. Use no_expiry only when perpetual access is needed, otherwise replace an expired token. The site is the API site parameter, for example stackoverflow. Connection verification reads your profile on that site.
from: stackapps.com

  Site (optional)
