## fillout_api_key (Fillout)
name: API key
line: Paste an API key from Fillout.
how: Enable the REST API in Settings → Developer, then copy its API key. The same key works for forms and databases.
from: app.zite.com
  API key — Generate this in Zite / Fillout → Settings → Developer → API key
  API region (optional) — Choose the Forms API base URL shown in Developer settings
