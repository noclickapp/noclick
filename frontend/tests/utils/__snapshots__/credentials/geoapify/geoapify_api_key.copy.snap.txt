## geoapify_api_key (Geoapify)
name: API key
line: Paste an API key from Geoapify.
how: Open your project in Geoapify MyProjects, select API Keys, and paste an API key. Allow NoClick's server requests in any key restrictions. NoClick sends it only to api.geoapify.com in the x-api-key header. Connecting uses one IP Geolocation credit and proves key acceptance, not account identity.
from: myprojects.geoapify.com
