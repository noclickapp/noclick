## stibee_api_key (Stibee)
name: API key
line: Paste an API key from Stibee.
how: Paste an API key created after January 21, 2025 from Stibee Workspace settings > API keys. Subscriber operations require Standard or above; email and group operations require Pro or Enterprise, and address-book reads require Enterprise. Connection verification lists your emails and needs Pro or Enterprise. NoClick sends the key only to api.stibee.com in the AccessToken header.
from: help.stibee.com
