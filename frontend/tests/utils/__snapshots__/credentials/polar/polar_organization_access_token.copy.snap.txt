## polar_organization_access_token (Polar)
name: Organization access token
line: Paste an organization access token from Polar.
from: polar.sh
  Organization access token — Existing OAT from this environment. No PAT, customer session, OAuth client secret, or partner token interchange.
  Polar Environment — Select explicitly; tokens and organizations are separate in each environment.
  Organization ID
  Configured token Scopes — Existing OAT permissions plus local restrictions. These supplied values are not token introspection or proof of a provider grant.
  Allowed Operations
  Current resource Restrictions (optional) — If a kind has bindings, reads are limited to those IDs. Existing-resource writes require a binding; deletion also requires owned_disposable. Newly created IDs are never added automatically.
