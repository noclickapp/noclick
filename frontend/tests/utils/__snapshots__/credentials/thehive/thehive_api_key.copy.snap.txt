## thehive_api_key (Thehive)
name: API key
line: Paste an API key from Thehive.
how: In Thehive, open your user settings and copy your API key. Enter your instance origin and paste the key below.
from: docs.strangebee.com
  Instance URL — Public HTTPS origin of your Thehive instance, for example https://thehive.example.com. Use an instance reachable from NoClick.
  API key — Paste your existing API key without the Bearer prefix.
  Organization (optional) — Optional organization name for X-Organisation. Leave blank to use your default organization.
