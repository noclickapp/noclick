## telematicssdk_token (Telematicssdk)
name: JWT access token
line: Paste a JWT access token from Telematicssdk.
how: Paste an existing Damoov JWT without the Bearer prefix. Use an admin JWT for user searches, counts and instance administration. Tokens expire; replace an expired JWT with one refreshed outside NoClick.
