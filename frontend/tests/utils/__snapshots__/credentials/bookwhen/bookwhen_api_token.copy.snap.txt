## bookwhen_api_token (Bookwhen)
name: API token
line: Paste an API token from Bookwhen.
how: Paste an existing Bookwhen v2 access token with the schedule permissions needed for these reads. NoClick sends the token as the Basic username with an empty password to api.bookwhen.com only. No token creation, refresh or OAuth flow is provided. Public schedule reads establish reachability, not user identity or account ownership.
from: support.bookwhen.com
  API token
  Connection read resource (optional)
