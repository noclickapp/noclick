## mindbody_api_key (Mindbody)
name: Public API
line: Enter the developer API key and site ID for Mindbody.
how: Supply a developer API key activated for this Site ID. Protected client reads, appointments and client writes also require an authorized staff user's complete Authorization header value. No login, token issue, renewal or activation request is made. Public metadata does not establish staff identity or account ownership.
from: developers.mindbodyonline.com
  Developer API key
  Site ID — The activated business site. Mindbody's documented developer test site is -99; no environment is inferred from a key.
  Staff Authorization (optional) — The complete Authorization header value accepted for this staff user. It is sent verbatim; no Bearer prefix is added.
  Staff token expiry (optional) — Optional UTC/offset ISO timestamp from the token issuer. Expired supplied tokens require replacement.
