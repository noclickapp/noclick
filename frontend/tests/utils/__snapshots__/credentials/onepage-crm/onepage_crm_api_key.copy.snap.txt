## onepage_crm_api_key (Onepage Crm)
name: API key
line: Paste an API key from Onepage Crm.
how: Open OnePageCRM Settings > API > Configuration and copy your User ID and API key. Paste both values below. The API key grants access to your account; NoClick sends it only to app.onepagecrm.com using HTTP Basic authentication.
from: app.onepagecrm.com
  User ID — User ID from the API Configuration tab.
