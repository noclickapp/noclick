## evolution_go_instance_token (Evolution Go)
name: Instance token
line: Paste an instance token from Evolution Go.
how: Paste the token of an existing, paired Evolution Go WhatsApp instance and its public HTTPS server URL. Use the instance token, not the global admin key. NoClick sends it in the apikey header to that server.
from: github.com
  Server URL — The public HTTPS origin of your Evolution Go server, without a path.
  Instance token
