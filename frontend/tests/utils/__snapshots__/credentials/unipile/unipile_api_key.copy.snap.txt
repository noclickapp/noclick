## unipile_api_key (Unipile)
name: API key
line: Paste an API key from Unipile.
how: Paste your Unipile v1 dashboard DSN (including its port) and access token. Connect messaging or email accounts in Unipile first. The token is sent as X-API-KEY only to your Unipile DSN. Listing linked accounts verifies this connection; individual provider permissions may differ.
from: dashboard.unipile.com
  DSN — HTTPS origin from your Unipile dashboard, e.g. https://api1.unipile.com:13111
  API key
