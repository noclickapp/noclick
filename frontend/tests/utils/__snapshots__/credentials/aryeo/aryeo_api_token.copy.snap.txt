## aryeo_api_token (Aryeo)
name: API token
line: Paste an API token from Aryeo.
how: In Aryeo, open your group's developer settings and generate a personal access token. Paste only the token, without the Bearer prefix. NoClick reads your listings to check the connection. The token's user and current group determine which records you can access.
from: docs.aryeo.com
