## cloze_api_key (Cloze)
name: API key
line: Paste an API key from Cloze.
how: Paste your Cloze API key from More > Settings > Accounts and Services > API Access. NoClick sends it as a bearer token to api.cloze.com. API availability depends on your Cloze plan and permissions. Cloze requires OAuth for publishing a public integration; this connection uses your own API key.
from: help.cloze.com
  API key
