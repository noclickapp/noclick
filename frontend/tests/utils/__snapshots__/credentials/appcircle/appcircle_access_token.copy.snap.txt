## appcircle_access_token (Appcircle)
name: Access token
line: Paste an access token from Appcircle.
how: Paste the generated access token, without Bearer. Exchange your Personal Access Key at Appcircle's Auth API first; the key itself is not an access token. Access tokens expire: replace this credential when it expires. The token must allow the selected build or testing-distribution actions.
from: docs.appcircle.io
