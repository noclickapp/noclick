## sap_concur_oauth (Sap Concur)
name: OAuth tokens
line: Enter the Geolocation and access token for Sap Concur.
how: Use existing issued OAuth tokens and their exact current server geolocation. Optional refresh requires the same application's client ID/secret and expiry. No login or initial token mint is performed.
from: developer.concur.com
  Geolocation
  Access token
  Refresh token (optional)
  Client ID (optional)
  Client secret (optional)
  Expires At (optional) — Issued access-token expiry as ISO 8601 with timezone; required when refresh is configured
  Scope (optional) — Actual granted scope string, if known; this field grants no permissions
