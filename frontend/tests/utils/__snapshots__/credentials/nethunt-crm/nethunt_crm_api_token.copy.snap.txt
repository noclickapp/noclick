## nethunt_crm_api_token (Nethunt Crm)
name: API token
line: Paste an API token from Nethunt Crm.
how: In NetHunt Settings → Integrations → API & MCP, create a token and paste it here. Use a v2 API token (nh_live_…), with access to the folders you want to automate. NoClick checks the connection by listing accessible folders.
from: nethunt.com
