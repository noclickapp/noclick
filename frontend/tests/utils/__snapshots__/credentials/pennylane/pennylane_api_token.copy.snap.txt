## pennylane_api_token (Pennylane)
name: API token
line: Paste an API token from Pennylane.
how: In Pennylane, go to Settings > Connectivity > Developers and generate a Company API V2 token (Essential plan or higher, company admin access). Select read and write permissions for the resources you automate: customers, suppliers, products, customer invoices, supplier invoices, bank accounts and transactions. Paste the token here. NoClick sends it as a Bearer token to app.pennylane.com and verifies the company with /me. Replace the token here when it expires or is revoked. A Firm token also needs the company ID below.
from: pennylane.readme.io
  API token
  Company ID (optional) — Required only for a Firm token. Leave empty for a Company token.
