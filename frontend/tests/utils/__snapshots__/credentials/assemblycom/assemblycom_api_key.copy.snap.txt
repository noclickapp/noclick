## assemblycom_api_key (Assemblycom)
name: API key
line: Paste an API key from Assemblycom.
how: In your Assembly workspace, copy an API key and paste it here. NoClick sends it in the X-API-KEY header to api.assembly.com. Use a key with permissions for your selected actions; Tasks operations also need the Tasks app installed.
