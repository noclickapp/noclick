## chroma_token (Chroma)
name: API token
line: Paste an API token from Chroma and enter the tenant and database.
from: trychroma.com
  Auth method (optional) — Token auth (Chroma Cloud / default) or Basic auth (self-hosted with password auth enabled).
  API token (optional) — Chroma token. Required when Auth Method is Token.
  Username (optional) — Basic auth username. Required when Auth Method is Basic.
  Password (optional) — Basic auth password. Required when Auth Method is Basic.
  Tenant — Id or default_tenant.
  Database — Chroma database name (or 'default_database')
  Base URL (optional) — Override for self-hosted Chroma. Defaults to Chroma Cloud
