## goatcounter_api_token (Goatcounter)
name: API token
line: Paste an API token from Goatcounter.
how: Supply an existing API token and one HTTPS site origin/site ID. Bearer HEADER plus Content-Type application/json, fixed /api/v0 only. The auth guide documents Bearer while Swagger declares basicAuth; this node has no Basic/query/body fallback, token issue or signup. Current code.goatcounter.com/cname are compared internally to the configured hostname; never followed. No /me (it returns token/user), decoded identity, account ownership or permission/entitlement claim.
from: goatcounter.com
  Existing GoatCounter API token
  GoatCounter site origin — Single public HTTPS site origin, including a documented custom/self-hosted hostname. No API path or credentials in URL.
  Selected site ID — Existing exact site ID; current catalog and detail must identify this origin uniquely. Resource access is not actor/account ownership.
