## android_texter_api_key (Android Texter)
name: API key
line: Paste an API key from Android Texter.
how: Create an API key in Android Texter under Dashboard → Settings → API Keys. Paste the key here; NoClick sends it in the X-API-Key header.
from: androidtexter.com
  API key — Paste your Android Texter API key, without a header name or Bearer prefix.
