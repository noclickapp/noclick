## jiraservicemanagement_api_token (Jiraservicemanagement)
name: API token
line: Paste an API token from Jiraservicemanagement.
how: Create an API token without scopes in your Atlassian account security settings. Paste the token, the account email and your Jira Cloud site URL. The token inherits your account permissions.
from: id.atlassian.com
  Site URL — Your Jira Cloud site, for example https://your-team.atlassian.net
  Atlassian account email — Email of the Atlassian account that created the API token
  API token
