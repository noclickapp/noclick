## discourse_api_key (Discourse)
name: API key
line: Paste an API key from Discourse.
from: meta.discourse.org
  Forum URL — Your Discourse site base URL, e.g. https://meta.discourse.org (no trailing /admin)
  API key — Admin API key from Admin → API → Keys (/admin/api/keys)
  API username (optional) — Username the request acts as. Use 'system' or an admin for full access.
