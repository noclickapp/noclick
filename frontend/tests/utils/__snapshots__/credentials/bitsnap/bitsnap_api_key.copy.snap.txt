## bitsnap_api_key (Bitsnap)
name: API key
line: Paste an API key from Bitsnap.
how: In Bitsnap, open Settings → Developer and create a project API key. Paste the bs_test_ or bs_live_ key. Choose the scopes your actions need and enable its write switch for writes. Payment links require a live key. NoClick checks GetAccount to show the shop and environment.
