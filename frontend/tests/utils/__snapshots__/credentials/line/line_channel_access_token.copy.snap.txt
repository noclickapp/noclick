## line_channel_access_token (Line)
name: Channel access token
line: Paste a Channel access token from Line.
how: Paste a channel access token from your Messaging API channel in the Line Developers Console. A long-lived token is available on the Messaging API tab. Use a Messaging API token, not a Line Login token. NoClick reads the bot profile to verify the connection. Tokens are not refreshed automatically; replace expired or revoked tokens here.
