## ignition_api_key (Ignition)
name: API key
line: Paste an API key from Ignition.
how: An admin must enable the Ignition API in Settings → Labs, then create an API key in Developer hub. Paste the key without Bearer. Include practice:read for the connection check. Select clients:read/write, services:read/write, proposals:read/write, invoices:read, payments:read and tax_rates:read as needed for your operations. The key acts with its creator's permissions.
