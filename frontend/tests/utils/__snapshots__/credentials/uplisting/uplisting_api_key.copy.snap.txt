## uplisting_api_key (Uplisting)
name: API key
line: Paste an API key from Uplisting.
how: Copy your API key from Uplisting Connect > API. Paste the raw key; NoClick encodes it for Basic authentication. V2 booking and custom attribute operations also require a partner client ID from Uplisting's API access form. Other operations need only the API key.
from: app.uplisting.io
  API key
  Partner client ID (optional) — Only needed for V2 booking and custom attribute operations. Request from Uplisting's partner team.
