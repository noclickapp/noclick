## langfuse_api_key (Langfuse)
name: API key
line: Paste an API key from Langfuse.
how: In your Langfuse project settings, create a project API key. Paste its public key and secret key, then select the project's Cloud region. Organization keys are not supported. NoClick uses Basic authentication to the selected Langfuse Cloud host. Self-hosted instances are not supported.
from: langfuse.com
  Public key
  Secret key — Secret API key paired with the public key.
  Cloud region (optional) — Use the region where your project lives.
