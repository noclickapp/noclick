## voluum_access_key (Voluum)
name: Access key
line: Paste an access key from Voluum.
how: In Voluum Settings → Security → Access keys, create or select a key for the intended user. Copy its Access ID and Access Key together. NoClick creates a temporary API session; this is not OAuth.
from: doc.voluum.com
  Access ID — UUID from Voluum Settings → Security → Access keys
  Access key — Access key for the same Voluum user
