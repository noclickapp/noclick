## affinda_api_key (Affinda)
name: API key
line: Paste an API key from Affinda.
how: Paste your API key from Settings in the Affinda web app. Choose the region matching your account's app URL: Global (app.affinda.com), US (app.us1.affinda.com), or EU (app.eu1.affinda.com). NoClick sends the key as a Bearer token only to that region's Affinda API. Document parsing consumes your Affinda credits.
from: app.affinda.com
  API key
  Region (optional) — api = Global / Australia; api.us1 = US; api.eu1 = EU
