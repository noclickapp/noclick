## servicetrade_session_token (Servicetrade)
name: Session token
line: Paste a Session token from Servicetrade.
how: Paste an existing API session's authToken (the PHPSESSID cookie value) from Servicetrade. Send only the value, without PHPSESSID= or a Cookie header. The API documents this legacy session method alongside OAuth client credentials. Sessions expire: replace the token when Servicetrade rejects it. NoClick does not sign in or renew this session. The session's user permissions govern reads and writes.
from: api.servicetrade.com
  Session token
