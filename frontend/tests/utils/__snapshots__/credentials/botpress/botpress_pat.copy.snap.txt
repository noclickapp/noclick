## botpress_pat (Botpress)
name: Personal access token
line: Paste a personal access token from Botpress.
how: Use an existing Personal Access Token from your profile and copy the workspace and bot IDs. Current user/workspace permissions control access. Connection checks bot metadata; it does not establish human identity or permission for every write.
from: app.botpress.cloud
  Workspace ID — Existing workspace accessible to the PAT's user.
  Bot ID — Existing bot in this workspace. Table and file operations stay bound to this bot.
  Personal access token — An existing user PAT; bot and integration access keys are different credentials.
