## humanitix_api_key (Humanitix)
name: API key
line: Paste an API key from Humanitix.
how: In the Humanitix console, open API keys and create a key with events:read for connection verification, orders:read for orders, tickets:read for tickets and check-in counts, and tickets:checkin for check-in and check-out. Paste the key here. Global reads also need global:read and special permission from Humanitix. Keys access your account's events; legacy keys may also access shared events.
