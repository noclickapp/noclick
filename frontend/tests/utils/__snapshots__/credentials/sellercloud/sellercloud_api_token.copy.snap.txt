## sellercloud_api_token (Sellercloud)
name: API token
line: Paste an API token from Sellercloud.
how: Paste an existing access_token and your Sellercloud REST API endpoint. Obtain the token using your integration employee in Sellercloud Swagger. Sellercloud tokens expire (the docs state 60 minutes); replace expired tokens here. NoClick does not store your Sellercloud password or renew tokens.
from: developer.sellercloud.com
  REST API endpoint — Your assigned endpoint, e.g. https://pbf2.api.sellercloud.com/rest. Sellercloud .com and .us API hosts are supported.
  Access token
