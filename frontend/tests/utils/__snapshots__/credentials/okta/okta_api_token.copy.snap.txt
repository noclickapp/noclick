## okta_api_token (Okta)
name: API token
line: Paste an API token from Okta.
how: In your Okta Admin Console, open Security → API → Tokens and create a token. Paste the token and your organization URL. The token inherits its creator's permissions; use an administrator permitted to manage the resources your workflow needs.
from: developer.okta.com
  Organization URL — Your Okta organization URL, such as https://example.okta.com. Custom domains are supported. Use the organization host, not the -admin host.
  API token
