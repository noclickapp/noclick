## wildjar_access_token (Wildjar)
name: Access token
line: Paste an access token from Wildjar.
how: Paste an existing Wildjar access token, without the Bearer prefix. Wildjar documents obtaining tokens using your username and password at /v2/token/. Tokens expire (normally after one hour); replace this token when it expires. NoClick does not request or renew tokens. Listing your accounts proves read access; it does not prove write permissions.
