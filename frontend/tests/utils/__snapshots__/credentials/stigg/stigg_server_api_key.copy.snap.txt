## stigg_server_api_key (Stigg)
name: Environment
line: Enter the server API key and Existing Customer ID for Stigg.
how: Use an issued server- secret key for one Stigg environment. Full and scoped server keys are supported; client publishable keys are excluded. Supply an existing customer ID for the read-only connection check.
from: docs.stigg.io
  Server API key — Existing server- full or scoped secret key. Permissions and environment are set by Stigg; no key is minted or rotated.
  Existing Customer ID — One existing customer in this key's environment, used for a protected metadata read on connect. This does not prove an account or environment name.
