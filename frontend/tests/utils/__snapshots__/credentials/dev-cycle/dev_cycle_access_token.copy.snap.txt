## dev_cycle_access_token (Dev Cycle)
name: Access token
line: Paste an access token from Dev Cycle.
how: Paste a DevCycle Management API access token without the Bearer prefix. Obtain it using the client credentials in Organization Settings and the documented token endpoint. SDK keys are not management tokens. NoClick does not refresh this token; replace it when it expires. Project access proves this token works, not every write permission.
