## turso_api_token (Turso)
name: API token
line: Paste an API token from Turso.
how: Paste a Turso Platform API token, not a database SQL token. Use the Turso CLI to mint a token scoped to your organization. Grant read for database reads, org:read for members and billing usage, and the write scopes your workflow needs. Group creation/deletion requires an organization-level token. NoClick sends it only to api.turso.tech using Bearer authentication.
