## supernormal_api_key (Supernormal)
name: API token
line: Paste an API token from Supernormal.
how: Supply an already-issued Supernormal scoped API key and its actual granted read scopes. The fixed v1 API sends X-API-TOKEN, not Bearer/Basic. user:read is required for the real identity probe; add recordings:read or calendar_events:read only when issued for those operations. API entitlement is account-dependent and not verified here. No OAuth/global client or key creation is automated.
from: app.supernormal.com
  Existing Scoped Supernormal API token
  Actual Granted read Scopes — Enter only these scopes actually issued to the key. This is not an API scope-grant request; unknown scope requires issuer clarification.
  Expected user ID (if known) (optional) — Optional actual /user ID. If supplied, every operation refuses a different principal. Absence is unknown, not filled from the current app or a guessed account.
