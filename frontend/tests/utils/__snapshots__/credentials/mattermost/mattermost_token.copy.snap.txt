## mattermost_token (Mattermost)
name: Personal access token
line: Paste a personal access token from Mattermost.
how: Enter your public HTTPS Mattermost server URL (including its deployment subpath, if any) and paste a personal access token from Profile > Security > Personal Access Tokens. Your administrator must enable token creation. Use a non-admin account with access to the teams and channels you automate. NoClick checks the token by reading your current user profile; individual operations still require the corresponding server permissions.
from: docs.mattermost.com
  Server URL — Public HTTPS deployment URL, e.g. https://chat.example.com. Include a deployment subpath if used; omit /api/v4.
  Personal access token
