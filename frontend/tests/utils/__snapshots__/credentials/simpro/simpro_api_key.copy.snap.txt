## simpro_api_key (Simpro)
name: API key
line: Paste an API key from Simpro.
how: In Simpro, open System > Setup > API > Applications and request API Key access. Paste the access token from the key file and your build URL. The key's application permissions must allow the operations you use. Company listing verifies the connection.
from: developer.simprogroup.com
  Build URL — Your HTTPS Simpro build, for example https://example.simprosuite.com or https://example.simprocloud.com.
  API key
