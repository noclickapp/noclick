## glean_api_token (Glean)
name: API token
line: Paste an API token from Glean.
how: In Glean Admin Console → Platform → Client API Tokens, create a Glean-issued USER token for your email. Enable COLLECTIONS to verify the connection, plus SEARCH, DOCUMENTS, ANSWERS and SHORTCUTS for the actions you need, and TRIGGERS for preset events. Paste the token with your instance backend URL. This connection accepts user-scoped Client API tokens; global and Indexing API tokens need a different setup.
from: developers.glean.com

  Instance backend URL — https://yourcompany-be.glean.com
