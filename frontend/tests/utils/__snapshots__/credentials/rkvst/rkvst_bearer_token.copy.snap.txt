## rkvst_bearer_token (Rkvst)
name: Bearer access token
line: Paste a bearer access token from Rkvst.
how: Paste an existing DataTrails (formerly Rkvst) bearer access token, without the Authorization header. Application tokens expire after one hour; replace the token when it expires. NoClick sends it only to app.datatrails.ai. Your application needs an access policy permitting the selected reads and writes. Listing assets shows resources visible to this token; it does not verify your personal identity or write permissions.
