## docuseal_api_key (Docuseal)
name: API key
line: Paste an API key from Docuseal.
how: Copy your API key from the Docuseal API console and paste the key alone. Choose the region that holds your account. NoClick sends X-Auth-Token only to that region's Docuseal API. Connecting reads your templates; writes use this key's permissions. Creating submissions sends signature request emails by default; turn Send email off to create without emailing signers.
from: console.docuseal.com
  API key
  Account region (optional)
