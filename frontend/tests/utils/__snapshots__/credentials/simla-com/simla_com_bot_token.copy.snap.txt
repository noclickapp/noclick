## simla_com_bot_token (Simla Com)
name: Bot token
line: Paste a bot token from Simla Com.
how: Paste your existing Simla.com bot token. NoClick sends it as X-Bot-Token to the documented MG Bot API server. The bot needs access to the channels and dialogs you automate. Connection checks list your channels; they do not prove message delivery or write permissions.
from: mg-api-docs.simla.com
  Bot token
