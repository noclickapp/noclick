## invoiceninja_api_token (Invoice Ninja)
name: API token
line: Paste an API token from Invoice Ninja.
how: In Invoice Ninja, open Settings → Account Management → Integrations → API tokens. Create a token and paste it here. For self-hosted accounts, enter your HTTPS server URL.
from: invoiceninja.github.io
  API token
  Server URL (optional) — Invoice Ninja server origin. Use https://invoicing.co for hosted accounts or your self-hosted HTTPS server.
