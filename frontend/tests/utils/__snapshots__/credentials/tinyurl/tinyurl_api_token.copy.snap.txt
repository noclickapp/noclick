## tinyurl_api_token (Tinyurl)
name: API token
line: Paste an API token from Tinyurl.
how: Create an API token in Tinyurl API Settings, then paste it here. Give it permission to read your links and perform the actions you need. NoClick sends it as a Bearer token to api.tinyurl.com. Analytics and editing features depend on your Tinyurl plan.
from: tinyurl.com
  API token
