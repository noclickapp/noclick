## lead_prosper_api_token (Lead Prosper)
name: API token
line: Paste an API token from Lead Prosper.
how: In Lead Prosper, open Settings → API and copy an account API token. Paste only the token. NoClick sends it as a Bearer header to api.leadprosper.io. Campaign reads verify access; write permissions depend on the token owner's role.
from: api.leadprosper.io
