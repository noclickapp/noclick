## nextcloud_app_password (Nextcloud)
name: App password
line: Paste an app password from Nextcloud.
how: Enter your public HTTPS Nextcloud installation URL, username and an app password from Personal settings → Security → Devices & sessions. File triggers require the Webhook Listeners app and administrator or delegated Webhooks privileges. The app password is sent using HTTP Basic authentication.
from: docs.nextcloud.com
  Nextcloud server URL — Installation root, for example https://cloud.example.com/nextcloud. Public HTTPS only.
