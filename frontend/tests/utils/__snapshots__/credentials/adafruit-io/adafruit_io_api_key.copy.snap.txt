## adafruit_io_api_key (Adafruit Io)
name: API key
line: Paste an API key from Adafruit Io.
how: In Adafruit Io, click the gold key icon or View Adafruit Io Key. Paste your username and active account key. NoClick sends the key in the X-AIO-Key header to io.adafruit.com. Connection checks show the account returned by the key.
from: io.adafruit.com
  Adafruit IO username
  Adafruit IO key
