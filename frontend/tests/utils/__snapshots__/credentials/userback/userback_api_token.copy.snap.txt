## userback_api_token (Userback)
name: API token
line: Paste an API token from Userback.
how: Paste your Userback REST API token from the token page linked in the authentication documentation. An API-enabled account and Admin permissions are required. NoClick sends it as a Bearer token to rest.userback.io and lists projects to check the connection.
