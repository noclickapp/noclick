## blackboard_access_token (Blackboard)
name: Access token
line: Paste an access token from Blackboard.
how: Paste your Blackboard Learn HTTPS site URL and an existing bearer access token for that site, without the Bearer prefix. Ask your Blackboard administrator for a token from an already registered REST integration with the permissions your operations need. Blackboard tokens expire after one hour; replace an expired token here. NoClick does not create or refresh tokens. Connection testing lists courses and does not verify all write permissions.
from: docs.blackboard.com
  Blackboard site URL — Your institution's public HTTPS Blackboard Learn origin, for example https://school.blackboard.com.
