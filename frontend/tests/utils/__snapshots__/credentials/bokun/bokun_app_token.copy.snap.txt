## bokun_app_token (Bokun)
name: Bókun Existing app token
line: Paste a Bókun Existing app token from Bokun.
how: Supply an already issued App Store access token and its vendor tenant label. GraphQL uses X-Bokun-App-Access-Token on that tenant's host. Catalog reads require the actual PRODUCTS_READ grant; booking reads require BOOKINGS_READ. Installation/consent, callback verification, REST-secret retrieval and token issuance are not performed by this supplied-token method. Keep the token private; no token is sent in provider URLs or output.
from: bokun.dev
  Environment (optional) — Use the environment belonging to this existing credential; the node never changes it automatically.
  Vendor tenant — The existing vendor's single subdomain label, without a URL or suffix.
  App access token
