## printify_oauth_access_token (Printify)
name: OAuth access token
line: Paste an OAuth access token from Printify.
how: Supply a current access token from your vendor-approved platform app. This connection does not register a platform app, authorize a merchant or refresh a token. Do not paste a refresh token or app ID as the access token. Requested scopes are distinct from actual grants.
from: developers.printify.com
  API brand (optional)
  OAuth access token
  Token expiry — Actual expiry returned by the approved platform's token exchange, with timezone. Access tokens expire after six hours; replace the token when expired.
