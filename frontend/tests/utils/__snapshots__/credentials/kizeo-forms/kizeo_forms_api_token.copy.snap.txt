## kizeo_forms_api_token (Kizeo Forms)
name: API token
line: Paste an API token from Kizeo Forms.
how: Paste your existing Kizeo Forms API token. An administrator can request a token from support@kizeo.com with the company code and administrator or group leader user ID. NoClick sends it directly in the Authorization header. Your token's user permissions determine which forms, data, lists and groups you can access.
from: kizeo.github.io
