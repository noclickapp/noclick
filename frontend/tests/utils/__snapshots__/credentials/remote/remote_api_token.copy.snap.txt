## remote_api_token (Remote)
name: API token
line: Paste an API token from Remote.
how: In Remote, open Company → Company Settings → Integrations & APIs → Integrations → Remote API. Paste your customer API token. Enable the read/write permissions your actions need and webhook:write for triggers. ra_test_ tokens use Remote's sandbox; other tokens use production.
