## esputnik_api_key (Esputnik)
name: API key
line: Paste an API key.
how: Use an existing eSputnik/Yespo API key as the HTTP Basic password. Any username is accepted by the provider; the default is noclick. This is not your account password or an event Bearer token. Connection reads account/info and shows the returned organization name and user email; it does not prove contact/broadcast permissions, entitlement or subscription status.
  API key
  Basic username (optional) — The provider accepts any value. This value is sent as the Basic username; the API key is its password.
  Expected organization name (optional) — Optional exact name to match against account/info during connection and account reads. No organization ID is required.
