## vectara_client_credentials (Vectara)
name: OAuth client
line: Enter the client ID, client secret, token endpoint and Bound Corpus key for Vectara.
how: Supply an existing app client's ID, secret, exact official token endpoint and allowed corpus. The server obtains short-lived machine tokens; no browser consent or refresh token. The bound corpus read proves reachability, not account identity.
from: console.vectara.com
  Client ID
  Client secret
  Token endpoint — Select the exact official authentication URL shown for your existing app client. No automatic host fallback.
  Bound Corpus key — Every operation is restricted to this existing or deliberately new corpus key.
