## iclosed_api_key (Iclosed)
name: API key
line: Paste an API key from Iclosed.
how: In Iclosed, open Settings → Developer → API Keys. Create a key and paste the complete key, including its iclosed_ prefix, without Bearer. The key acts as its user and account. Connection checks read your contacts; write permissions are checked by Iclosed when used.
from: app.iclosed.io
