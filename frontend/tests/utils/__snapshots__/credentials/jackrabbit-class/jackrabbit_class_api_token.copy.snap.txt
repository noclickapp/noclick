## jackrabbit_class_api_token (Jackrabbit Class)
name: Customer API token
line: Paste a Customer API token from Jackrabbit Class.
how: Paste the Customer API token provided by Jackrabbit, without the Bearer prefix. Organization tokens already select their organization. For a corporate token, enter the organization ID to send as X-Org-Id. NoClick checks the organization name using Options/me.
from: api.jackrabbitclass.com
  Customer API token
  Organization ID (optional) — Only for corporate tokens. Leave empty for an organization token.
