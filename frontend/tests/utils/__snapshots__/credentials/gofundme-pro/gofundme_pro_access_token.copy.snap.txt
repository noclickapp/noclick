## gofundme_pro_access_token (Gofundme Pro)
name: Access token
line: Paste an access token from Gofundme Pro.
how: Paste an existing Gofundme Pro bearer access token and your organization ID. Use a token authorized for that organization's resources and the reads or writes you need. API credentials are created in the organization admin dashboard; the documented client-credentials exchange issues app access tokens. Tokens expire (the documentation example lasts 3600 seconds); replace an expired token here. NoClick checks campaigns when connecting.
from: developers.gofundme.com
  Access token
  Organization ID — Numeric ID of the organization whose resources to list or create.
