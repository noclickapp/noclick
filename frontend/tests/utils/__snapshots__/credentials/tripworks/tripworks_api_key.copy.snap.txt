## tripworks_api_key (Tripworks)
name: API key
line: Paste an API key from Tripworks.
how: In Tripworks, open Setup → REST API → Keys and create a key with the read/write scopes for the resources you automate. Enter your account subdomain and paste the key shown once.
from: api-docs.tripworks.com
  Account subdomain — The account part of https://your-account.tripworks.com
