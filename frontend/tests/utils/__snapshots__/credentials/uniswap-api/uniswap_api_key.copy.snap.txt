## uniswap_api_key (Uniswap API)
name: API key
line: Paste an API key from Uniswap API.
how: Paste an API key from the Uniswap developer dashboard. NoClick sends it in x-api-key only to trade-api.gateway.uniswap.org. The connection check reads supported chains to verify key reachability, not account or wallet ownership. Your wallet private key is never required.
from: developers.uniswap.org
