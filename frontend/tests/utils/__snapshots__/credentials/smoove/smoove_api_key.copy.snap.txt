## smoove_api_key (Smoove)
name: API key
line: Paste an API key from Smoove.
how: Create an API key in Smoove's API settings and paste it here without the Bearer prefix. Listing your lists verifies account access. The key needs AccountMembersRead for reads, AccountSubscriptions for contact updates, AccountAdmin for creating lists, and AccountCrm for CRM notes; provider role alternatives are documented per endpoint.
