## nationbuilder_v2_token (Nationbuilder)
name: V2 token
line: Paste a V2 token from Nationbuilder.
from: nationbuilder.com
  Nation slug — Only the nation subdomain, such as acme, from acme.nationbuilder.com. Custom domains and arbitrary URLs are not supported.
  V2 access token — Paste an existing v2 JWT, without Bearer. V1 tokens do not work. V2 tokens expire after 24 hours; replace an expired token. This connection does not mint or refresh tokens.
  Known token expiry (optional) — Optional actual expiry supplied with your token, in ISO 8601 with timezone. It is not inferred from an unverified JWT.
