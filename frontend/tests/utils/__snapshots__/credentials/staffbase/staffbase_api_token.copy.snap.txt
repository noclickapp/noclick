## staffbase_api_token (Staffbase)
name: Prepared API token
line: Paste a Prepared API token from Staffbase.
from: developers.staffbase.com
  Tenant API Root — Copy the HTTPS root from Studio, for example https://exampleapp.staffbase.com/api. Private hosts and redirects are refused.
  Prepared API token — Paste the API token from Studio. It is already encoded and is sent once as Authorization: Basic token; omit the Basic prefix.
