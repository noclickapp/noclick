## bambooci_pat (Bambooci)
name: Personal access token
line: Paste a personal access token from Bambooci.
how: Supply the existing PAT, public HTTPS deployment URL and independently known project key. Current READ/VIEW permissions apply. Catalog reachability does not identify the actor. Current OAS JSON deployment parity remains unverified.
from: developer.atlassian.com
  Public HTTPS Bamboo Deployment URL — Existing public DNS HTTPS origin, optionally its actual single context segment such as /bamboo. Do not include /rest/api/latest.
  Bound Existing project key — Independently supplied project binding, verified in the current catalog before metadata reads. This is an access witness, not ownership.
  Existing Bamboo personal access token — Issued PAT without Bearer prefix. No Basic login, OAuth flow, issuance or inferred lifetime.
