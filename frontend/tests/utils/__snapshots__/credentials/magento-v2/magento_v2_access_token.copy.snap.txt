## magento_v2_access_token (Magento V2)
name: Access token
line: Paste an access token from Magento V2.
how: Paste the store REST root and an existing admin access token authorized for your operations. Admin tokens normally expire after four hours; replace expired tokens manually. Customer tokens cannot access these admin endpoints. An integration access token works only when the store already permits standalone bearer tokens. NoClick does not change that setting or request tokens. This connects Magento Open Source / Adobe Commerce on-premises or PaaS, not Adobe Commerce as a Cloud Service.
from: developer.adobe.com
  Store REST root — Full HTTPS root including store code, for example https://shop.example.com/rest/default. Include a subdirectory if Magento is installed in one.
  Access token — Paste the token itself, without Authorization or Bearer.
