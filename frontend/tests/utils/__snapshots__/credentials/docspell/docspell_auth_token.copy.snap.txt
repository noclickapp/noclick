## docspell_auth_token (Docspell)
name: Auth token
line: Paste an auth token from Docspell.
from: docspell.org
  Instance HTTPS origin — One public HTTPS origin, with no credentials/path/query/fragment. API paths are fixed /api/v1. Hosted/self-hosted instance version parity is unverified.
  Existing user token — Supplied existing authenticated-user token, X-Docspell-Auth header only. No login, admin/share token, JWT parsing or mint/refresh/extend.
