## lokalise_api_token (Lokalise)
name: API token
line: Paste an API token from Lokalise.
how: In Lokalise, open your avatar > Profile settings > API tokens. Paste a personal API token. Choose read/write for writes; read-only tokens support reads. You need an admin role in each project you access. Listing your projects checks the connection, but does not verify write permissions.
