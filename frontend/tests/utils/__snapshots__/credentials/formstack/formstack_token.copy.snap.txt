## formstack_token (Formstack)
name: Personal access token
line: Paste a personal access token from Formstack.
how: In Formstack Administration, open Personal Access Tokens and generate a token. An organization admin must enable token creation for your user, and your account needs the Forms API add-on. Paste the token itself, without Bearer. It follows your Formstack user permissions. NoClick checks the connection by reading your forms.
from: admin.formstack.com
  Personal access token
