## netbox_api_token (Netbox)
name: API token
line: Paste an API token from Netbox.
how: Enter your public HTTPS Netbox origin and paste an API token from your user profile. Prefer a v2 token (nbt_<key>.<token>); legacy v1 tokens are also supported. Enable writes and grant the relevant object permissions for write operations. Triggers also need add/delete permissions for extras.webhook and extras.eventrule. Private network instances cannot be reached from NoClick.
from: netbox.readthedocs.io
  NetBox URL — Public HTTPS origin, for example https://netbox.example.com. Use an instance served at the domain root.
  API token — Paste the token without the Authorization, Bearer or Token prefix.
