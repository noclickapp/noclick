## infisical_api_token (Infisical)
name: API token
line: Paste an API token from Infisical.
how: In Organization > Access Control > Machine Identities, configure Token Auth and add a token. Add the identity to each project with the required role. Paste that token here without Bearer. Replace expired tokens manually. Choose the cloud region containing your organization.
from: infisical.com
  API token
  Cloud region (optional)
