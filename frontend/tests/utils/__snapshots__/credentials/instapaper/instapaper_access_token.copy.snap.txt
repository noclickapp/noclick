## instapaper_access_token (Instapaper)
name: Access token
line: Paste an access token from Instapaper.
how: Generate a personal access token on Instapaper's Applications page and paste it here. Use your own account's token. Article content access by non-personal applications also requires an Instaparser API key; leave that field empty for personal use.
from: instapaper.com
  Access token
  Instaparser API key (optional)
