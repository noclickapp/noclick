## talkable_api_key (Talkable)
name: API key
line: Paste an API key from Talkable.
how: In Talkable Site Settings → API Integration, copy your API Key and Site ID. Use a REST API key, not an MCP credential.
from: talkable.com
  API key
  Site ID — Talkable Site ID from your dashboard, such as my-store. This scopes every request.
