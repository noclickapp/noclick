## wachete_api_token (Wachete)
name: API token
line: Paste an API token from Wachete.
how: Use the token returned by Wachete's API-key login (POST /thirdparty/v1/user/apilogin with the userId and apiKey from your Wachete profile). Paste only the returned token. Tokens expire: replace this credential's token when it expires. NoClick does not store your password or refresh the token.
from: wachete.com
  API token — Paste the token from the API login response, without the Bearer prefix.
