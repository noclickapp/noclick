## websupport_api_key (Websupport)
name: API key
line: Paste an API key from Websupport.
how: Supply an existing API key, signing secret and selected service reference. NoClick sends Basic key:fresh-signature, not key:secret, with matching UTC X-Date. Only protected v2 verification/zone/record metadata reads are implemented; no key issue, rotation, exchange or ownership claim.
from: rest.websupport.sk
  Existing API key
  Existing signing secret — Used locally for fresh HMAC-SHA1 signatures. The secret itself is never transmitted.
  Existing service Reference — Opaque supplied service route reference. No service catalog is invented; this need not equal a domain name.
