## quentn_api_key (Quentn)
name: API key
line: Paste an API key from Quentn.
how: In Quentn, open My account → API info. Copy the API URL and an API key into the fields below. API access requires a Basic account or higher. Use a separate key for NoClick.
from: help.quentn.com
  API URL — Your system URL, for example https://example.s1.quentn.com/public/api/v1.
