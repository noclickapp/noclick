## halopsa_access_token (Halopsa)
name: Access token
line: Paste an access token from Halopsa.
how: Paste an existing Halopsa API access token and your hosted instance URL. Obtain a token using your Halo API application's configured authentication flow. Grant permissions for the operations you use. Tokens expire; replace the token when it expires. This connection does not refresh tokens. Hosted halopsa.com instances are supported.
from: halopsa.com
  Instance URL — For example https://yourcompany.halopsa.com
  Access token
