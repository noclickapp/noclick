## bsc_designer_api_token (Bsc Designer)
name: API token
line: Paste an API token from Bsc Designer.
how: In Bsc Designer, open Settings, then Integrations, then Add API Key. Paste the generated token here. NoClick sends it in the token header to www.webbsc.com. Connecting reads the scorecards owned by your account.
