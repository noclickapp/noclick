## datarobot_api_token (Datarobot)
name: API token
line: Paste an API token from Datarobot.
how: In Datarobot, select the user icon, then API keys and tools. Under Personal API keys, create or copy a key. Paste it here without the Bearer prefix. This integration connects to app.datarobot.com. Project access confirms the connection; each write still needs the corresponding account permission.
