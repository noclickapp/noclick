## transloadit_token (Transloadit)
name: Bearer access token
line: Paste a bearer access token from Transloadit.
how: Paste an API2 bearer access token without the Bearer prefix. Create it server-side using your Auth Key and Auth Secret with audience api2. Request assemblies:read, assemblies:write, templates:read, templates:write, template_credentials:read, template_credentials:write and assembly_notifications:write for all operations. Tokens expire (normally after six hours); replace the token when it expires. NoClick does not renew it. Connection checks list your own Templates and require templates:read.
from: transloadit.com
