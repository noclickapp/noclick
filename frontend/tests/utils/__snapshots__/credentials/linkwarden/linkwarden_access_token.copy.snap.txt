## linkwarden_access_token (Linkwarden)
name: Access token
line: Paste an access token from Linkwarden.
from: docs.linkwarden.app
  Instance HTTPS origin — One public HTTPS origin, with no credentials/path/query/fragment. API paths are fixed /api/v1. Hosted/self-hosted instance version parity is unverified.
  Existing access token — Supplied existing access token, Authorization Bearer header only. No login, JWT parsing, token mint/refresh or alternate auth.
