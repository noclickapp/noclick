## talenthr_api_key (Talenthr)
name: API key
line: Paste an API key from Talenthr.
how: In Talenthr, open Settings → Domain settings → API and copy an API key. Paste the key alone. NoClick sends it as the Basic username with an empty password. A read-only key supports reads; writes require a full key and the appropriate permissions.
from: help.talenthr.io
  API key
