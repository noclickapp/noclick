## wheelbase_api_token (Wheelbase)
name: API token
line: Paste an API token from Wheelbase.
how: Paste an existing Wheelbase Partner API bearer token. Use a production token for api.wheelbasepro.com, without the Bearer prefix. The token needs the read/write scopes for your selected operations; dealer-only operations also need a dealer-scoped token. NoClick does not mint or refresh tokens. Replace an expired or revoked token here. Connection checks read only the current credential at /v1/me.
from: api.wheelbasepro.com
  API token
