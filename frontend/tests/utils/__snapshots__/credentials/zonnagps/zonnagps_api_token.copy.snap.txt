## zonnagps_api_token (Zonnagps)
name: API token
line: Paste an API token from Zonnagps.
how: In Zonnagps, open Settings → Integrations and create a dedicated API key. Paste the key shown once, without Bearer. Enable assets.list for connection evidence and each action's documented scope. Triggers also need webhooks.create and webhooks.delete; older keys only support reads.
