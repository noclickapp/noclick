## lumapps_access_token (Lumapps)
name: Supplied access token
line: Paste a Supplied access token from Lumapps.
how: Supply an already issued Lumapps bearer token, its actual expiry, organization ID and production cell API origin. The node does not create tokens, impersonate users or run browser OAuth.
from: developer.lumapps.com
  Issued access token
  Platform Cell API origin — Use your actual platform cell, for example https://go-cell-001.api.lumapps.com.
  Organization ID — Actual Lumapps customer/organization ID. Token owner and instances are checked against it.
  Actual token expiry — ISO 8601 timestamp with timezone. Renew externally; no inferred token lifetime.
