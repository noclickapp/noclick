## senta_api_key (Senta)
name: API key
line: Paste an API key from Senta.
how: Enter your Senta workspace subdomain and paste its API key. In Senta Settings > Users, choose Add integration, name it NoClick, and generate an API key. Regenerating a key revokes its predecessor. NoClick sends it in the x-auth header to your workspace only.
from: support.senta.co
  Workspace subdomain — For acme.senta.co, enter acme.
  API key
