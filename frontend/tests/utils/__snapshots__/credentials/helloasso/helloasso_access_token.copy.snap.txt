## helloasso_access_token (Helloasso)
name: Access token
line: Paste an access token from Helloasso.
how: Paste an existing Helloasso access_token without the Bearer prefix. Access tokens expire after 30 minutes: replace an expired token here. NoClick does not request or refresh tokens. Organization clients can access their own organization; partner tokens need authorization for private organization data. Enable AccessPublicData for the connection check and the privileges and roles required by each operation.
