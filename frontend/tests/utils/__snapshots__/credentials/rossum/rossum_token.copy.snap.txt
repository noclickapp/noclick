## rossum_token (Rossum)
name: API token
line: Paste an API token from Rossum.
how: Paste an already-issued Rossum Bearer token and exact tenant origin. Bind your organization ID from Rossum. This connection does not log in, exchange one-time tokens, refresh, or log out. The documented default token lifetime is 162 hours, but a token can expire sooner or be revoked. Organization reachability proves this resource binding, not user identity or every queue permission.
from: example.app.rossum.ai
  Rossum tenant origin — Exact HTTPS origin, without /api, a path, port, query or fragment.
  Rossum organization ID — Positive ID of the organization this connection may use.
  Issued Rossum API token
