## jira_software_server_token (Jira Software Server)
name: Personal access token
line: Paste a personal access token from Jira Software Server.
how: In Jira Server/Data Center 8.14 or later, open Profile > Personal access tokens and create a token. Paste it with your instance URL, including any context path such as /jira. The token uses your Jira permissions. Your instance must be publicly reachable; prefer HTTPS. Private network hosts and redirects are refused.
from: confluence.atlassian.com
  Jira instance URL — Instance base URL, for example https://jira.example.com/jira. Omit /rest.
  Personal access token — Paste the token itself, without the Bearer prefix.
