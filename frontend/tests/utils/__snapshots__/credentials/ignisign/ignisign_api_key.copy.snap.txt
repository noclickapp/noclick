## ignisign_api_key (Ignisign)
name: API key
line: Paste an API key from Ignisign.
how: Copy your application ID and its environment API key from the Ignisign console. Choose the matching environment. NoClick sends the key as a Bearer token to api.ignisign.io. Connecting reads the application context to verify access.
from: console.ignisign.io
  API key
  Application ID
  Environment (optional)
