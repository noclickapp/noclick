## gusto_access_token (Gusto)
name: Access token
line: Paste an access token from Gusto.
how: Paste an existing company-level access token from your approved Gusto integration and select its environment. Tokens expire after two hours; replace an expired token here. Your integration must grant the scopes listed in each operation's description.
from: docs.gusto.com
  Access token — Company-level Bearer access token issued by your approved Gusto integration. Expires after two hours.
  Environment (optional) — Use demo for tokens from api.gusto-demo.com; production for api.gusto.com.
