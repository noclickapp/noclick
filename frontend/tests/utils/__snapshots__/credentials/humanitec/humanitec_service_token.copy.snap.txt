## humanitec_service_token (Humanitec)
name: Service user token
line: Paste a service user token from Humanitec.
from: developer.humanitec.com
  Service token — Already issued service-user API token; sent only as Bearer to api.humanitec.io. No browser login, OAuth app, refresh or token mint is configured.
  Organization ID — Exact existing Humanitec organization ID. All API paths and saved-authority checks remain scoped to this organization.
  Allow Metadata Writes (optional) — Off by default. Allows explicitly confirmed app creation without an environment and app/environment name changes. Notifications/automation effects are not assumed suppressed; irreversible cascading deletes are omitted.
