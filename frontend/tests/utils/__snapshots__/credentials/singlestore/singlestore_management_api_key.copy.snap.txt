## singlestore_management_api_key (Singlestore)
name: Management API
line: Enter the management API key and SingleStore organization ID for Singlestore.
how: Use an issued hex-encoded Management API key for one organization and that organization's ID. The API key's existing permissions and expiration apply. No OAuth application, key minting or refresh is performed.
from: docs.singlestore.com
  Management API key
  SingleStore organization ID — Expected orgID returned by the protected current-organization route. This key is bound to one organization.
