## qonto_api_key (Qonto)
name: API key
line: Paste an API key from Qonto.
how: In Qonto, select your organization, then Integrations and Partnerships > API key. Copy its login and secret key. NoClick sends login:secret-key directly to Qonto. API keys support the reads and bookkeeping writes shown here; payment transfers require OAuth and are not offered.
from: docs.qonto.com
  Organization login — The organization's API login, for example pied-piper-7132; not your email address.
  Secret key
