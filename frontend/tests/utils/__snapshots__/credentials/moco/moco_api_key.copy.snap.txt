## moco_api_key (Moco)
name: API key
line: Paste an API key from Moco.
how: In Moco, open your profile's Integrations tab and copy the API key. Enter the account subdomain from your Moco URL, such as mycompany. An account API key from Settings > Extensions > API & Webhooks also works; writes require full access. Requests use the key's permissions and user identity.
from: docs.mocoapp.com
  Account subdomain — Only the account name before .mocoapp.com, without https:// or a path.
