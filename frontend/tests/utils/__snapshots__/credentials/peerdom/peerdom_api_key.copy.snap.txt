## peerdom_api_key (Peerdom)
name: API key
line: Paste an API key from Peerdom.
how: Create an API key in your Peerdom organization's settings and paste it here. API access requires an active paid subscription or trial. The key selects the organization and is sent as X-Api-Key to api.peerdom.app.
from: api.peerdom.org
