## cloudzero_api_key (Cloudzero)
name: Existing API key
line: Paste an Existing API key from Cloudzero.
how: Supply an existing Cloudzero key with fixed read scopes: billing:read_dimensions, billing:read_costs, views:read_views and views:read_view for the operations used. Raw Authorization header without Bearer on fixed api.cloudzero.com. Managed send-only telemetry keys do not imply read access. The protected dimensions check proves reachability only, never principal/organization identity, all scopes or plan entitlement. HTTP403 is a request refusal with unknown key/scope/role/plan cause. No key issuance, environment fallback, OAuth, ingestion or account action.
