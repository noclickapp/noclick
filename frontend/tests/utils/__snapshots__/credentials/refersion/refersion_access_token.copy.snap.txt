## refersion_access_token (Refersion)
name: Access token
line: Paste an access token from Refersion.
how: In Refersion, open Settings → Integrations → Refersion API Keys and generate an OAuth client. Follow the linked guide to exchange its Client ID and Client Secret for an access token, using token_type=long_lived for a 90-day token. Paste only the returned access_token here. Replace it when it expires; issuing another token of the same lifetime immediately revokes the previous token. NoClick does not issue or refresh tokens.
