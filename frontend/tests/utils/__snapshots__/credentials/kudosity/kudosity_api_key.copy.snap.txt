## kudosity_api_key (Kudosity)
name: API key
line: Paste an API key from Kudosity.
how: In your Kudosity account, open Settings and scroll to API Settings. Copy your Messaging API key and paste it here. NoClick sends it in x-api-key to api.transmitmessage.com. Legacy TransmitSMS API keys and secrets use a different API.
from: developers.kudosity.com
