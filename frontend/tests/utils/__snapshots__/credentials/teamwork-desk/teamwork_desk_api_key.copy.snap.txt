## teamwork_desk_api_key (Teamwork Desk)
name: API key
line: Paste an API key from Teamwork Desk.
how: In Teamwork Desk, open your avatar → View Profile → API Keys → Create an API key. Paste the key and your Teamwork site URL. Use the US or EU teamwork.com URL for your site.
from: apidocs.teamwork.com
  API key
  Teamwork Desk site URL — For example https://acme.teamwork.com or https://acme.eu.teamwork.com; a pasted Desk page URL is accepted.
