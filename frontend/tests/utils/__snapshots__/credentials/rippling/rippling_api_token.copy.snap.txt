## rippling_api_token (Rippling)
name: API token
line: Paste an API token from Rippling.
how: In Rippling, open Tools → Developer → API Tokens and create a token. Select companies.read for connection verification, workers.read, departments.read and departments.read-write, leave-requests.read and leave-requests.read-write, leave-types.read, leave-balances.read, supergroups.read and supergroups.read-write for the operations you use. Your permission profile and Rippling API plan also limit access. Copy the token once and paste it here.
from: app.rippling.com
  API token — Paste the token generated in Rippling's Developer app.
