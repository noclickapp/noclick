## elasticsearch_api_key (Elasticsearch)
name: Cluster URL and API key
line: Enter the cluster URL and API key for Elasticsearch.
how: Create an API key in Kibana → Stack Management → API Keys and paste the encoded value here.
from: elastic.co
  Cluster URL — Your Elasticsearch endpoint, e.g. https://my-deployment.es.us-central1.gcp.cloud.es.io
  API key — Encoded Elastic API key (the value shown after creating a key in Kibana → Stack Management → API Keys)
