## forcemanager_session_key (Forcemanager)
name: Session key
line: Paste a Session key from Forcemanager.
how: Paste an existing session token from the Forcemanager v4 POST /login response. Obtain it with your public API key as username and private API key as password; an admin finds these under Settings > Integrations > API key. NoClick sends the token as X-Session-Key to the production API. If it expires, obtain a new token and replace it here.
from: developer.forcemanager.com
