## postgres_credentials (Postgres)
name: Host, database, username and password
line: Enter the host, database, username and password.
  Host — PostgreSQL server hostname or IP address
  Port (optional) — PostgreSQL server port (default: 5432)
  Database — Name of the database to connect to
  Username — PostgreSQL username
  Password — PostgreSQL password
  SSL mode (optional) — SSL connection mode (defaults to require)
