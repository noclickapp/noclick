## printful_private_token (Printful)
name: Private token
line: Paste a private token from Printful.
how: Use an already issued traditional Printful token with the required scopes. Store metadata requires stores_list. Read scopes do not authorize writes. No token is created here.
from: developers.printful.com
  Bound store ID — The explicitly selected store authorized by this token. This binding cannot be overridden by operation inputs.
  Private token
  Issued access Level — Use the actual token access level. Account tokens send X-PF-Store-Id; store tokens use their issued store context.
  Issued expiry (UNIX seconds) (optional) — Private tokens cannot refresh. If known, supply the actual expiry; absent means unknown, not perpetual.
