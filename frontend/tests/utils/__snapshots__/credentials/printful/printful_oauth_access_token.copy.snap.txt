## printful_oauth_access_token (Printful)
name: Issued OAuth access token
line: Paste an Issued OAuth access token from Printful.
how: Manual already-issued store-level Public App access only. Copy actual bearer token type and expires_at. OAuth installation, client credentials and rotating refresh are not implemented here.
from: developers.printful.com
  Bound store ID — The explicitly selected store authorized by this token. This binding cannot be overridden by operation inputs.
  Already Issued access token
  Issued expiry (UNIX seconds) — Public App access tokens expire after one hour. This manual credential does not exchange or refresh them.
