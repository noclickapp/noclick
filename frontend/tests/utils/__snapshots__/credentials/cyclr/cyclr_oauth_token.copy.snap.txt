## cyclr_oauth_token (Cyclr)
name: OAuth token
line: Paste an OAuth token from Cyclr.
how: Supply an already issued private console-level Cyclr API OAuth Bearer token, its region and selected account API ID. No exchange, client-secret storage, refresh or token minting occurs. Account-level DataOnDemand, MCP and webhook tokens are distinct and not substitutes for console API grants. Actual expiry/permissions remain Cyclr authority.
from: community.cyclr.com
  Console OAuth access token
  Cyclr region (optional) — Use the region of the console that issued this token. Private-instance URLs are not accepted.
  Selected account API ID — A partner-accessible AccountResponseModel.Id; this saved value supplies X-Cyclr-Account. It is not a user or principal identity.
