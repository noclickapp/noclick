## neetoform_api_key (Neetoform)
name: API key
line: Paste an API key from Neetoform.
how: In your workspace Admin panel, open API keys, add a General key, and copy it. Paste the key and the workspace subdomain from your workspace URL. Zapier keys are only for Zapier. NoClick sends the key to this workspace's Neetoform API and checks it by listing your forms.
from: apidocs.neetoform.com
  Workspace subdomain — The part before .neetoform.com in your workspace URL, for example acme.
  API key
