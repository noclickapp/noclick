## powerdns_api_key (Powerdns)
name: API origin and API key
line: Enter the API origin and API key.
how: Supply an existing X-API-Key and a publicly reachable HTTPS API origin. The selected server ID must be present in the protected catalog with daemon_type authoritative. localhost is the documented server resource label, not the API host. This proves resource access, not a user or tenant identity. No key issuance, webserver enabling, trust changes or private network workaround.
  API origin — Exact public HTTPS origin, e.g. https://dns.example.com:8443. No /api/v1 path, credentials, query or fragment. DNS resolution and connection remain strictly public.
  API key
  Server ID (optional) — Exact protected catalog ID. The documented localhost value is a resource label, never a host or networking exception.
