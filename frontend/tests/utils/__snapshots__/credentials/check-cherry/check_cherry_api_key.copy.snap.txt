## check_cherry_api_key (Check Cherry)
name: Integration key
line: Paste an integration key from Check Cherry.
how: In Check Cherry, open Manage → Business Settings → Integrations → API Overview → API Keys. Create an Integration Key with lead_read for the connection check and the read/write permissions needed for your operations. Paste the key here; NoClick sends it in the Api-Key header. Keys cannot exceed their creator's permissions.
