## super_dispatch_api_key (Super Dispatch)
name: Carrier API key
line: Paste a Carrier API key from Super Dispatch.
how: Contact Super Dispatch support for a Carrier API key and paste it here without the Bearer prefix. An existing Carrier API access token also works until it expires; replace it when needed. NoClick sends it only to carrier.superdispatch.com. Connecting reads the carriers associated with your application; it does not verify permission for every operation. Shipper and Pricing Insights credentials are separate and are not supported by these operations.
