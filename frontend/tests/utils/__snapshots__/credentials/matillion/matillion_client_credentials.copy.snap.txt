## matillion_client_credentials (Matillion)
name: Maia (Matillion) client ID and secret
line: Paste a Maia (Matillion) client ID and secret from Matillion.
how: Use an existing issued API client ID/secret. Native OAuth client_credentials sends a URL-encoded form to id.core.matillion.com/oauth/dpc/token with fixed audience https://api.matillion.com; resource calls use Bearer. Tokens remain in memory for one operation and are never persisted or returned. No app registration, user login, invented refresh token or role assignment. Actual account/project/environment roles and execution/credit access depend on the credential.
