## outseta_api_key (Outseta)
name: API key
line: Paste an API key from Outseta.
how: In Outseta, open Settings > Integrations > API Keys. Paste the API key and secret, and enter your account subdomain or admin URL. These server-side keys grant full account access. NoClick reads a page of CRM people to check the connection.
from: docs.outseta.com
  Account subdomain — The part before .outseta.com, or your HTTPS Outseta admin URL.
  API key
  API secret
