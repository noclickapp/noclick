## responder_access_token (Responder)
name: Access token
line: Paste an access token from Responder.
how: Paste an existing Responder V2 account access token, without Bearer. The API documentation describes obtaining access_token through /oauth/token using a support-issued API client and your user_token from Settings > External connections (API). A user_token alone is not an access token. NoClick uses the supplied access token and does not create or refresh it. Replace it here if Responder expires or revokes it.
from: app.swaggerhub.com
  Access token — Account access_token returned by the Responder V2 token endpoint. Omit Bearer.
