## mercury_api_token (Mercury)
name: API token
line: Paste an API token from Mercury.
how: Create an API token in Mercury Settings > API. Paste the entire token, including secret-token: when present. Choose read-only access for reads or the permissions needed for payments and other writes. Read-write tokens require Mercury's IP allowlist.
from: app.mercury.com
  API token — Your Mercury API token, including its secret-token: prefix. Omit the Bearer prefix.
