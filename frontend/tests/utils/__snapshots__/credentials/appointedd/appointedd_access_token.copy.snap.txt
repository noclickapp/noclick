## appointedd_access_token (Appointedd)
name: Access token
line: Paste an access token from Appointedd.
how: Create an OAuth client in Appointedd's API integration settings, then use Create OAuth Token to generate a bearer access token. Paste only the token here. Appointedd supports long-lived tokens; choose an expiry appropriate for your account and replace the token before it expires. NoClick does not refresh this manually supplied token.
