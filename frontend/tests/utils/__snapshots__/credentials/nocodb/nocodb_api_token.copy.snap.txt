## nocodb_api_token (NocoDB)
name: API token
line: Paste an API token from NocoDB.
how: Create a scoped API token under Account settings → API Tokens. Grant read/write access for the operations you use.
from: app.nocodb.com
  API token — A NocoDB API token with access to the bases used by this workflow.
  NocoDB URL (optional) — Your NocoDB Cloud or self-hosted HTTPS origin (no /api/v3 suffix).
