## open_sea_api_key (Open Sea)
name: API key
line: Paste an API key from Open Sea.
how: Paste an OpenSea API key. NoClick sends it as x-api-key to api.opensea.io. The connection check reads public collections and proves API reachability, not wallet ownership. Listings and offers require an already-signed Seaport order; NoClick does not sign transactions.
