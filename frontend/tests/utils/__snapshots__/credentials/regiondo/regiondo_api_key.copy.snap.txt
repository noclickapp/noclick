## regiondo_api_key (Regiondo)
name: API key
line: Paste an API key from Regiondo.
how: Paste the public and private API keys from your Regiondo account. Requests are HMAC-SHA256 signed and sent only to api.regiondo.com. Supplier and partner operations require the corresponding account access. Connection checks list your account's active holds; an empty list proves API access but cannot name the account.
from: sandbox-api.regiondo.com
