## wayfront_api_token (Wayfront)
name: API token
line: Paste an API token from Wayfront.
how: Paste your Wayfront workspace URL and existing API bearer token. Use a token with permission for your chosen operations. Listing clients verifies access to workspace data; it does not verify write permissions.
from: wayfront.com
  Workspace URL — Your HTTPS workspace origin, such as https://example.wayfront.com.
  API token
