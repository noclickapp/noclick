## mercado_pago_access_token (Mercado Pago)
name: Access token
line: Paste an access token from Mercado Pago.
how: Open your Mercado Pago application, choose production or test credentials, and paste its Access Token. Use the token for the account you want to automate. Do not paste a Public Key or the Bearer prefix.
from: mercadopago.com
  Access token
