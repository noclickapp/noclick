## content_snare_personal_token (Content Snare)
name: Personal access token
line: Paste a personal access token from Content Snare.
how: In Content Snare, open Settings → Security → Personal access tokens and generate a token. Paste only the token, without Bearer. Select read_clients, write_clients, read_requests, write_requests, review_requests, read_templates, read_team_members for all these actions, or only the scopes you need. NoClick checks your name with /me. Tokens expire and must be rotated manually; rotation invalidates the old token.
