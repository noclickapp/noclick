## kontent_ai_api_key (Kontent AI)
name: Management API key
line: Paste a management API key from Kontent AI.
how: In Kontent.ai, open your environment's API keys and copy a Management API key and the environment ID. Paste the key without the Bearer prefix. The key must permit the operations you use. NoClick reads environment information to verify this connection. Replace expired keys manually.
from: app.kontent.ai
  Environment ID — The environment UUID from Kontent.ai API keys.
  Management API key
