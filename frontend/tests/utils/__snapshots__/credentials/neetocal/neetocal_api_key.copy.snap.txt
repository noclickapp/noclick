## neetocal_api_key (Neetocal)
name: API key
line: Paste an API key from Neetocal.
how: Create a workspace API key in Neetocal's Admin Panel → API keys. Paste the key and your workspace subdomain, for example spinkart for spinkart.neetocal.com. NoClick sends X-Api-Key only to this workspace's Neetocal API.
from: apidocs.neetocal.com
  API key
  Workspace subdomain — The workspace part of your Neetocal address, for example spinkart.
