## small_improvements_personal_access_token (Small Improvements)
name: Personal access token
line: Paste a personal access token from Small Improvements.
how: Ask Small Improvements to enable API access for your company. Then open Profile → Manage → API Access Tokens and create a token. Paste it here and select your company's data center. The token has the permissions of its employee account.
from: resources.small-improvements.com
  Personal access token
  Data center (optional) — Choose app for the US data center or eu for the EU data center.
