## gotify_client_token (Gotify)
name: Client token
line: Paste a client token from Gotify.
how: Enter your public HTTPS Gotify server URL and an existing client token (not an application token). Obtain a client token with POST /client using the Gotify API. NoClick checks access by listing your applications. Some administrative actions require session elevation on Gotify 3. Sending a message requires an application ID owned by your account.
from: gotify.net
  Server URL — Public HTTPS server URL, including a reverse-proxy path prefix if used.
  Client token
