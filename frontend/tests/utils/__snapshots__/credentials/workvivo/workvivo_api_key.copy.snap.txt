## workvivo_api_key (Workvivo)
name: API key
line: Paste an API key from Workvivo.
from: developer.workvivo.com
  Tenant API base URL — Copy the regional Base URL from API Keys & JWT Settings, adding /v1. For example https://api.workvivo.com/v1 or https://api.us2.workvivo.com/v1. All requests use production data.
  Workvivo Organisation ID — Exact Workvivo-Id header shown by your tenant administrator; not a user identity.
  API key — Static app API key with the endpoint and visibility permissions you need. This is not OAuth or a user login.
