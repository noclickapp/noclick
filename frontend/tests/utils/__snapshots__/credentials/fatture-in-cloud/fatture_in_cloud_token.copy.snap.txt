## fatture_in_cloud_token (Fatture In Cloud)
name: Access token
line: Paste an access token from Fatture In Cloud.
how: Paste a manually generated access token from Settings > Connected Applications. Token generation requires a Fatture In Cloud application Client ID. Select the companies and permissions you need: entity.clients:r/a, entity.suppliers:r/a, products:r/a, issued_documents.<document type>:r/a and received_documents:r. Tokens do not expire but can be revoked. Listing companies proves access; each operation still needs its own permissions.
