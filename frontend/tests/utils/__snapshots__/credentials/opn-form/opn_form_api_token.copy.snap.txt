## opn_form_api_token (Opn Form)
name: API token
line: Paste an API token from Opn Form.
how: Paste a Personal Access Token from OpnForm Settings → Access Tokens. Include workspaces-read for connection evidence, forms-read for form reads, forms-write for changes, workspace-users-read for members, and manage-integrations for webhooks. Workspace changes need workspaces-write. NoClick sends the token only to api.opnform.com.
