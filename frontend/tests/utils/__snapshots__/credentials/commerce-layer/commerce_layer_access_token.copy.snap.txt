## commerce_layer_access_token (Commerce Layer)
name: Access token
line: Paste an access token from Commerce Layer.
how: Paste an existing integration access token and your organization slug. Obtain the token using your integration API credentials and the documented client_credentials grant. Integration tokens expire (the documented example lasts 7200 seconds); replace an expired token here. NoClick does not obtain or refresh tokens. Your integration role must permit the operations you use. Listing SKUs verifies catalog read access, not every write permission.
from: docs.commercelayer.io
  Organization slug — The subdomain in https://yourdomain.commercelayer.io; paste the slug or organization URL.
