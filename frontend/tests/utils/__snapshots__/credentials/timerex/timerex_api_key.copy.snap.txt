## timerex_api_key (Timerex)
name: API key
line: Paste an API key from Timerex.
how: In Timerex, open Dashboard → Team Settings → Developer Tools → Timerex API. Create and copy the 64-character API key. Paste it here; it grants access only to the team that issued it. Enable API integration in that team's Security settings.
