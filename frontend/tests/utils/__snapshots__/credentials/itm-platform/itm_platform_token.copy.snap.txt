## itm_platform_token (Itm Platform)
name: Session token
line: Paste a Session token from Itm Platform.
how: Enter your company URL segment and paste an existing session token obtained using Itm Platform's documented API-key login. Paste the Token value, without a header prefix. Tokens expire; replace an expired token here. NoClick checks account users and never creates a new session for you.
from: developers.itmplatform.com
  Company URL segment — The companyURL segment from your Itm Platform API URL, for example companyURL. Enter only the segment.
  Session token
