## cliengo_api_token (Cliengo)
name: API token
line: Paste an API token from Cliengo.
how: In Cliengo, open Integrations → API, generate a token with the permissions your operations need, and paste it here. Contacts need clients_read/clients_write; conversations, tags and phases need conversations_read/conversations_write; channels need websites_read; users need users_read. Account reads prove the connection. Production tokens use connect.cliengo.com; sk_test_ tokens use connect.stagecliengo.com.
