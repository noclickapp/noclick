## airbyte_basic (Airbyte)
name: Basic auth
line: Enter the server URL, username and password for Airbyte.
how: Enter your self-hosted Airbyte server origin and its Configuration API username and password. Use HTTPS for a remote server. This connects the Configuration API, not the Airbyte Cloud public API. Hosted NoClick can reach public servers; private servers require a self-hosted NoClick deployment with private outbound access configured.
