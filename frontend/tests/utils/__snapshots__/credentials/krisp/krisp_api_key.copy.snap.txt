## krisp_api_key (Krisp)
name: Personal API key
line: Paste a personal API key from Krisp.
from: meeting-api-docs.krisp.ai
  Personal API key — Krisp Settings → Integrations → API. A Read scope and an eligible paid/trial plan are required.
  Configured key Scopes (optional) — Copy the key's configured Read/Write scopes. This form does not grant permissions. These operations require Read.
  Actual key expiry (optional) — Optional actual aware ISO 8601 expiry. Leave unset for a no-expiration key; do not invent a new 90-day lifetime.
  Expected Krisp user ID (optional)
  Expected team ID (optional)
  Expected workspace ID (optional) — Optional expected IDs from /me. A mismatch fails before meeting data is requested.
