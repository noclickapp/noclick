## giftbit_api_token (Giftbit)
name: API token
line: Paste an API token from Giftbit.
how: In your Giftbit account, open Account → API keys and generate an API token. Paste the token without the Bearer prefix and select its environment. Testbed and Production use separate tokens. NoClick checks the connected account with Giftbit's read-only ping endpoint.
from: docs.giftbit.com
  API token
  Environment (optional) — Use the environment where this token was created. Production orders spend real funds.
