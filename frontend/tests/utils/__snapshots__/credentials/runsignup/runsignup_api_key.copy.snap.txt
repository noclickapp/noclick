## runsignup_api_key (Runsignup)
name: API key
line: Paste an API key from Runsignup.
how: Paste your Runsignup v2 API key and matching API secret. Legacy API keys and API caller registration tokens are different credentials. NoClick sends the key in rsu_api_key and the secret in X-RSU-API-SECRET to api.runsignup.com. The key needs permission for each selected race and action; connection verification names the key's entity and does not grant permissions.
from: runsignup.com
  API key
  API secret
