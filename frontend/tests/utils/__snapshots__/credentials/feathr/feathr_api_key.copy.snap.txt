## feathr_api_key (Feathr)
name: API key
line: Paste an API key from Feathr.
how: Create an API key in the Feathr app and paste the secret shown at creation. Grant only the resource scopes needed by your operations (for example persons:read and persons:write). NoClick checks the key with GET /me; that confirms the account, not permission for every operation.
from: docs.feathr.co
  API key — Paste your Feathr API key without the Bearer prefix.
