## abyssale_api_key (Abyssale)
name: API key
line: Paste an API key from Abyssale.
how: In Abyssale, open Workspace settings → API key and copy an existing API key. An Admin can create one there. Paste the key alone. NoClick sends it in x-api-key to api.abyssale.com. Generation uses your workspace credits; a webhook signing secret is a different credential.
from: developers.abyssale.com
  API key
