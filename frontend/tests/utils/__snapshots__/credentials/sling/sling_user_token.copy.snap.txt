## sling_user_token (Sling)
name: User token
line: Paste an user token from Sling.
how: Supply an existing user-bound Sling token and organization ID. The header is Authorization: token, without Bearer. Access follows the issuing user's permissions. Console-session tokens stop working on logout. No login, session mutation, token minting or refresh is performed.
from: github.com
  Sling user token
  Sling organization ID — The organization whose protected details you can read. This supplied ID is a resource parent, not proof of the token's current organization or principal identity.
