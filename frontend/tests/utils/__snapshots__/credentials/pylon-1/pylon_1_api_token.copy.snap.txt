## pylon_1_api_token (Pylon 1)
name: API token
line: Paste an API token from Pylon 1.
how: An Admin creates a token in Settings > Integrations & dev > API tokens. Paste the token and select your tenant region. Its role controls access; Pylon API tokens have no separate scopes. NoClick checks /me to identify the connected organization.
from: app.usepylon.com

  Region (optional) — Region hosting your Pylon tenant.
