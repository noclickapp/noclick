## kantataox_api_token (Kantataox)
name: Personal bearer token
line: Paste a personal bearer token from Kantataox.
how: As a Kantata OX account administrator, register an application on the application management page and copy the personal OAuth bearer token from its page. Paste only the token. NoClick sends it only to api.mavenlink.com. The token inherits your Kantata permissions; a paid account is required to register applications.
from: app.mavenlink.com
  Personal bearer token
