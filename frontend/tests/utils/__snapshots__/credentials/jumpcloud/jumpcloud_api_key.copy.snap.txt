## jumpcloud_api_key (Jumpcloud)
name: API key
line: Paste an API key from Jumpcloud.
how: In the Jumpcloud Admin Console, open your username menu and My API Key. Paste your administrator API key. It grants your administrator's access; keep it private. Select the region containing your organization. Optionally enter an organization ID for multi-tenant access.
from: console.jumpcloud.com
  API key
  Region (optional)
  Organization ID (optional)
