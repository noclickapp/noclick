## spotio2_api_token (Spotio2)
name: API token
line: Paste an API token from Spotio2.
how: Paste an existing SPOTIO Bearer token without the Bearer prefix. SPOTIO documents exchanging the ClientId and Secret from Settings → Integrations → API Access at /api/users/apitoken. Tokens last two hours; replace an expired token here. NoClick sends this token only to api.spotio2.com.
from: app.spotio2.com
  API token
