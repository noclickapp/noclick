## smsapi_api_token (Smsapi)
name: API token
line: Paste an API token from Smsapi.
how: Paste a token generated in the Smsapi Customer Portal under API Settings → OAuth Tokens. Enable profile, sms, sms_sender and contacts access for the operations you use. NoClick sends it as a Bearer header only to api.smsapi.com. The profile read checks the account; write permissions remain subject to your token grants.
from: smsapi.com
  API token
