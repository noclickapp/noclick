## klicktipp_api_user (Klicktipp)
name: API user
line: Enter the API user username and API user password for Klicktipp.
how: Requires Klicktipp Premium or higher. Create a dedicated API User under My Account → Settings → User Account → Sub-Accounts, then enter its username and password. NoClick logs in for each operation and logs out afterward; sessions are never saved.
from: developers.klicktipp.com
  API user username — The dedicated API User, such as mainaccount-subaccountname.
  API user password
