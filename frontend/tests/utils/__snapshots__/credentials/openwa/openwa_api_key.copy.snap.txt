## openwa_api_key (Openwa)
name: API key
line: Paste an API key from Openwa.
how: Enter your publicly reachable HTTPS Openwa server origin and paste its API key. An operator key can send messages; a viewer key supports reads. NoClick lists the sessions visible to your key to check the connection. Use an already linked WhatsApp session.
from: github.com
  Server URL — Public HTTPS origin of your Openwa gateway, for example https://openwa.example.com.
  API key
