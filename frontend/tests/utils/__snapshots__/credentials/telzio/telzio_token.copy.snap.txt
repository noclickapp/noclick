## telzio_token (Telzio)
name: Token
line: Paste a token from Telzio.
how: Paste an existing Telzio claims_token, returned by Telzio's POST /v3/auth. Telzio documents this token for Bearer authorization on subsequent requests. Paste only the token, without Bearer. When it expires, replace it with a new token obtained from Telzio. NoClick does not sign in or renew tokens for you.
from: api.telzio.com
  Token
