## synap_pat (Synap)
name: Personal access token
line: Paste a personal access token from Synap.
how: In your Synap portal, open Settings → Automations → API and create a personal access token. Paste the entire token, including p:, and your Portal ID. V3 API access requires a Business or Enterprise plan. NoClick reads your user groups to check the connection; the token acts as its issuing administrator.
from: synap.ac
  Personal access token
  Portal ID — Your Synap organisation's Portal ID.
