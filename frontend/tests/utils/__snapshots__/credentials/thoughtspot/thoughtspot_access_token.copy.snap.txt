## thoughtspot_access_token (Thoughtspot)
name: ThoughtSpot tenant, bearer access token and ThoughtSpot organization ID
line: Enter the ThoughtSpot tenant, bearer access token and ThoughtSpot organization ID for Thoughtspot.
from: developers.thoughtspot.com
  ThoughtSpot tenant — Public HTTPS cluster origin, without /api or a path.
  Bearer access token — Already-issued scoped token. NoClick does not mint or refresh it.
  ThoughtSpot organization ID — Active org_id from the token scope. It is verified before operations; no organization switching occurs.
  Token Object GUID (optional) — Required for an object-scoped token. Leave empty for a full token; the provider scope is checked.
  Expected user GUID (optional) — Optional user binding checked against actual token and session evidence.
  Known token expiry (optional) — ISO timestamp with timezone. Omission means unknown; actual expiry is checked with token validation.
