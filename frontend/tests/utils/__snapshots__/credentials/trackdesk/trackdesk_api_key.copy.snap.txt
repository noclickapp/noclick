## trackdesk_api_key (Trackdesk)
name: API key
line: Paste an API key from Trackdesk.
how: In your Trackdesk program, open your name → Settings → Integrations → Personal access tokens. Generate an API key and paste it here with your program's tenant subdomain. The key inherits your account permissions.
from: developers.trackdesk.com
  Tenant subdomain — The tenant in https://your-program.trackdesk.com; you can also paste that program URL.
  API key
