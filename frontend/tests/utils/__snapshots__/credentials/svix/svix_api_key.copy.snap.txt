## svix_api_key (Svix)
name: API key
line: Paste an API key from Svix.
from: docs.svix.com
  Svix Environment region — Use the region of the environment that issued this key. No self-hosted or arbitrary API origin is accepted.
  Environment API key — Existing server-side Svix environment key. Development and production environments have separate keys; this is not an app-portal or polling-consumer token.
