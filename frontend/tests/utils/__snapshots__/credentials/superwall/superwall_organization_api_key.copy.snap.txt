## superwall_organization_api_key (Superwall)
name: Organization API key
line: Paste an organization API key.
how: Enter an issued organization key, its organization ID, approved project IDs and documented read scopes. These saved restrictions narrow this node and do not establish vendor permissions.
  Organization API key
  Organization ID — The numeric organization ID returned with your projects. It is checked against the provider, not decoded from the key.
  Approved project IDs — JSON string array of existing projects allowed for this workflow. Maximum 50 is a NoClick limit.
  Connection Witness project ID — One approved project for a protected read-only connection check.
  Read Scopes (optional) — Space-separated issued read scopes. Saved labels constrain this node; the provider independently checks actual key scopes and project access.
