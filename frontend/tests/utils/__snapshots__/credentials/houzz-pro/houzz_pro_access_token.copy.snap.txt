## houzz_pro_access_token (Houzz Pro)
name: Access token
line: Paste an access token from Houzz Pro.
how: Request a company service account from your Houzz representative. Follow the authentication guide to exchange its client ID and secret using grant_type=client_credentials and audience=https://pro-api.houzz.com, then paste the access_token here. Include read:projects for the connection check and the scopes required by your actions. Tokens expire: replace the token here when its expires_in lifetime ends. NoClick sends it only to pro-api.houzz.com and does not obtain or refresh it. Listing projects checks this company's project read access, not all write permissions.
