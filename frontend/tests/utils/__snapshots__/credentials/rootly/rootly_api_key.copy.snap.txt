## rootly_api_key (Rootly)
name: API key
line: Paste an API key from Rootly.
how: In Rootly, open the organization dropdown, then Organization Settings > API Keys. Create a key with access to the incidents and resources you want to automate, and paste the key here without the Bearer prefix. NoClick sends it only to api.rootly.com. Connecting reads your incidents; write permissions depend on the key's access.
