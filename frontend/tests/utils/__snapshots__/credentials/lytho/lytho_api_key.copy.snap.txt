## lytho_api_key (Lytho)
name: API key
line: Paste an API key from Lytho.
how: In Lytho DAM, open Settings → Advanced → API management. Add an API access key and paste its Value. The key is bound to your tenant. These operations use the published openapi.lytho.io/v1 API.
from: help.lytho.com
  API key
