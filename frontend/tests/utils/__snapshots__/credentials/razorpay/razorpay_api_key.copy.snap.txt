## razorpay_api_key (Razorpay)
name: API key
line: Paste an API key from Razorpay.
how: In Razorpay Dashboard, select Test or Live mode, then Account & Settings → API Keys. Paste the key ID and key secret from the same pair. Test keys operate on test data; live keys can create live orders, payment links and subscriptions. NoClick sends Basic authentication only to api.razorpay.com. Connecting reads your customers; it does not verify write permissions.
from: dashboard.razorpay.com
  Key ID
  Key secret
