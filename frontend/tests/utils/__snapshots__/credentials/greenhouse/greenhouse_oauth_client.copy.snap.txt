## greenhouse_oauth_client (Greenhouse)
name: Client ID and client secret
line: Enter the client ID and client secret for Greenhouse.
how: In Greenhouse API Credentials, create Harvest V3 (OAuth) credentials and grant the scopes required for the operations you use. Enter the Client ID and Client Secret. Greenhouse permits OAuth client credentials for custom integrations; one-click authorization-code login requires a Greenhouse partner app.
from: support.greenhouse.io
