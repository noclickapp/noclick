## zoho_cpaas_api_key (Zoho Cpaas Formerly Zeptomail)
name: API key
line: Paste an API key from Zoho Cpaas Formerly Zeptomail.
how: In your Agent, open SMTP/API > API Setup and copy the channel's API key. Each channel uses a separate key; attach the key for the action's channel. Paste only the key. SMS requires an India data-centre account. Email keys only allow sending, so their read-only connection verification is unavailable. Management APIs require OAuth and are not included.
from: zoho.com
  API key
  Key channel (optional) — Channel this key belongs to. Verification reads that channel's logs; email keys have no read probe.
