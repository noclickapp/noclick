## manifestly_api_key (Manifestly)
name: API key
line: Paste an API key from Manifestly.
how: An account admin creates an API key in Account Settings → Integrations and selects its department. Paste that key here. Calls act as the integration identity. For webhook triggers, also paste the separate signing secret from Workflow Hooks → Generate signing secret. Rotating that secret requires updating this connection.
from: manifest.ly
  API key
  Webhook signing secret (optional)
