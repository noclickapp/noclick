## ionoscloud_bearer (Ionoscloud)
name: Bearer token
line: Paste a bearer token.
how: Enter an existing Cloud API Bearer token and approved existing datacenter IDs. Supply a contract number only when your existing account requires one. Protected catalog access does not identify a principal or prove ownership.
  Bearer token
  Contract number (optional) — Optional exact existing X-Contract-Number integer. Bound to every request; no contract fallback.
  Approved Datacenter IDs (optional) — JSON string array of existing resource IDs, at most 50. Example: ["15f67991-0f51-4efc-a8ad-ef1fb31a480c"].
  Include resource Names (optional) — Opt in to datacenter/server names only. All links, entities, hostnames, users, network, boot and configuration data remain excluded.
