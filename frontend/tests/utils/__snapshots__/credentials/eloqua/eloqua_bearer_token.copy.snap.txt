## eloqua_bearer_token (Eloqua)
name: Oracle Eloqua Issued bearer token
line: Paste an Oracle Eloqua Issued bearer token from Eloqua.
from: docs.oracle.com
  Expected Eloqua site ID (optional)
  Expected Eloqua user ID (optional)
  Issued OAuth access token — Already issued by your registered Eloqua application. NoClick does not register an app or refresh this token.
  Actual token expiry — Use the issuing response's expires_in; do not assume the documentation example is your actual lifetime.
