## mews_tokens (Mews)
name: API tokens
line: Enter the client token and Property access token for Mews.
how: Paste your production Connector API client token and the property's access token, supplied by Mews for your enabled integration. Use a single-property access token, not a portfolio token. Demo tokens do not work on the production API. NoClick checks the property's configuration when you connect.
