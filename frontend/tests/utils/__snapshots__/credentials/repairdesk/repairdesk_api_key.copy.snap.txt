## repairdesk_api_key (Repairdesk)
name: API token
line: Paste an API token from Repairdesk.
how: Create an API token in Repairdesk Settings → Store → API Access → API Tokens. Grant Purchase Orders View for reads and polls, and Purchase Orders Update for status writes (Delete for deletion). Paste the token itself. Legacy store API keys are not accepted by v2. Tokens act on their issuing store unless an operation selects another store in the same business. Replace expired tokens in Repairdesk.
