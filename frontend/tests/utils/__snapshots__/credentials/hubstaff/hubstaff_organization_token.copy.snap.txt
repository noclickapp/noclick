## hubstaff_organization_token (Hubstaff)
name: Organization access token
line: Paste an organization access token from Hubstaff.
how: In Hubstaff, open Settings → All settings → Organization → Security & log in → API access tokens. Create an organization access token assigned to an active member with the permissions your workflow needs, then paste the secret shown once. These tokens start with hsoat_ and are sent directly as Bearer credentials. Personal access tokens from the developer portal require exchange and are not supported here. API access requires a Team plan or above.
from: support.hubstaff.com
  Organization access token — Paste the organization token secret without the Bearer prefix.
