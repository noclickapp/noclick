## knowify_session_token (Knowify)
name: Session token
line: Paste a Session token from Knowify.
how: Obtain a kAuth session token using Knowify's documented login endpoint. Paste kauthToken without the kauth prefix. Advisor accounts must first choose a tenant through advisor-assume. Tokens expire; replace an expired token here.
from: developer.knowify.com
  Session token — Your tenant-scoped Knowify kauthToken, without an Authorization prefix.
