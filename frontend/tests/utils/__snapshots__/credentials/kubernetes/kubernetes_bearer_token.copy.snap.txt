## kubernetes_bearer_token (Kubernetes)
name: Bearer token
line: Paste a bearer token from Kubernetes.
how: Paste the cluster API server URL and an existing bearer token, without the Bearer prefix. The API server must be publicly reachable over HTTPS. RBAC must allow listing namespaces for the connection check and the resources you automate. For a private certificate authority, paste the base64 certificate-authority-data from kubeconfig (or a PEM certificate). TLS verification is always enabled. Replace expiring tokens manually.
from: kubernetes.io
  API server URL — Public HTTPS cluster API origin, for example https://cluster.example.com:6443.
  Bearer token — An existing token with the RBAC permissions needed by your operations; omit the Bearer prefix.
  CA Certificate Data (optional) — Optional base64 certificate-authority-data from kubeconfig, or a PEM CA certificate. Leave empty to use public trusted certificate authorities.
