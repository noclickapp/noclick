## emnify_application_token (Emnify)
name: Application token
line: Paste an application token from Emnify.
how: In the Emnify Portal, open Integrations → Application tokens, create a token and copy it here. NoClick exchanges it for an authentication token before each operation. The token needs permission for the selected operation. Connection verification reads your organisation.
from: portal.emnify.com
