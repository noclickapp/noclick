## evoliz_api_keys (Evoliz)
name: API keys
line: Enter the Public API key, secret API key and company number for Evoliz.
how: In Evoliz, open Applications, enable the Evoliz API connector, then choose Create API Key. Paste both keys and your company number (shown below your name at the bottom left). NoClick exchanges these keys for a short-lived token and verifies access by reading your company.
from: evoliz.com
  Public API key
  Secret API key
  Company number — Your Evoliz customer number, shown below your name in the app.
