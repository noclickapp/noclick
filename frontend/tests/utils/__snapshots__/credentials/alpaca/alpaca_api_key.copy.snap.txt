## alpaca_api_key (Alpaca)
name: API key
line: Paste an API key from Alpaca.
how: In the Alpaca Trading Dashboard, generate an API key and paste its key ID and secret key. Choose the environment matching those keys: paper and live keys are different. Paper is the default. Live writes can place real trades. NoClick verifies the connection by reading your account; this does not prove permission to trade.
from: app.alpaca.markets
  API key ID
  API secret key
  Environment (optional) — Use the environment where these keys were generated.
