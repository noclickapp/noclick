## ritekit_client_id (Ritekit)
name: Client ID
line: Paste a client ID from Ritekit.
how: Create a token in the Ritekit developer dashboard, then paste its Client ID. Ritekit supports using this private value directly without OAuth. Keep it secret; NoClick sends it as the client_id query parameter to api.ritekit.com.
from: ritekit.com
  Client ID
