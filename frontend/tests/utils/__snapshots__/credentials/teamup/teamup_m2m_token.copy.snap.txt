## teamup_m2m_token (Teamup)
name: M2M token
line: Paste an M2M token from Teamup.
how: In Teamup Business Dashboard, open Settings → Integrations → API Integration → Options → View and Update Applications. Create an M2M token with the permissions your operations need and paste it here. Read-only tokens support reads only. Replace expired or revoked tokens here. This connection acts in provider mode; it does not sign in as a customer.
from: support.goteamup.com
  M2M token — Paste the M2M token only, without an Authorization prefix or your application client secret.
  Provider ID (optional) — Business ID from your Teamup customer site URL. Set this when the token can access multiple providers.
