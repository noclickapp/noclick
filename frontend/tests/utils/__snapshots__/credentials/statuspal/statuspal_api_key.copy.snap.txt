## statuspal_api_key (Statuspal)
name: API key
line: Paste an API key from Statuspal.
how: Supply an existing API key, region and selected organization ID. Authorization contains the raw key, without Bearer. Only protected organization status-page/service reads are exposed. Parsed catalog access, including an empty page, proves reachability; it does not identify a principal or prove organization ownership, all permissions, plan or private access. No key creation/exchange/refresh or environment fallback.
from: docs.statuspal.io
  Existing StatusPal API key
  StatusPal region (optional) — Fixed US statuspal.io or EU statuspal.eu API host. No arbitrary URL.
  Selected StatusPal organization ID — Existing organization numeric ID used for protected page catalog/detail. Resource reachability is not organization ownership.
