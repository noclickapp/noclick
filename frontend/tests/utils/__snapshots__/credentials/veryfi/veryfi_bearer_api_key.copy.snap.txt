## veryfi_bearer_api_key (Veryfi)
name: Bearer API key
line: Paste a bearer API key from Veryfi.
how: Recommended client-scoped Bearer key, full-access or explicitly route-scoped. Supply its matching CLIENT-ID, environment and signing secret if required. Route grants and expiry are enforced by Veryfi; no OAuth exchange, key administration or automatic refresh is performed.
from: docs.veryfi.com
  Veryfi Environment (optional) — Development uses the vendor staging model endpoint; it does not guarantee free or isolated processing. Confirm the environment shown with your issued key.
  Client ID — The CLIENT-ID belonging to the account that issued the API key.
  Client secret for Request signing (optional) — Optional in the public contract; supply it when your account requires signatures. Never retried without signing.
