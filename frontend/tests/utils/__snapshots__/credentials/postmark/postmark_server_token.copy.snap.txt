## postmark_server_token (Postmark)
name: Server API token
line: Paste a server API token from Postmark.
how: Open a server, then API Tokens, and copy its Server API Token. This token supports sending, templates, streams, messages, webhooks, suppressions, and statistics.
from: account.postmarkapp.com
  Server API token — Found in the Postmark server's API Tokens tab.
