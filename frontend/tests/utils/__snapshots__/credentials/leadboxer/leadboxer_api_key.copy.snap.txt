## leadboxer_api_key (Leadboxer)
name: API key
line: Paste an API key from Leadboxer.
how: Paste your Leadboxer API key and the email address of your Leadboxer user. An API license is required; contact Leadboxer for API access. NoClick sends the key in the x-api-key header to api.leadboxer.com and reads your datasets to check the connection.
from: developers.leadboxer.com
  API key
  Account email — Email address of your Leadboxer user; used by endpoints that require a user email.
