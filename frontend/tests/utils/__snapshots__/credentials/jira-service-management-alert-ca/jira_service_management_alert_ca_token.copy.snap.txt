## jira_service_management_alert_ca_token (Jira Service Management Alert Ca)
name: Service management Alert API token
line: Paste a service management Alert API token from Jira Service Management Alert Ca.
how: Paste your Atlassian account email, API token without scopes, and Jira Cloud ID. Your account needs permission to view or manage Operations alerts. Requests go to api.atlassian.com only.
from: id.atlassian.com
  Atlassian account email
  API token
  Cloud ID — The cloudId for your Jira Cloud instance, not the site URL.
