## formspark_api_token (Formspark)
name: API token
line: Paste an API token from Formspark.
how: Create an API token in the Formspark dashboard under API tokens and paste it here without the Bearer prefix. Include workspaces:read for the connection check, plus forms:read, forms:write, submissions:read, submissions:write or workspaces:write for the operations you use. Form and submission access requires an upgraded workspace. Tokens expire unless you choose Never; replace expired or revoked tokens manually.
from: dashboard.formspark.io
  API token
