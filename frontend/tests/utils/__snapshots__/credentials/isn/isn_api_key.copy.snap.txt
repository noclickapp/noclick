## isn_api_key (Isn)
name: API key
line: Paste an API key from Isn.
how: Paste your account's JSON API URL and the API access key and secret key used as the Basic-auth username and password. Use API keys with the permissions your workflow needs. The connection check reads the current user; it does not verify write permissions.
from: json.inspectionsupport.net
  ISN JSON API URL — Your account URL ending in /json, for example https://goisn.net/greenway/json
  API access key
  API secret key
