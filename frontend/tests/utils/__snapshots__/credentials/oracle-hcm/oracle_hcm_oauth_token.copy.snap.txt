## oracle_hcm_oauth_token (Oracle Hcm)
name: Supplied OAuth token
line: Paste a Supplied OAuth token from Oracle Hcm.
how: Supply an actual OAuth access token issued by the Oracle IAM confidential application configured for this exact Fusion tenant/resource audience. Paste the token only. Requested versus granted scope, role and audience remain issuer/provider authoritative; this manual family does not invent an OAuth popup, mint, refresh, client or broad grant.
from: docs.oracle.com
  Oracle Fusion tenant URL — The exact Oracle Fusion SaaS origin from your administrator's welcome email, such as https://tenant.fa.us2.oraclecloud.com. ERP/CX resource paths and custom/self-hosted aliases are not accepted.
