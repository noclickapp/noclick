## gleap_service_account (Gleap)
name: Service account token
line: Paste a service account token from Gleap.
how: Open your Gleap project, then Settings → Developer → API keys. Create a service account and paste its token. Use a separate project for testing. The Project ID is not a credential. The token can read and write contacts and conversations in its project.
from: app.gleap.io
  Service account token — Paste the token without the Bearer prefix.
