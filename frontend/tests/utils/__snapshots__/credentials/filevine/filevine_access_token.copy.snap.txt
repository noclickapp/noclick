## filevine_access_token (Filevine)
name: Access token
line: Paste an access token from Filevine.
how: Paste a Filevine Identity bearer access token and your Filevine organisation ID. Use the access_token returned by the Identity token exchange, not the personal access token used to obtain it. The token needs fv.api.gateway.access, tenant and filevine.v2.api.* access. Paste only the token without Bearer. Access tokens expire; replace it here when it expires. NoClick does not renew this token.
from: developer.filevine.io
  Access token
  Organisation ID — The numeric Filevine organisation ID sent as x-fv-orgid.
