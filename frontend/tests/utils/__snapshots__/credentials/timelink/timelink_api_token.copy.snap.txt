## timelink_api_token (Timelink)
name: API token
line: Paste an API token from Timelink.
how: Create an API token under My Account > API Tokens in Timelink and paste it here. Grant access to the resources your workflow uses. NoClick sends it as a bearer token to api.timelink.io. Client reads verify the connection; other permissions depend on the token.
from: docs.timelink.io
