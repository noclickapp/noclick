## kiwify_access_token (Kiwify)
name: Access token
line: Paste an access token from Kiwify.
how: In Kiwify, open Apps > API and create an API key with stats permission for the connection check and the permissions needed by your operations. Copy the account ID. Use the documented /oauth/token client-credentials request to obtain an access token, then paste that token here without the Bearer prefix. Replace it when it expires; NoClick does not renew it.
from: docs.kiwify.com.br
  Access token
  Account ID — Copy from Apps > API beside your API key.
