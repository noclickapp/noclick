## dacast_api_key (Dacast)
name: API key
line: Paste an API key.
how: Enter an existing API key and approve existing resource IDs. This node sends X-Api-Key and X-Format: default at the documented fixed API. Resource access is not a principal or account ownership check; actual API entitlement remains unknown until acceptance.
  API key
  Approved resource IDs (optional) — JSON string arrays of channel/video/playlist UUIDs and numeric-string folder IDs. Maximum 50 per family is a NoClick limit.
  Monitor All Folders (optional) — Allow the new-folder trigger to watch all folders, including newly created IDs outside the approved list. Manual reads still require approved IDs; names remain controlled by Include Resource Names.
  Include resource Names (optional) — Opt in to channel/video/playlist titles and folder names. Descriptions, all links, stream settings, passwords and custom content are always omitted.
