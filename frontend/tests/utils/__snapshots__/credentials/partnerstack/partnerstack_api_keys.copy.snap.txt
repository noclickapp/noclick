## partnerstack_api_keys (Partnerstack)
name: API keys
line: Enter the Public key and secret key for Partnerstack.
how: In your vendor dashboard, open Settings → Integrations → Partnerstack API Keys. Paste the public and secret keys from the same test or production pair. Test keys work with test partners and customers; production keys perform live actions. NoClick sends these keys over HTTPS using Basic authentication.
