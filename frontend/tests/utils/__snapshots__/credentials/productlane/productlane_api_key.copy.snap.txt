## productlane_api_key (Productlane)
name: API key
line: Paste an API key from Productlane.
how: In Productlane, open Settings → Integrations → API and create a v2 API key. Choose the read/write scopes for the resources your workflow uses: threads, contacts, companies, changelogs, tags, projects and issues; sending messages needs messages:write and internal comments need comments:write. Paste the secret without Bearer. The key's workspace is verified with GET /me.
