## signalwire_project_token (Signalwire)
name: Project token
line: Paste a project token from Signalwire.
how: Supply a Project ID and its API token. Management is needed for the connection project probe; Messaging, Voice, Numbers or the documented Fabric scopes are required for their operations. Actual enabled token scopes remain provider authoritative. Personal pat_ and subscriber/guest Bearer tokens are separate unsupported families. Paste the opaque token only, including legacy PT tokens; no OAuth, minting, rotation or SDK default credential chain is performed.
from: signalwire.com
  SignalWire Space URL — Your exact HTTPS <space>.signalwire.com origin. Custom domains, API routes and private hosts are unsupported.
  Project ID — The UUID of the project that issued this API token; not a Compatibility SID or personal user ID.
  Project API token
