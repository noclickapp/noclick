## force24_access_token (Force24)
name: Access token
line: Paste an access token from Force24.
how: Paste an existing Force24 bearer access token, without the Bearer prefix. Force24 issues tokens using its documented client_credentials grant with scope api.Master. The master user can find API credentials under Settings > Applications. Tokens expire: replace this token when it expires. NoClick does not obtain or refresh it. The connection check reads your account's marketing lists; it does not verify every write permission.
