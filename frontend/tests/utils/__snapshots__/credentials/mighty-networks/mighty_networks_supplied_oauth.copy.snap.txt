## mighty_networks_supplied_oauth (Mighty Networks)
name: Supplied OAuth
line: Enter the Network Numeric ID, Existing OAuth access token, client ID, scope and Expires At for Mighty Networks.
from: docs.mightynetworks.com
  Network Numeric ID — Actual numeric ID of the intended Mighty Network. Bound to every request and checked against network.resourceId; this form does not accept arbitrary hosts.
  Allow management Writes (optional) — Off by default. Enables private-space creation, names, collection/tag management and owned draft posts. Provider webhooks/automations may react; no notification suppression is promised for metadata writes.
  Existing OAuth access token — Already issued token for a specific user and Network. NoClick does not register an app, perform consent, exchange a code or refresh this supplied grant.
  Client ID — Actual application Client ID that issued this token, retained as supplied grant context.
  Scope — Exact scope from the successful token response, not the requested scope list. Member and host grants differ; role and plan remain vendor-enforced.
  Expires At — Actual expiry calculated from the issuing response. Tokens are short-lived, typically one hour; expired tokens must be replaced externally.
