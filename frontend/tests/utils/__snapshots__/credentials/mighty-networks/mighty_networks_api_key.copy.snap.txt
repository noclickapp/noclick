## mighty_networks_api_key (Mighty Networks)
name: API key
line: Paste an API key from Mighty Networks.
from: docs.mightynetworks.com
  Network Numeric ID — Actual numeric ID of the intended Mighty Network. Bound to every request and checked against network.resourceId; this form does not accept arbitrary hosts.
  Allow management Writes (optional) — Off by default. Enables private-space creation, names, collection/tag management and owned draft posts. Provider webhooks/automations may react; no notification suppression is promised for metadata writes.
  Mighty API host key — Issued in Network Admin → Integrations → Mighty API. Acts as its host, holds host scopes only and never expires until revoked. Admin REST keys are a different credential. Scale or above is required by the vendor; your plan/access is unverified.
  Scope (optional) — Exact host scopes selected for this key, when known. Unknown stays unknown; these supplied labels are not independent provider proof.
