## langflow_api_key (Langflow)
name: API key
line: Paste an API key from Langflow.
how: Supply an issued Langflow API key and the exact origin of your owned public HTTPS server. Localhost, private networks, login passwords and session tokens are not supported.
from: docs.langflow.org
  Public HTTPS server origin — An owned server origin only, with no path, query, user information or fragment.
