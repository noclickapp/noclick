## hubfit_api_key (Hubfit)
name: API key
line: Paste an API key from Hubfit.
how: In Hubfit Settings > API, create an API key (Ultimate plan, workspace owner). Paste the key alone. Select clients:read for connection verification and reads; clients:create, clients:write, messages:write, check-ins:review and tasks:write for their actions. Triggers require webhooks:write and an owner or admin key. The key acts as its owner in that workspace.
