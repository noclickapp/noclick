## etsy_token (Etsy)
name: Token
line: Paste a token from Etsy.
how: Copy keystring and shared secret from Etsy Your Apps into their separate fields. Generate an OAuth access token using Etsy's authorization-code/PKCE flow with the listed scopes, then paste it here. Tokens expire after one hour; replace expired tokens. Required scopes: listings_r, listings_w, listings_d, shops_r, shops_w, transactions_r, transactions_w.
from: etsy.com
  App Keystring — Your Etsy application keystring from Your Apps.
  Shared secret — The shared secret for the same Etsy application; required on every request.
  Access token — Paste an existing Etsy OAuth access token, including the numeric user ID prefix. Tokens expire after one hour; paste a replacement when it expires.
