## mycrm_leads_access_token (Mycrm Leads)
name: Access token
line: Paste an access token from Mycrm Leads.
how: Use the API base URL and adviser contact ID issued by LMG. Paste an existing access_token obtained with your issued client ID, client secret and approved scopes using MyCRM's client_credentials flow. Leads-only credentials are available in MyCRM Profile Management → API Access Management; other operations require additional access from LMG. Tokens expire: replace the token here when it expires. NoClick does not exchange or refresh tokens. The API base URL must be the issued HTTPS origin before /jsonapi. Listing contacts proves contact-search access; leads-only credentials may save as unverified or be rejected if they lack that access.
from: api-docs.mycrm.io
  API base URL — Issued HTTPS origin, without /jsonapi; service URLs differ by environment.
  Access token
  Adviser contact ID — The UserId context supplied with your API access, not a client contact ID.
