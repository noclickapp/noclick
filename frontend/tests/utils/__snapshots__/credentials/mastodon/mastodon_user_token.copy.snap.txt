## mastodon_user_token (Mastodon)
name: User token
line: Paste an user token.
how: Supply an existing USER OAuth access token and its public HTTPS instance origin. verify_credentials needs read:accounts, or profile on Mastodon 4.3+. Private own statuses need read:statuses. These are documented requirements, not a claim about your granted scopes or server version. No app token, token issuance/exchange/refresh, anonymous fallback or default instance.
  Instance origin — Exact public HTTPS origin where this user token was issued, e.g. https://social.example.com. No /api path, profile URL, query, userinfo or federation destination.
  Existing user access token
