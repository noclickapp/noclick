## reteno_api_key (Reteno)
name: API key
line: Paste an API key from Reteno.
how: In Reteno, open your profile > Settings > API, create a key and paste it here. Select access rights for the operations you need; Full access to API includes the account-info connection check. NoClick sends the key as the Basic Auth password to api.reteno.com. No username is needed.
