## planday_access_token (Planday)
name: Access token
line: Paste an access token.
how: Supply an already issued access token and its exact client ID. Calls send X-ClientId and Authorization: Bearer to openapi.planday.com. Connection reads protected portal info; it proves a portal resource, not human identity or every permission. Reads require department:read, employeegroup:read, employee:read and shift:read where used. No app creation, consent, refresh exchange or generic OAuth callback is performed. Documented access lifetime is one hour; replace expired tokens through their issuing flow.
  Client ID
  Access token
  Access token expiry (optional) — Optional exact issuer expiry with timezone. An expired value prevents any API request; no expiry is invented from the time of entry.
  Expected Portal ID (optional) — Optional exact protected /portal/v1.0/info data.id, checked before accepting other operation results.
