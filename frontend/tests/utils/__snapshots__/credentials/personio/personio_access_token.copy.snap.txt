## personio_access_token (Personio)
name: Access token
line: Paste an access token from Personio.
how: Generate a bearer token using your Personio API client ID and secret, then paste the token here. Tokens expire after 24 hours; replace the saved token when it expires. Enable read/write permissions for Employees, Absences and Attendances in your Personio API credentials.
from: developer.personio.de
  Access token — Without the Bearer prefix.
