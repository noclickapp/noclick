## api2cart_api_key (Api2cart)
name: API key
line: Paste an API key from Api2cart.
how: Use an existing Api2cart account API key and already connected store key. Enter the exact platform cart_id and selected stores_info store_id. NoClick does not install a bridge or connect a third-party store.
from: api2cart.com
  API2Cart API key
  Connected store key
  Platform cart ID — Exact cart_id from the existing Api2cart connection, for example Shopify
  Store ID — Exact selected stores_info store_id from cart.info; fixed parent scope
