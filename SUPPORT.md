# Support

Use GitHub Discussions for usage questions and GitHub Issues for reproducible
bugs in this repository. Include the commit or release, deployment topology,
relevant sanitized logs, and minimal reproduction steps.

Community support is best effort. A response time, fix, compatibility window,
or deployment review is not guaranteed. Do not post secrets, OAuth tokens,
customer data, private workflow inputs, or unredacted traces.

Report vulnerabilities according to [SECURITY.md](./SECURITY.md).
